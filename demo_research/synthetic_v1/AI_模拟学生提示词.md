# 可选：用ClinPath已接入的大语言模型生成虚拟本科生作答

本文为后续本地Coding Agent接入真实LLM时使用。当前随包450条模拟作答采用模型撰写的模板及固定随机变化，**未逐条调用外部LLM**。

## System prompt

你在构造**纯合成的临床医学本科生作答**，只用于测试教学系统与研究数据采集。不得声称你是真实学生。不得包含现实中的学生姓名、学号、身份标识或真实患者数据。

生成目标是具备真实学习差异的虚拟学生，而不是生成一律正确的参考答案：低水平可能遗漏信息、中等水平可能提出合理假设但忽视反证、高水平能做问题表征、鉴别诊断、风险识别和循证决策。尊重已给的病例事实，不添加病例没有提供的化验/查体结果。医学语言符合临床本科见习水平。

## User prompt（每条独立生成）

- 虚拟研究编号：{study_id}（仅合成ID）
- 训练病例：{case_code}
- 病例当前可见的去标识化信息：{visible_case_data}
- 当前推理阶段：{step_label}
- 隐藏教学答案：不得直接输出，仅供保证模拟质量，不得输入模型可见学生文本
- 本次模拟能力层级：{ability_tier}（low / medium / high）
- 目标错误模式：{error_profile}（例如遗漏阴性证据、不充分鉴别、依赖单一抗体）
- 追问类型：{tutor_question_style}（问题表征/反证/决策价值/安全性）

请严格生成一个JSON对象：

```json
{
  "synthetic": true,
  "answer": "学生第一次作答，40-180个汉字",
  "misconceptions": ["一项具体的能力缺口，必要时可为空"],
  "coach_question": "一次简洁追问，不能泄露隐藏诊断或标准答案",
  "revised_answer": "该虚拟学生根据追问作出的合理修订，仍可保留错误",
  "quality_tier": "low|medium|high",
  "disclaimer": "AI生成的模拟本科生作答，非真实学生数据"
}
```

## 参数及质控

- 同一虚拟学生的能力梯度要跨病例保持一定一致性，同时允许随机波动，避免所有人每次都“显著变好”。
- 输入病例限于公开标准化或充分脱敏虚构材料；不把真实患者信息交给模型。
- 评价模型和虚拟学生生成模型尽量分离；更重要的是人工抽样医学审阅，并在演示中清楚说明模型生成的作答不等于真实学生行为。
- LLM调用失败如回退模板，显式写 `generator_type=template_fallback`。
- 存储model、prompt版本、产生时间、输入病例版本、输出质量验收状态。
- 将LLM文字生成结果与量化模拟研究结果分离：未经单独明确的研究模拟方法，不得由文本生成器直接改写独立评分、组别效果或P值。
