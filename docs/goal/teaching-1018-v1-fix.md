## 目标

对第一轮A–D工作包及E1–E5证据包实施最小必要修复，使其具备医学专家审核、独立教学演示和省级教改申报书定稿条件。

**禁止大规模重构、新增无关平台功能、修改合成研究结局或未经批准部署生产。**

## 任务1：医学病例一致性修复

1. 重点复核 `A01_assessment_UA.md` 中2010 ACR/EULAR RA分类标准的计分、临床前提与标准诊断。
2. 不允许同一病例在评分逻辑中同时声称达到RA分类阈值又未达到任何疾病分类标准，除非已明确区分具体前提及可接受答案。
3. 检查其余5个病例的主要诊断、危险信号、鉴别诊断、检查和治疗原则。
4. 输出医学问题清单及修订草稿。
5. 所有病例仍保持 `PENDING_REAL_REVIEW`，不得模拟专家签名。

## 任务2：统一研究评分口径与来源

1. 研究量表暂保留10/20/25/15/20/10，状态为待专家确认。
2. 生产形成性评分保持原权重，本轮不得擅自变更。
3. 检查并修复教师复核接口将 `rule_fallback` 误存为 `ai_score` 的问题。
4. 显式区分规则、AI、教师确认和独立盲评。
5. 对现有字段及历史记录制定最小兼容迁移方案。
6. 补充评分来源和一致性统计的回归测试。

## 任务3：修订正式教学研究方案

1. 分组单位尚未确定，分别给出班次整群和班次内小组两种可行性方案。
2. 若采用整群分配，主要统计模型必须考虑群内相关及群数不足的问题；不能仅以个体层面HC3代替。
3. 删除或修正单一组别批次内估计组间效应的错误描述。
4. 根据每年20—50名学生的招募规模，提供实际可行的探索性研究方案。
5. 独立教师盲评作为主要结局，平台形成性评分仅作过程指标。
6. 修正HC3公式文档中不等价的错误解释。
7. 不使用合成数据估计真实干预效应或设计正式研究样本量。

- 项目特色与创新：不超过300字
- 具体实施计划及预期成果：不超过600字

不能把合成研究的统计显著性写成真实教学成效。
