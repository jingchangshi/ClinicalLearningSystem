# ClinPath省级教改项目第四轮：整批分配研究方案最终收敛

仓库：`jingchangshi/ClinicalLearningSystem`

目标分支：`teaching-grant-2026-wpd`

## 任务目标

根据申请人已经明确确认的教学组织限制，将研究设计固定为7个完整见习批次的整群分配探索性研究。

**申请人明确禁止同一批7名见习生拆分为两种教学组。此项为硬约束，不再请求确认，也不得以统计效率更高为由推荐班内随机方案B。**

保留正式项目名称：

《基于人工智能辅助临床推理训练的医学生个性化学习与形成性评价教学改革研究》

## T1：锁定研究设计

1. 仅采用7批次整群分配。
2. 每批7人，每批7天，共计划49名本科见习生。
3. 建议预先固定3批ClinPath、4批常规CBL，在35种可能的批次分配中随机产生实际分配。
4. 记录随机种子、批次日期、分配执行人及分配结果。
5. 若实际无法随机分配，则如实改为整群准实验研究，不再使用随机化推断。
6. 方案B作为历史备选方案可以保存在旧版修订记录，但不得出现在当前申报正文或现行研究方案的推荐、主模型、待确认事项中。

## T2：修订统计分析方案

1. 主要结局保持为两位独立教师盲评的D6标准化病例总分。
2. D1独立病例成绩作为研究基线。
3. 以7个批次为主要分析单位，展示各批次前后测均值、变化量、个体离散程度及数据完整率。
4. 预先规定探索性组间比较统计量，避免在观察结果后选择最有利的分析方法。
5. 如采用预先固定3批干预的整群随机化，精确枚举C(7,3)=35种合法分配。
6. 保留必要的小样本整群调整模型作为辅助分析，明确7个群使模型估计和区间推断高度不稳定。
7. 删除方案B对应的批次内置换、35^7组合数、Monte Carlo检验和49人个体分组功效推断。
8. 不能使用个体层面HC3替代整群相关性处理。
9. 不能使用合成研究Demo预设差异计算真实研究的预期效果。
10. 报告批次数、实际参与人数、缺失情况、评分者一致性及研究局限性，不承诺统计显著性。

## T3：修正7天教学闭环

保持基本时间安排：

- D1：独立T0考核；
- D2—D3：基础病例训练及形成性评分；
- D4—D5：能力短板强化、个性化推荐及教师干预；
- D6：独立T1考核；
- D7：学习反馈及总结。

重要修正：

**独立T0考核由盲评教师在T1后统一评分，不得假设其成绩已于D1进入ClinPath能力画像。**

D4个性化推荐应基于D2/D3实际形成性训练产生的能力画像。

通过现有代码审计与最小验证确认：

1. D2/D3训练可产生六维形成性评价；
2. 评价能更新能力画像；
3. 推荐系统能针对短板产生差异化任务；
4. D4/D5教师能够查看推荐依据并记录干预。

如果其中某个环节尚未真正连通，准确记录缺口；只补必要功能，不扩展平台架构。

## T4：调整独立考核质量控制

1. 保留A01、A02两份考核病例的医学难度校准。
2. 删除A04中依赖方案B的精确组内分配表。
3. 在每个完整批次内部随机分配考核题本顺序X/Y，不改变该批次所属教学组。
4. 尽量使X/Y顺序在7个批次及两种教学组之间平衡。
5. 明确独立T0/T1考核不能依赖学生随意访问的公开训练病例列表。
6. 未经真实教师审核、未完成病例访问隔离，不得开放正式研究考核。
7. 统一评分分歧裁决阈值和实际评分流程。
