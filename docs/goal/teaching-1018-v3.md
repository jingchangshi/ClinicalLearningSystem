## 四、任务T2：按照7天见习重新设计干预

将真实教学干预从原来的6周假设改为7天轮转周期。

建议基础框架：

- 第1天：T0独立标准化病例考核。
- 第2—3天：基础病例推理训练。
- 第4—5天：个性化强化训练与教师反馈。
- 第6天：T1独立标准化病例考核。
- 第7天：总结、问卷及教学反馈。

这是待教研室确认的建议流程，不得写成已经实际执行的排课安排。

明确每组核心教学内容和教师接触时间，制定适用于7天见习的最小有效训练方案。

确保ClinPath的个性化教学不只是统一病例练习，至少应具有：

1. 基线能力识别；
2. 能力短板对应的强化任务推荐；
3. 推荐理由与训练记录；
4. 教师针对性反馈。

优先复用现有能力画像、推荐和教师干预功能。

## 五、任务T3：修订研究人群、分组与统计分析

主要研究对象暂定为49名本科见习生。

其余实习生作为独立拓展人群，不直接与见习生合并进行主要结局分析。

提供两种实施方案：

**方案A：7个批次整群分配**

- 每个批次作为一个分配单位；
- 由于总共只有7个群，定位为探索性研究；
- 不承诺确证性统计显著性；
- 分析方法必须考虑群数不足和批次间差异。

**方案B：每批7人内部随机分成3人与4人**

- 每个批次同时设置ClinPath组和常规CBL组；
- 全部49人约形成24人与25人的两组；
- 同批次内使用随机分配，保留随机化记录；
- 主要采用基线校正、批次固定效应的组间比较；
- 提供按批次限制随机分配的置换检验等小样本敏感性分析；
- 明确教学污染、教师效应与人员流失的控制措施。

方案B为优先研究建议，但必须经教研室确认允许班内分组后才能定稿。

重算样本量可行性，所有分析定位必须与49名学生、7个批次的实际规模一致。

不得使用60名合成学生的预设差异估计真实干预效应。

## 六、任务T4：独立考核质量控制

1. 检查现有两份独立考核病例是否具有可比的难度和评价覆盖范围。
2. 提供教师进行难度校准的表格。
3. 评估是否需要平衡T0/T1题本顺序。
4. 保持考核病例与训练病例的内容隔离。
5. 明确两位教师盲评、评分分歧裁决及独立评分工作量。
6. 所有病例继续保持待真实教师审核状态，未经审核不得用于正式学生考核。

同时根据2024年EULAR/PReS Still病管理推荐核对成人Still病病例的参考文献名称与内容。
