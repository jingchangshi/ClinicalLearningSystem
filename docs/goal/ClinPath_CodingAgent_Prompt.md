## 2. 工作包A：标准化风湿免疫病例（A01-A04，P0）

- **A01**：拟定6例标准化病例教学卡（4例训练：SLE、RA、ANCA血管炎、炎性肌病；2例独立考核：未分化多关节炎、复杂多系统症状）。每例字段：病例编号、适用学段、教学目标、核心表现、按5阶段逐步释放信息、诊断及鉴别逻辑、危险信号、检查/治疗策略、常见错误、评分要点、指南文献及版本、脱敏与审核状态。禁止把未审核草稿写为已通过。
- **A02**：核对平台病例schema，提供最小导入/校验脚本与dry-run；训练病例与独立考核病例隔离，独立考核标准答案在学生端不可见。
- **A03**：生成两位真实带教教师审核空白表，字段含审核人、日期、准确性/本科适切性/难度、问题条目、修改、最终决定。提供`PENDING_REAL_REVIEW`默认状态；真实意见由教师填写。
- **A04**：至少1例训练病例完成真实UI教学路径验证，保存病例版本ID/截图。其余5例若来不及导入，可以作为审核中的标准化教学文档提交。
- **验收**：6份非重复教学卡草稿（4训2考）、审核状态正确、训练/考核不串用、输入信息可脱敏、教师可审；1例走通平台。

## 3. 工作包B：六维度形成性评价（B01-B04，P0）

- **B01**：依据现有六项评分结构建立六维量表v0.1，并对照拟议权重 `医学知识10 / 关键信息20 / 鉴别诊断25 / 证据整合15 / 临床决策20 / 循证安全10`，说明系统内部六项0-100的原始含义、量表加权规则、边界与版本。评分锚点至少覆盖低/中/高三个水平。
- **B02**：构造12-20份可追溯的**模拟学生作答**用于两位真实教师独立盲评；不得预填人工分数或虚构签字。确保教师先独立评分、再讨论校准意见。两位计算机模拟评分者不能等同真实教师。
- **B03**：统一导出模板：`sample_id, case_id, rubric_version, rater_id, rater_origin, six_scores, total, review_date, remarks`。保留原始分、争议和修订记录；提示教师复核当前系统内可能会回写能力画像，不应把那种确认流程直接当作盲法独立考核。
- **B04**：生成量表一致性分析脚本（真实评分尚未提供时不得输出“真实教师一致性”数值）；输出示例只能标注“模拟评分者示例”。
- **验收**：量表v0.1可读、可评分；评分脚本一致；真实教师审核保持待办直至收到实际记录。

## 4. 工作包C：教学闭环示范（C01-C04，P0）

- **C01**：对现有学生端和教师端录制一次SLE演示用例的端到端流程：课前诊断→5阶段作答→AI/规则追问来源→评分反馈→推荐任务→教师复核/干预→训练复盘。
- **C02**：记录每个环节的账号角色、病例与session ID、数据来源、模型名称/评价模式、版本SHA；自动化E2E仅测系统能走通，不据此宣称教学有效。
- **C03**：复用已有教师驾驶舱、学生画像、研究导出，不重复开发。补足可读中文字段、阶段标签及必要的页面证据提示，不进行大型UI重构。
- **C04**：输出一段3-5分钟教学演示录屏脚本与截图索引；演示账号/模拟数据必须醒目标识，实际专家观摩记录由用户补入。
- **验收**：一个完整流程能重放、页面无身份数据泄露、降级被正确标识、记录可按ID追溯、截图带版本与合成数据标签。

## 5. 工作包D：独立合成研究展示（D01-D05，P0/P1）

- 输入：已生成的 `ClinPath_WPD_2026_全合成研究演示完整包.zip`：60名虚拟学生(30/30)、120条T0/T1、180条训练、450条推理阶段；统计结果来自预设差异情景，非真实教学证据。
- **D01(P0)**：导入仓库内独立、只读、版本化数据资源或独立演示库；不得写入 `students/case_sessions/learning_evidence_events/teacher_score_reviews` 等实际业务表；不得运行旧合成数据脚本改写生产库。
- **D02(P0)**：教师端新增`/teacher/research-demo`及只读API，展示分组、前后测、各维度得分、模拟差异/CI/P值、病例过程及可下载的SYNTHETIC CSV。所有图表、截图、下载保留“模拟研究”显著标记。
- **D03(P0)**：统计值从同一版本数据动态计算或从可复现离线统计产物加载，不能网页硬编码与CSV不同的数；保留生成器版本、随机种子`20261018`、效应预设说明。

- **D05(P1)**：可选真实LLM“模拟学生角色”离线文本生成，不预设为必须；只模拟作答文本，不据此推导真实因果效果；记录`generator_type/model/prompt_version`，专家抽样核查医学真实性。
- **验收**：60唯一ID、每人T0/T1各一条、各组30、统计结果从导出数据复现、180训练/450步骤可追溯、无生产数据污染、全部标识一致。
