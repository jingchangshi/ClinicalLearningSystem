## 1. 脚本能力与安全护栏

脚本只使用标准库（`argparse`/`csv`/`math`/`statistics`/`decimal`），
不依赖 scipy/numpy。

计算内容：

| 项目 | 说明 |
| --- | --- |
| 各维度描述统计 | 合并两位评分者的均值、SD、n |
| 加权总分 | `Σ(维度分 × 权重)`，权重取自 B01（10/20/25/15/20/10） |
| 配对一致性 | 完全一致 / ±5 以内 / ±10 以内的比例 |
| ICC(2,1) | 双向随机效应、绝对一致性、单评分者（Shrout & Fleiss） |
| Cohen's kappa | 分数按低 0–39 / 中 40–69 / 高 70–100 分箱 |
| 自检 | `--self-check`，含 ICC 手算样例与 kappa 手算样例 |

护栏（均已实测）：

| 情况 | 行为 | 退出码 |
| --- | --- | --- |
| 空白的真实模板（`REAL_BLINDED_RATER` 有效评分为 0） | 打印“尚无可分析的真实评分（REAL_BLINDED_RATER=0），不得报告真实教师一致性”，不出数 | 2 |
| 只有 1 个样本具备完整双评分 | 同上，说明至少需要 2 个样本 | 2 |
| 模拟数据但未加 `--demo` | 拒绝运行 | 4 |
| 同一文件混有真实与模拟评分 | 拒绝运行 | 5 |
| 缺列 / 非数字 / 超出 0–100 | 报输入错误 | 3 |
| 自检失败 | 报失败 | 6 |
| 真实评分但缺 `rater_id` 或 `review_date` | 打印警告（B03 要求必填），仍继续分析 | 0 |
| 评分无差异或方差为 0 | 对应统计量显示“不可计算”，不插补 | 0 |

**没有真实评分时，脚本不会生成任何可被误读为一致性结果的数字。**

## 6. 如何解读（以及在什么情况下不能解读）

### 6.1 演示输出的含义

模拟评分者由固定随机种子生成，两份评分围绕同一个预设水平波动。
因此演示中的 ICC 偏高（>0.9）只反映“两个模拟器围绕同一中心值抽样”，
**不反映任何人类评分者的行为**。

### 6.2 真实评分到位后的报告要求

- 必须注明 `rubric_version`、评分者人数（2）、样本量、是否盲法；
- 必须报告“专家对**模拟作答**的独立评分”，不得表述为“真实学生得分”；
- 样本量小（16 份）时，ICC 与 kappa 的置信区间很宽，
  应同时报告区间或明确说明不确定性，不宜只给点估计；
- 一致性高 ≠ 评分正确：两位评分者可能共同偏离量表锚点，
  需要专家讨论而非只看数字；
- 量表改版（`rubric-v0.2`）后必须重新校准，不同版本不得合并报告。

### 6.3 不得出现的内容

- 不得把本文件的任何数字描述为“真实教师一致性”；
- 不得把 `SIMULATED_NOT_HUMAN` 改标为教师；
- 不得把平台内“复核确认”数据当作盲法独立评分（见 B03 第 4 节）。
