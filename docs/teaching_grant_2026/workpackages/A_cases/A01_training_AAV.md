## 1. 教学目标

1. 能识别“肺—肾综合征”这一模式：咯血 + 快速进展的肾功能不全 + 尿沉渣活动性改变。
2. 能说出 AAV 的三个临床表型（GPA、MPA、EGPA）及其与 ANCA 血清型的常见对应关系，并强调二者不能完全互相替代。
3. 能说出 2022 ACR/EULAR AAV 分类标准的用途与局限，并解释“分类标准 ≠ 临床诊断”。
4. 能提出关键鉴别（抗 GBM 病、感染、肿瘤、SLE）并说明如何用检查区分。
5. 能说出 AAV 治疗的两阶段结构（诱导缓解 + 维持缓解）与治疗前必须完成的感染筛查。

## 2. 核心表现

**主诉**：患者C，男性，56岁，间断咯血、乏力、尿色加深 3 周。

**关键阳性**

- 近 3 周咳嗽、痰中带血，近 1 周咯血量增多；活动后气促。
- 乏力明显，体重下降约 4 kg，食欲差。
- 近 2 周尿色加深（茶色），尿量较前减少。
- 鼻塞、血性鼻涕反复 2 个月，曾按“鼻窦炎”治疗，效果不佳。
- 查体：贫血貌；双肺散在湿啰音；双下肢轻度凹陷性水肿；血压 152/92 mmHg；体温 37.8 ℃。

**关键阴性**

- 无关节肿痛、无皮疹、无口腔/生殖器溃疡。
- 无哮喘病史、无嗜酸性粒细胞增多（初步血常规未见）。
- 无明确结核接触史；无长期免疫抑制用药史。
- 无吸烟史（肺癌风险相对低，但不能排除）。
- 无肉眼血尿外伤史、无泌尿系结石史。

## 4. 诊断及鉴别逻辑

**诊断思路**

1. **识别综合征模式**：上呼吸道（鼻窦炎、鼻出血）+ 肺（结节、空洞、咯血）+ 肾（活动性尿沉渣、肾功能下降）= 肺肾综合征，高度提示系统性血管炎。
2. **血清学定位**：PR3-ANCA 阳性更常见于 GPA，MPO-ANCA 更常见于 MPA 与 EGPA；但血清型与表型并不一一对应。
3. **组织学确认**：肾活检见寡免疫复合物新月体肾炎是重要支持证据；肉芽肿性炎症支持 GPA。
4. **排除模拟疾病**：感染（结核、真菌、心内膜炎）、肿瘤、抗 GBM 病、SLE、冷球蛋白血症。

**分类标准 ≠ 临床诊断（必须向学生讲清）**

- 2022 ACR/EULAR 的 AAV 分类标准是**分类**工具，用于研究入组，前提是“已诊断为小血管炎”。
- 分类标准不能用于“从零开始诊断”，也不能替代组织学与临床综合判断。
- ANCA 阴性不能排除 AAV（尤其 MPA 与 EGPA）；ANCA 阳性也可见于感染、药物、IBD 等。
- 分类标准里的“排除其他血管炎”条目需要真实的鉴别过程支撑。

**鉴别诊断**

| 鉴别疾病 | 支持点 | 反对点 / 本病例的不支持之处 |
| --- | --- | --- |
| 抗 GBM 病（Goodpasture 病） | 肺出血 + 急进性肾小球肾炎 | 抗 GBM 抗体未提及；AAV 与抗 GBM 病可重叠，必须检测抗 GBM 抗体 |
| 肺结核 | 咯血、肺空洞、发热、体重下降 | 无结核接触史；肾受累与上呼吸道受累不能由结核解释；仍需痰检与影像排除 |
| 肺部真菌感染（如曲霉） | 空洞、咯血 | 无免疫抑制史；肾与鼻窦表现不典型；需真菌学检查 |
| 细菌性肺炎 / 肺脓肿 | 发热、咳嗽、肺部浸润 | 多系统受累（肾、鼻窦）无法解释；抗感染治疗无效 |
| 肺癌 | 咯血、体重下降、空洞性病变 | 多系统受累不支持；但仍需支气管镜/影像随访排除 |
| 系统性红斑狼疮 | 多系统、ANA 可阳性、肾炎 | 无皮疹、关节痛、脱发；ANCA 相关血管炎以寡免疫复合物肾炎为特征 |
| 感染性心内膜炎 | 发热、血尿、多系统 | 无心脏杂音、无栓塞表现；血培养可排除 |
| 冷球蛋白血症性血管炎 | 肾小球肾炎、皮肤表现 | 无皮疹、无丙肝史；需冷球蛋白检测 |

## 5. 危险信号（organ-threatening red flags）

- **肺泡出血**：咯血量增加、血红蛋白快速下降、低氧血症 → 危及生命，需紧急处理。
- **急进性肾小球肾炎**：肌酐短期内快速上升、少尿、红细胞管型 → 需紧急肾内科评估与肾活检。
- **中枢神经系统受累**：头痛、癫痫、意识改变、颅神经麻痹。
- **消化道受累**：腹痛、黑便、肠穿孔征象。
- **心血管受累**：胸痛、心包炎、心肌受累。
- **治疗相关风险**：大剂量激素与免疫抑制剂后的严重感染（尤其肺孢子菌肺炎）、乙肝/结核再激活。

## 6. 检查策略（本科见习层面）

**必做**

- 血常规（含嗜酸性粒细胞）、肾功能、电解质、肝功能、尿常规 + 尿沉渣镜检。
- ESR、CRP。
- ANCA（PR3、MPO）、抗 GBM 抗体。
- ANA、抗 dsDNA、补体（鉴别 SLE）。
- 血培养（排除感染性心内膜炎）、痰涂片/培养、结核筛查（T-SPOT/PPD + 胸片）。
- 胸部 CT、鼻窦 CT。
- 乙肝、丙肝、HIV 筛查（免疫抑制前）。

**按需**

- 肾活检（光镜 + 免疫荧光 + 电镜）：确认寡免疫复合物新月体肾炎，评估活动性与慢性化程度。
- 支气管镜 + 肺泡灌洗：排除感染与肿瘤，评估肺泡出血。
- 肺功能 + DLCO：基线评估。
- 神经传导/肌电图、头颅 MRI：有神经系统症状时。
- 心脏超声、心电图：有心脏症状时。

**检查选择的原则**：AAV 的诊断需要“临床模式 + 血清学 + 组织学 + 排除模拟疾病”四条腿；任何一条缺失都要在记录中说明理由。

## 7. 治疗策略（原则层面，不做处方剂量指导）

1. **诱导缓解**（器官威胁性病变）：糖皮质激素联合利妥昔单抗或环磷酰胺；重症（如肺泡出血、急进性肾炎）可考虑血浆置换，指征由专科判断。
2. **维持缓解**：诱导缓解后改用毒性更低的方案（如利妥昔单抗、硫唑嘌呤、甲氨蝶呤），维持足够时长。
3. **治疗前安全筛查**：结核、乙肝、丙肝、HIV；评估乙肝再激活风险并决定抗病毒预防。
4. **感染预防**：肺孢子菌肺炎预防、疫苗接种（灭活疫苗）、避免不必要的侵入性操作。
5. **器官支持**：肾功能替代治疗指征、呼吸支持、血压管理。
6. **监测**：血常规、肝肾功能、尿常规、ANCA 滴度（不能单独作为复发依据）、疾病活动度、药物毒性、感染征象。
7. **多学科**：肾内科、呼吸科、耳鼻喉科、重症医学科协作。

> 本卡片不提供具体药物剂量、疗程与血浆置换次数。

## 8. 常见错误

1. **仅凭 ANCA 阳性诊断 AAV**：不结合临床模式、不做组织学与感染排除。
2. **把分类标准当作诊断标准**：不知道 2022 ACR/EULAR 标准的前提是“已诊断小血管炎”。
3. **漏掉肾脏评估**：只关注咯血，不查尿常规与肌酐，延误急进性肾炎的识别。
4. **不做感染排查就上免疫抑制**：未排除结核、真菌、心内膜炎，导致治疗相关恶化。
5. **不检测抗 GBM 抗体**：漏诊 AAV 与抗 GBM 病重叠。
6. **混淆诱导与维持**：把维持方案用于器官威胁性病变，或长期使用高毒性诱导方案。
7. **不写感染预防**：遗漏肺孢子菌肺炎预防与乙肝再激活预防。
8. **把 ANCA 滴度当作唯一复发指标**：忽略临床与尿液指标。
