## 4. 诊断及鉴别逻辑

**诊断思路**

1. **是否为“发热待查”**：病程 4 周、多次体温 >38.3 ℃、初步检查未明确病因 → 按发热待查框架处理。
2. **症状群定位**：高热 + 一过性皮疹 + 关节炎 + 咽痛 + 肝脾大 + 中性粒细胞性白细胞增多 + 铁蛋白极高 → 高度提示 AOSD。
3. **是否为排除性诊断**：AOSD 没有特异性抗体或病理标志，必须在排除感染、肿瘤（尤其淋巴瘤）、其他结缔组织病后作出。
4. **是否合并 MAS/HLH**：持续高热、血细胞进行性下降、铁蛋白极高、肝脾大、纤维蛋白原下降、sCD25 升高、NK 细胞活性降低 → 需紧急评估。
5. **危险分层**：肝功能异常、铁蛋白 >5000、血小板下降、凝血异常提示预后不良。

**分类标准 ≠ 临床诊断（必须向学生讲清）**

- Yamaguchi 标准（1992）是 AOSD 最常用的分类标准，包含主要与次要条目，且要求排除感染、肿瘤与其他风湿病。
- 分类标准用于研究入组与病例定义，不是诊断金标准；阴性条目不能排除 AOSD，阳性条目也不能替代排除过程。
- 铁蛋白极高也可见于 HLH、严重感染、肝损伤、Still 病；不能单独作为诊断依据。
- AOSD 与 HLH/MAS 是连续谱，MAS 是 AOSD 的严重并发症，不能因为“已诊断 AOSD”而忽略 MAS 的评估。

**鉴别诊断**

| 鉴别疾病 | 支持点 | 反对点 / 本病例的不支持之处 |
| --- | --- | --- |
| 细菌感染（败血症、脓肿、心内膜炎） | 高热、白细胞升高、CRP 高 | 血培养 2 次阴性；抗生素无效；无明确感染灶；一过性皮疹与关节痛不典型 |
| 病毒感染（EBV、CMV、HIV） | 发热、皮疹、肝脾大、肝功能异常 | 需血清学排除；本病例无淋巴结肿大、无异型淋巴细胞描述；EBV/CMV 待查 |
| 淋巴瘤（尤其 T 细胞淋巴瘤） | 高热、肝脾大、铁蛋白高、体重下降 | 无淋巴结肿大；需骨髓与影像排除；不能仅凭“无淋巴结”排除 |
| HLH / MAS | 高热、肝脾大、血细胞减少、铁蛋白极高、纤维蛋白原下降 | 本病例血小板尚正常，但已有 MAS 风险；需 sCD25、NK 活性、骨髓评估 |

## 5. 危险信号（organ-threatening red flags）

- **MAS/HLH**：持续高热、血细胞进行性下降、铁蛋白 >5000 ng/mL、纤维蛋白原下降、甘油三酯升高、sCD25 显著升高、NK 细胞活性降低、骨髓噬血现象 → 急症，需紧急处理。
- **肝功能衰竭**：ALT/AST 快速上升、凝血酶原时间延长、黄疸。
- **心肌炎/心包炎**：胸痛、心律失常、心肌酶升高、心脏超声异常。
- **中枢神经系统受累**：意识改变、癫痫、脑膜刺激征。
- **呼吸衰竭**：AOSD 可合并急性呼吸窘迫综合征。
- **DIC**：凝血异常、出血倾向。
- **治疗相关风险**：大剂量激素与免疫抑制后的严重感染；长期激素的代谢与骨骼并发症。

## 6. 检查策略（本科见习层面）

**必做**

- 血常规（动态复查）、ESR、CRP、铁蛋白（动态复查）。
- 肝功能、肾功能、电解质、白蛋白、凝血功能（PT/APTT、纤维蛋白原、D-二聚体）。
- 血培养（多次、不同部位）、尿培养、痰培养（按症状）。
- ANA、抗 dsDNA、RF、抗 CCP、ANCA（排除其他风湿病）。
- 胸部 CT、腹部超声（肝脾、淋巴结）。
- 感染筛查：结核（T-SPOT/PPD + 胸片）、乙肝、丙肝、HIV、EBV/CMV 血清学。
- 甲状腺功能。

**按需**

- 骨髓穿刺 + 活检（排除淋巴瘤、评估噬血现象）。
- sCD25（可溶性 IL-2 受体）、NK 细胞活性、甘油三酯。
- 淋巴结超声/活检（有淋巴结肿大时）。
- 心脏超声、心电图、心肌酶（有心脏症状时）。
- 腰椎穿刺（有神经系统症状时）。
- PET-CT（高度怀疑淋巴瘤且常规检查阴性时，由专科决定）。

**检查选择的原则**：AOSD 是排除性诊断，检查顺序应体现“先排除可致命、可治疗的疾病（感染、肿瘤、MAS）”；铁蛋白与血常规需要**动态**复查，单次值不足以判断。

## 7. 治疗策略（原则层面，不做处方剂量指导）

1. **AOSD 分层治疗**：
   - 轻症：NSAIDs 或小剂量糖皮质激素。
   - 中重症：糖皮质激素为主，联合甲氨蝶呤或其他传统免疫抑制剂。
   - 难治/重症：IL-1 或 IL-6 通路生物制剂。
2. **MAS/HLH**：属于急症，需按 HLH 方案紧急处理（大剂量激素 ± 环孢素/依托泊苷等），由血液科/风湿科/重症医学科联合决定。
3. **治疗前安全筛查**：结核、乙肝、丙肝、HIV；评估感染风险。
4. **感染预防**：肺孢子菌肺炎预防（大剂量激素/免疫抑制时）、疫苗接种（灭活疫苗）。
5. **监测**：体温曲线、皮疹、关节、血常规、铁蛋白、肝功能、凝血功能、sCD25；警惕 MAS 复发与药物毒性。
6. **患者教育**：说明 AOSD 的慢性复发性、发热时及时就医、不可自行停用激素。

> 本卡片不提供具体药物剂量、疗程与生物制剂选择细节。

## 8. 常见错误

1. **把 AOSD 当作“确诊即可”的疾病**：忽略它是排除性诊断，未排除感染与淋巴瘤。
2. **不做骨髓评估**：遗漏淋巴瘤与 HLH。
3. **忽视 MAS 预警**：只关注发热与关节痛，不动态复查血常规、铁蛋白、凝血。
4. **把铁蛋白高只归因于 AOSD**：不鉴别 HLH、严重感染、肝损伤。
5. **抗生素滥用**：血培养阴性、抗生素无效仍长期使用。
6. **不做治疗前感染筛查**：大剂量激素前未筛查结核、乙肝。
7. **不写随访与复发监测**：AOSD 易复发，需长期随访。
8. **把分类标准当作诊断标准**：不知道 Yamaguchi 标准要求排除其他疾病。
