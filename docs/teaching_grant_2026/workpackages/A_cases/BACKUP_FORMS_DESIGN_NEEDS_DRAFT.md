# 备用平行题本：设计需求草案（仅草案，**未启用**）

> 状态：**DRAFT_DESIGN_NEEDS_NOT_ENABLED**；所有备用题本内容均不存在，也不得在真实专家审核之前创建为可发布的 AssessmentForm。本文件由 AI 起草（AI technical/medical DRAFT re-check），不含任何教师审定。动因见 `LEAKAGE_AUDIT_DRAFT.md` 的 L-1/L-2/L-3。

## 1. 何时需要备用题本（决策点，由研究负责人和统计负责人决定）

| 条件 | 是否需要备用题本 |
| --- | --- |
| 采用批内 X/Y 交叉且不接受 100% 批内暴露（L-2） | 需要（方案 P2） |
| 公开仓库中的 A01/A02 被视为已暴露（L-1） | 需要（至少需要替换已暴露的那一份；备用题本是首选路径） |
| 以管理措施（同时开考、监考、保密声明）为主，并接受批内暴露的残余风险 | 可不立即需要，但应预先准备以便应急替换 |
| 发生登记在案的泄漏事件 | 需要，且应立即停用被泄漏题本 |

## 2. 平行性（等价）要求

备用题本 B01（对应 A01 的推理类型）与 B02（对应 A02 的推理类型）在下列方面必须与主题本匹配，匹配程度由两位真实教师在 `review_forms/DIFFICULTY_MATCH_A01_A02.md` 的扩展版中判定：

| 维度 | 要求 |
| --- | --- |
| 结构 | 5 阶段（S1–S5），每阶段 `title / clinical_information / question`，与主题本相同的阶段功能 |
| 信息量 | 学生可见 `clinical_information` 总字符数与主题本相差 ≤10%（A01 载荷计数 604，A02 为 636） |
| 推理类型 | B01：信息不完整下的暂定诊断 + 分类标准计分 + 随访重新分类；B02：持续症状待查 + 客观证据识别 + 血清阴性/决定性检查的解释 + 审慎管理 |
| 六维覆盖 | 六个维度均有可观察锚点；锚点粒度与主题本一致（高/中/低三档，可计数条目） |
| 难度与时间 | 预计作答时间同量级（AI 估计 45–60 分钟，未校准）；难度由教师校准而非假定 |
| 疾病域 | 与训练池（SLE、RA、AAV、IIM，以及种子病例 SLE 合并感染、成人 Still 病）**不重叠**；与 A01/A02 的主诊断也不重叠；B01 与 B02 互不重叠 |
| 表面特征 | 不复用主题本的年龄、性别、化验数值、病程、患者代号；避免“换皮”（同一推理链仅换数值） |
| 答案模式 | 不共享“万能不确定+随访”的得分捷径；每份题本必须含需要作出明确决策的节点 |
| 安全 | 不含无指征免疫抑制的诱导性提示；治疗选项仅原则层面 |
| 虚构与脱敏 | 虚构合成病例，患者以字母代号，年龄取整，相对时间 |

## 3. 候选主题（仅供教师讨论，非选题决定）

下列主题只是**满足疾病域不重叠**的候选，是否合适、是否本科见习范围内、是否有可核实的分类标准与指南，均须教师判断；AI 未创建任何病例内容。

| 平行于 | 候选主题 | 可借助的分类/管理框架（均需教师核实原文） | 需教师重点考虑 |
| --- | --- | --- | --- |
| B01（对应 A01 型：信息不完整的炎性关节痛） | 银屑病关节炎 / 脊柱关节炎早期（炎性腰背痛+附着点炎）/ 痛风与假性痛风鉴别 | CASPAR（银屑病关节炎）；ASAS 轴性/外周脊柱关节炎分类；ACR/EULAR 痛风分类标准 | 是否仍涉及“多关节炎+随访重新分类”同一推理链；与 A01 的鉴别诊断表重叠程度 |
| B02（对应 A02 型：持续症状待查+客观证据+决定性检查） | 持续性雷诺现象伴指端改变（系统性硬化症早期线索）/ 不明原因肌酶升高 / 反复口腔与生殖器溃疡待查 | 2013 ACR/EULAR 系统性硬化症分类标准；ISG/ICBD 白塞病标准 | 与训练病例（炎性肌病）的重叠；是否有同样清晰的“未评估项”设计 |

## 4. 创建与审核流程（启用前的硬门槛）

1. 由课题组指定作者起草（可 AI 辅助，必须在文件头标注 `PENDING_REAL_REVIEW` 与“AI 辅助草案”）；起草材料**不得存放在公开仓库**（见 L-1）。
2. 通过 `scripts/grant/validate_assessment_payloads.py` 的技术校验（五阶段、锚点、学生可见字段无答案）。
3. 两位真实教师**独立**完成与主题本相同的 `CASE_REVIEW_FORM`（含 E 类考核专项）与难度匹配表，并在系统内各自提交表单审核。
4. 小规模非研究试答（住院医/非研究学生）用于校准时间与评分者一致性；试答数据**不并入研究数据**。
5. 管理员核验后发布；发布后版本冻结，医学内容修改须新建版本。
6. 在研究数据集中记录每名学生每个时点所用题本、版本、顺序与分配方案版本。

## 5. 分配与分析设计需求（交统计负责人，本工作包不改 SAP）

| 需求 | 说明 |
| --- | --- |
| 先冻结题本顺序，再做整批教学组分配 | 与 R4.5 一致；任何备用题本方案同样先冻结 |
| 记录每名学生的题本家族与顺序 | 数据字典需增加 `form_family`（A/B）等字段（由研究/统计域决定命名） |
| 家族难度差 | D1 与 D6 使用不同家族时，T0→T1 变化含家族难度差；两臂都经历相同差异，组间变化差理论上抵消，但需敏感性分析并明确写出假设（无臂×家族交互） |
| 往届传播 | 对 B 家族同样存在；需按批次序号、批内知情者数做敏感性分析 |
| 泄漏事件 | 登记、停用、替换及对分析集的处理（排除/敏感性）需预先规定 |
| 数据泄漏 | 题本内容不得写入导出的研究数据集；仅保留题本编码、版本和分数 |
