## 1. 教学目标

1. 能识别炎性肌病的核心三联：**对称性近端肌无力 + 特征性皮疹 + 肌酶升高**，并识别“无肌病性皮肌炎”这一变异。
2. 能区分“肌痛”与“肌无力”，并能用徒手肌力测试（MRC 分级）描述近端肌力。
3. 能说出肌炎特异性抗体（MSA）的临床意义，尤其是抗 Jo-1 与抗合成酶综合征、抗 MDA5 与快速进展型间质性肺病的关系。
4. 能说出 2017 EULAR/ACR IIM 分类标准的用途与局限，并解释“分类标准 ≠ 临床诊断”。
5. 能识别间质性肺病（ILD）这一决定预后的关键器官受累，并提出筛查与监测计划；同时能说出成人皮肌炎需警惕恶性肿瘤筛查。

## 2. 核心表现

**主诉**：患者D，女性，52岁，四肢近端无力、双手皮肤粗糙、活动后气促 2 个月。

**关键阳性**

- 近 2 个月逐渐出现上楼、从椅子上站起、梳头困难；无晨轻暮重波动。
- 双手掌指关节及指间关节伸侧紫红色斑丘疹（Gottron 丘疹），眼睑周围紫红色水肿性红斑（向阳疹）。
- 双手掌面皮肤粗糙、脱屑、皲裂（“技工手”）。
- 干咳、活动后气促进行性加重，平地快走 100 米即感气短。
- 查体：双肺底可闻及 Velcro 啰音；近端肌力（肩外展、髋屈曲）MRC 4 级，远端肌力正常；颈屈肌力减弱；无吞咽困难。
- 实验室：CK 1850 U/L，LDH 升高，AST/ALT 轻度升高；ESR 42 mm/h，CRP 18 mg/L；ANA 1:160 阳性；抗 Jo-1 抗体阳性。
- 影像：胸部 HRCT 示双下肺胸膜下网格影与磨玻璃影，伴轻度牵拉性支气管扩张，符合间质性肺病（NSIP 型倾向）。
- 肺功能：FVC 预计值 68%，DLCO 预计值 55%。

**关键阴性**

- 无皮疹光照加重（与 SLE 的光敏感不同）。
- 无口腔溃疡、无脱发、无关节肿胀。
- 无雷诺现象（抗合成酶综合征可有，但本病例未出现）。
- 无吞咽困难、无构音障碍（提示咽部肌群暂未受累）。
- 无肌痛明显（以无力为主）。
- 无近期他汀类、秋水仙碱、氯喹等药物使用史。
- 无甲状腺疾病史、无家族性肌病病史。

## 4. 诊断及鉴别逻辑

**诊断思路**

1. **是否为炎性肌病**：对称性近端肌无力 + 肌酶升高 + 肌电图/肌活检支持 + 特征性皮疹。
2. **属于哪一亚型**：皮肌炎（Gottron、向阳疹、技工手）、抗合成酶综合征（抗 Jo-1 + ILD + 技工手 + 关节炎）、免疫介导坏死性肌病（抗 SRP/HMGCR）、包涵体肌炎（远端与不对称受累、对激素反应差）。
3. **是否有器官威胁**：ILD（决定预后）、吞咽困难（误吸风险）、心肌受累、快速进展型 ILD（抗 MDA5 相关）。
4. **是否需肿瘤筛查**：成人新发皮肌炎，尤其抗 TIF1-γ 阳性者，恶性肿瘤风险升高。

**分类标准 ≠ 临床诊断（必须向学生讲清）**

- 2017 EULAR/ACR IIM 分类标准用于**分类**，前提是“已怀疑特发性炎性肌病”，且需满足特定的临床与检查条目。
- 该标准不能替代临床诊断，也不能用于排除所有肌病；对包涵体肌炎、免疫介导坏死性肌病的区分能力有限。
- 抗 Jo-1 阳性支持抗合成酶综合征，但抗体阴性不能排除；抗体谱需结合临床解读。
- “无肌病性皮肌炎”肌酶可正常，仍属皮肌炎谱系。

**鉴别诊断**

| 鉴别疾病 | 支持点 | 反对点 / 本病例的不支持之处 |
| --- | --- | --- |
| 他汀类/药物性肌病 | 肌痛、CK 升高 | 无相关用药史；有特征性皮疹与 ILD，药物性肌病不能解释 |
| 甲状腺功能减退性肌病 | 近端无力、CK 升高、乏力 | 需甲状腺功能排除；不能解释皮疹与 ILD |
| 包涵体肌炎 | 近端/远端无力、CK 轻中度升高 | 多见于老年男性，远端与不对称受累，对激素反应差；本病例皮疹与 ILD 不支持 |
| 重症肌无力 | 无力、易疲劳 | 晨轻暮重波动、无肌酶升高、无皮疹；本病例不符合 |
| 系统性红斑狼疮 | 皮疹、ANA 阳性、多系统 | 皮疹为 Gottron/向阳疹而非蝶形；无口腔溃疡、脱发、蛋白尿；以肌无力为主 |
| 系统性硬化症 | 技工手样改变、ILD、ANA 阳性 | 需有皮肤硬化、雷诺现象、抗 Scl-70/着丝点抗体；本病例无皮肤硬化 |
| 运动神经元病 | 进行性无力、肌萎缩 | 无上/下运动神经元体征、无肌束颤动；肌酶与皮疹不支持 |
| 感染性肌炎（病毒/细菌） | 肌痛、CK 升高 | 病程 2 个月、无发热；皮疹与 ILD 不典型 |

## 5. 危险信号（organ-threatening red flags）

- **快速进展型间质性肺病**：数周内气促加重、FVC 快速下降、HRCT 迅速进展（抗 MDA5 相关者风险高）→ 需紧急呼吸科/风湿科联合处理。
- **吞咽困难与误吸**：咽部肌群受累，可致吸入性肺炎、营养不良。
- **呼吸肌受累**：呼吸浅快、血气异常 → 呼吸衰竭风险。
- **心肌受累**：心律失常、心力衰竭、心肌酶持续升高而无骨骼肌解释。
- **恶性肿瘤**：成人新发皮肌炎，尤其抗 TIF1-γ 阳性、体重下降、不明原因贫血。
- **治疗相关风险**：大剂量激素与免疫抑制后的严重感染；激素性肌病可模拟疾病复发。

## 6. 检查策略（本科见习层面）

**必做**

- 肌酶谱：CK、LDH、AST、ALT、醛缩酶。
- 徒手肌力测试（MRC 分级）、吞咽功能评估。
- 肌炎抗体谱：抗 Jo-1、抗 PL-7、抗 PL-12、抗 EJ、抗 OJ、抗 MDA5、抗 Mi-2、抗 TIF1-γ、抗 SRP、抗 HMGCR。
- ANA、抗 dsDNA、抗 Scl-70、抗着丝点抗体（鉴别其他结缔组织病）。
- 甲状腺功能、电解质、肾功能、肝功能。
- 胸部 HRCT、肺功能（含 DLCO）。
- 感染筛查：结核、乙肝、丙肝、HIV。
- 肿瘤筛查：按年龄与性别进行（胸腹盆 CT、胃肠镜、乳腺/妇科检查等，由教师说明原则）。

**按需**

- 肌电图（肌源性损害）。
- 肌活检（光镜 + 酶组织化学；必要时免疫组化）：诊断不明确或需分型时。
- 心脏评估：心电图、心脏超声、心肌酶动态。
- 吞咽造影：有吞咽困难时。
- 恶性肿瘤筛查的强化评估：抗 TIF1-γ 阳性或临床高度怀疑时。

**检查选择的原则**：肌炎诊断需要“临床 + 肌酶 + 电生理/病理 + 抗体”综合判断；ILD 评估必须在治疗开始前完成，作为基线。

## 7. 治疗策略（原则层面，不做处方剂量指导）

1. **糖皮质激素**为一线基础治疗，按病情严重程度分层。
2. **免疫抑制剂**：激素应答不佳或需减少激素用量时联合（如甲氨蝶呤、硫唑嘌呤、吗替麦考酚酯、钙调神经磷酸酶抑制剂）。
3. **ILD 的处理**：ILD 是决定预后的关键，需呼吸科联合评估；快速进展型 ILD 需更积极的免疫抑制。
4. **难治/重症**：可考虑静脉免疫球蛋白、利妥昔单抗等，由专科判断。
5. **治疗前安全筛查**：结核、乙肝、丙肝、HIV；评估感染风险。
6. **支持治疗**：康复训练、吞咽评估与营养支持、误吸预防、疫苗接种。
7. **肿瘤筛查与随访**：成人皮肌炎诊断后应完成基线肿瘤筛查，并在随访中保持警惕。
8. **监测**：肌力、肌酶、肺功能与 HRCT、药物毒性、感染征象；注意激素性肌病与疾病复发的鉴别。

## 8. 常见错误

1. **把肌痛当作肌无力**：不测近端肌力，不区分疼痛与无力。
2. **仅凭 CK 升高诊断肌炎**：不鉴别药物性、甲状腺性、神经源性肌病。
3. **不做 ILD 评估**：只关注肌酶，遗漏决定预后的间质性肺病。
4. **不做肿瘤筛查**：成人新发皮肌炎未进行恶性肿瘤排查。
5. **把分类标准当作诊断标准**：不知道 2017 EULAR/ACR 标准的前提与局限。
6. **忽视吞咽功能**：不评估吞咽，导致误吸风险。
7. **抗体解读绝对化**：认为抗 Jo-1 阴性就不是抗合成酶综合征，或抗 MDA5 阳性就一定是快速进展型 ILD。
8. **混淆激素性肌病与疾病复发**：激素治疗后肌无力加重时，未鉴别肌病复发与激素性肌病。
