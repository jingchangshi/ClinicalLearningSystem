### 2.2 主分析（分组方案已锁定：7 个批次整群随机分配）

**分组方案不再二选一**：本 SAP 采用**唯一的 7 批次整群随机分配**——
预先固定 3 批入 ClinPath、4 批入常规 CBL，再随机选定哪 3 批入 ClinPath，
合法分配 **C(7,3) = 35 种**（`E5_01` §3.1）。**批次（7 个群）是主分析单位。**

#### 2.2.1 主分析：批次层面（cluster-level）分析

**主分析的统计量（预先固定的唯一主探索性统计量）**：

$$
T = \overline{\Delta}_{3} - \overline{\Delta}_{4},
\qquad
\Delta_b = \overline{Y_{T1}}_b - \overline{Y_{T0}}_b
$$

其中 $\Delta_b$ 是批次 $b$ 内学生的**平均前后变化**（以 D1 为基线），
$\overline{\Delta}_{3}$ 是 3 个 ClinPath 批次的 $\Delta_b$ 的**未加权均值**，
$\overline{\Delta}_{4}$ 是 4 个 CBL 批次的 $\Delta_b$ 的未加权均值。
**这是一个"批次层面的变化量均值差"**，与随机化单位（批次）一致。

**为什么选它作为唯一主探索性统计量（n = 7 个群）**：

1. **与随机化单位一致**：随机化发生在批次层面，统计量也必须以批次为单位，
   否则会把 7 个群当作 49 个独立观测（正是 §2.4 要避免的错误）；
2. **最小假设**：不假设群内相关结构、不依赖正确的标准误公式、不依赖大样本；
3. **可精确枚举**：合法分配只有 35 种，其精确零分布可直接算出（§3.5），
   这是 7 个群下唯一具备"精确推断"性质的路径；
4. **预先固定**：先写死统计量，就无人能在看到结果后挑选更"好看"的方法。

**主分析必须报告的批次层面量（每批一行，见 §2.2.5 表模板）**：
批次组别、分配人数、D1 均值、D6 均值、批内变化 $\Delta_b$、批内离散度（标准差/IQR）、
数据完整度（D1/D6 完成人数）。**只报告描述性批次层面量 + §3.5 的精确随机化 P 值**，
不做个体层面的确证性推断。

#### 2.2.2 批次固定效应**不可估**（关键事实）

整群分配下，一个批次只含一种组别，**组别列与批次哑变量列完全共线**：

```
若批次 1、2、3 全为对照组，批次 4、5、6、7 全为干预组：
    batch_1 = 1 ⟺ G = 0
    batch_4 = 1 ⟺ G = 1
   → 设计矩阵中 G 与 (batch 哑变量) 线性相关，rank 不足，系数不可识别。
```

因此本设计的模型里**不能同时放入 `batch` 固定效应与 `G`**；
能估的只有 `G`（+ 基线 `X`），批次信息只能通过**随机效应**或**整群稳健方差**进入。
这正是"整群分配无法分离批次效应与组别效应"的代数表达，也是**为什么主分析走批次层面**。

#### 2.2.3 辅助分析：小样本整群校正模型（**高度不稳定，仅辅助**）

在批次层面主分析之外，报告**一个**整群校正模型作为辅助，并**明确标注其不稳定性**：

```
模型（辅助，个体层面 + 整群稳健方差）：
    Y_T1 ~ G + Y_T0
    vcov = cluster-robust at batch（vcovCL / cov_type="cluster"）

模型（辅助，混合效应）：
    Y_T1 ~ G + Y_T0 + (1 | batch)
```

- **自由度现实**：整群稳健/混合模型的组别效应自由度由**群数**决定，约 **G − 2 = 5**
  （不是 49 名学生）；t₀.₉₇₅(df=5) = 2.571，是正态 1.960 的 1.31 倍；
- **7 个群时估计与区间都高度不稳定**：点估计与 CI 对模型设定、ICC、单批异常值都很敏感，
  **不得**据此做确证性宣称；
- **报告 ICC** 及其 95% CI（用于说明群内相关有多大）；
- **个体层面 HC3 不能替代**：见 §2.4。

#### 2.2.4 主分析的共同要求

- **假设检验**：双侧；报告点估计与 95% CI（bootstrap，**按群重抽样**）；
  **同时明确写出"P 值只有 k/35 的分辨率；p < 0.05 仅当观察分配 \|T\| 唯一最大（p = 1/35）时出现，仍属探索性信号"**（§3.5）；
- **不**对 P 值做"是否显著"的二元表述；同时报告效应量与 CI；
- **报告 ICC、群数（7）、每群人数（7）**——这三项必报；
- 分析脚本必须在数据锁定前写好并版本化（§9）。

### 2.3 为什么用 ANCOVA 而不是"增益的 t 检验"

| 方法 | 估计量 | 说明 |
| --- | --- | --- |
| 增益 t 检验 | mean(D6−D1) 的组间差 | 简单，但忽略基线不平衡；基线差异会直接进入估计 |
| **ANCOVA（主分析）** | 基线校正后的组间差 | 基线不平衡时更有效；在前后测相关 ρ 较高时功效更高 |

在随机化缺失的设计里，ANCOVA 还有一个重要优点：它把"基线差异"显式地放进模型，
而不是让它混进组间差。代价是它假设**组内回归斜率相同**（见 §2.5）。

### 2.4 HC3 是什么、不是什么（**更正**）

#### 2.4.1 HC3 的定义与适用范围

HC3 是**异方差稳健**协方差估计量的一种，属于 HC0–HC3 家族：

$$
\widehat{\mathrm{Var}}_{\mathrm{HC3}}(\hat\beta)
= (X'X)^{-1}\left(\sum_i \frac{e_i^2}{(1-h_i)^2}x_i x_i'\right)(X'X)^{-1}
$$

其中 $e_i$ 是 OLS 残差，$h_i$ 是杠杆值。相对于 HC0，它把每个残差平方放大了
$1/(1-h_i)^2$ 倍（HC1 只放大 $n/(n-k)$），因此在**小样本、高杠杆点**存在时
比 HC0/HC1 更保守。

**HC3 的适用范围是：观测相互独立、但误差方差不恒定。**
它**不假设**同方差，但**确实假设**观测之间独立。

#### 2.4.2 HC3 **不能**处理群内相关（原文错误，已更正）

| 说法 | 是否正确 |
| --- | --- |
| HC3 处理异方差 | ✅ 正确 |
| HC3 处理小样本杠杆 | ✅ 部分正确（更保守，但不解决群数问题） |
| **HC3 处理群内相关 / 整群设计** | ❌ **错误** |
| **HC3 与 cluster-robust 可以互换** | ❌ **错误** |

**为什么不能互换**：HC3 的"肉"矩阵是 $\sum_i e_i^2/(1-h_i)^2 \, x_i x_i'$，
**逐个观测**求和。群内相关意味着同一批次内学生的残差同向，交叉项
$e_i e_j\ (i \ne j, \text{同群})$ 不为零。HC3 把它们全部当作零丢弃，
于是方差被**系统性低估**，CI 过窄，P 值过小。

**正确做法**：整群设计用 **cluster-robust 方差**（`vcovCL` / `cov_type="cluster"`，
按群求和并包含群内交叉项）或**混合效应模型**。二者都不是 HC3 的变体。

#### 2.4.3 参考分布与演示实现的说明

- **正式分析**用 R `lmtest::coeftest(..., vcov = vcovHC(..., type = "HC3"))`
  或 Python `statsmodels` 的 `fit(cov_type="HC3")`；整群分析用 `vcovCL`。
  由第二名分析人员用另一套代码复算 $\beta_1$ 与 CI（双人复核）。
  两条实现路径的差异若超过 0.01 分，必须查明原因后才报告。
- **平台演示层的纯标准库实现**（`backend/app/services/demo_research.py`）：
  - HC3 的杠杆校正作用在**白化残差**上，即 $(e_i/(1-h_i))^2$，而不是 $e_i^2/(1-h_i)^2$
    （已在 `docs/ARCH.md` §18.3 与代码注释中固定）；
  - **参考分布用正态**，对应 statsmodels `use_t=False`；
  - **这个实现只用于合成演示页**。它与真实分析无关——真实分析不会使用
    演示层的纯 Python 实现，也不会用演示数据。演示层的参考分布选择
    **不构成**对本 SAP 的任何约束。
- 正式分析的参考分布：**主分析用 t 分布**（自由度按模型与群数确定）；
  整群小样本情形见 §3.2 的 CR2 / Satterthwaite 说明。

### 2.5 模型假设检查

| 假设 | 检查方式 | 违反时的处理 |
| --- | --- | --- |
| 线性（Y 与 X） | 残差 vs 拟合值图、局部加权平滑 | 加入 X 的样条项作为敏感性分析 |
| 组内斜率相同 | 加入 `G × X` 交互项检验 | 若交互显著，报告分层斜率并解释（不改变主要结论的表述方式） |
| **残差独立（整群设计）** | **计算 ICC；检查群内残差相关** | **整群设计必须按整群分析（批次层面主分析 §2.2.1；或 cluster-robust / 混合模型 §2.2.3）；不得只靠 HC3** |
| 残差正态 | QQ 图（描述性，不作检验门槛） | 大样本下 OLS 推断稳健；同时报告 bootstrap CI |
| 影响点 | Cook's distance、杠杆值 | 报告剔除影响点后的敏感性结果，不擅自删除 |

> **注意**：上表"残差独立"一行在整群设计中**几乎必然被违反**。
> 这不是一个可以"检查后再说"的假设，而是设计本身决定的结构性特征——
> 因此 §2.2.1 把**批次层面分析**定为**主分析**，§2.2.3 的整群稳健/混合模型
> 只作**辅助**（且高度不稳定），而不是"违反时才用的补救"。

## 3. 整群设计下的推断与降级规则

### 3.1 群数决定推断能力（不是学生人数）

整群设计的推断精度由**群数**决定，而不是由学生总数决定。本项目只有 **7 个批次**
（每臂 3–4 个）：

| 每臂群数 | 可用自由度（近似） | 能否做确证性组间检验 |
| --- | --- | --- |
| 1 | 0 | **否**（组别与群完全共线，效应不可估计） |
| 2–4 | 1–3 | **否**（cluster-robust SE 严重向下偏倚） |
| 5–9 | 4–8 | 仅在小样本校正下勉强可报告，须标注不确定性 |
| ≥ 10 | ≥ 9 | 可以，但仍须报告 ICC 与群数 |

**本项目：每臂只有 3–4 个批次**，落在"否"的区间。

| 3 | 0.20 | 2.20 | 9.5 | 21 |
| 4 | 0.05 | 1.30 | 21.5 | 28 |
| 4 | 0.20 | 2.20 | 12.7 | 28 |
| 7（全部） | 0.20 | 2.20 | 22.3 | 49 |

> **7 个批次全部用上、ICC = 0.20 时，全部 49 人的有效样本量只有约 22 人（每臂约 11 人）。**
> 这不是"功效略低"，而是**没有推断基础**。

### 3.2 群数很少时的强制规则（**必须写入预注册**）

> **每臂只有 3–4 个批次（总共只有 7 个批次）时，组间确证性检验不可信。**

具体地：

1. **常规 cluster-robust 标准误在群数少时向下偏倚**——CI 过窄、P 值过小，
   第一类错误率远高于名义 α。这是已知的有限样本性质，不是实现问题。
2. **自由度由群数决定**：组别效应的可用自由度约 G − 2 = **5**；
   t₀.₉₇₅(df=5) = **2.571**，是正态 1.960 的 **1.31 倍**，区间本就宽得多。
3. **精确随机化检验的 P 值只有 k/35 的分辨率**：合法分配只有 C(7,3) = 35 种；
   p = 1/35 ≈ 0.029 仅当观察分配 |T| 在 35 种中唯一最大，出现并列则 p ≥ 2/35 ≈ 0.057 > 0.05
   （**不得无条件宣称最小双侧 P 为 2/35**，§3.5）。
4. 可用的**小样本校正**：
   - **CR2** 校正（`clubSandwich` in R；`vcovCR` with `type="CR2"`）；
   - **Satterthwaite 自由度**（`lmerTest` / `clubSandwich` 的 `Satterthwaite`）；
   - **wild cluster bootstrap**（`fwildclusterboot` in R，`boottest`）。
5. **但即使做了这些校正**，7 个群仍不足以支撑一个可信的 P 值：
   - wild cluster bootstrap 在 **G = 7、Rademacher 权重**下只有 **2⁷ = 128 种符号组合**，
     双侧 P 值**不可能小于 2/128 = 0.0156**（`sample_size.py` §[6] 实测）。
     这不是实现问题，而是**信息量的上限**；
   - 校正能缓解偏倚，不能凭空创造信息。
6. 因此本 SAP 规定：

| 情形 | 报告方式 |
| --- | --- |
| 每臂 ≥ 10 个群 | 可报告主分析 P 值 + CI，并报告 ICC 与群数 |
| 每臂 5–9 个群 | 可用小样本校正后报告，但必须标注不确定性 |
| **每臂 2–4 个群（本项目）** | **按探索性报告**：ICC、群数、批次层面描述性量、bootstrap 区间、精确随机化 P 值；**不报告确证性 P 值**，不写"显著优于" |
| 每臂 1 个群 | **组间效应不可估计**；只报告单组前后变化与可行性指标 |

> **本项目的补充说明**：批次固定效应**不可估**（§2.2.2），因此**没有**个体层面的
> 固定效应模型可用作主分析；主分析是**批次层面**分析（§2.2.1）+ **精确随机化检验**（§3.5）。
> 批次层面的 cluster-robust / 混合模型只作**辅助**（§2.2.3），其自由度受群数限制（约 5），
> **不据此做确证性宣称**。

### 3.3 单一组别批次内**不能**估计组间效应

原文（v1）的敏感性分析写"每个批次内单独估计 $\beta_1$，报告森林图式汇总"。
这在**整群分配下是错的**：

- 整群分配中每个批次只含**一种**组别；
- 在一个只含一种组别的批次内，组别变量是常数，$\beta_1$ **不可识别**
  （设计矩阵中组别列与截距列完全共线）；
- 强行估计会得到无意义的系数（软件通常会丢弃该列或报奇异矩阵）。

**正确表述**：

| 情形 | 批次内分析是否可行 |
| --- | --- |
| 整群分配：一个批次只有一组 | **不可行**。批次内**不估计**组间效应；批次只用于描述、ICC 估计与**批次层面**汇总 |

- 本设计**不做**"森林图式批次内汇总"。可做的是：
  报告各批次的**组内前后变化**（单组前后差）、批内离散度与完整度，
  以及批次间的**变化量异质性**描述（即 §2.2.5 的每批次表）；
- 批次层面的 $\Delta_b$（3 批 vs 4 批）比较是主探索性统计量（§2.2.1），
  其推断走精确随机化检验（§3.5）。

### 3.5 精确随机化检验（**本设计的随机化推断，必须预先声明**）

本设计的随机化机制是**在 7 个批次中随机选定哪 3 个批次入 ClinPath**，
合法分配只有 **C(7,3) = 35 种**，因此可以做**精确**（非 Monte Carlo）随机化检验——
这是 7 个群下唯一具备"精确推断"性质的路径。

#### 3.5.1 随机化方案（零假设世界如何生成）

- 共有 **7 个批次**（b = 1,…,7），每批 7 人；
- **预先固定**：恰好 **3 个批次入 ClinPath、4 个批次入常规 CBL**；
- 从 7 个批次中**等概率**选出 3 个入 ClinPath：合法分配数
  $\binom{7}{3} = 35$ 种，每种概率 $1/35$；
- 这 **35 种分配**构成精确零分布，**可完全枚举**（不是 $35^7$，不是 Monte Carlo）。

> **这是与"批内置换"完全不同的方案**：随机化发生在**批次层面**（整群），
> 批次内的 7 名学生始终同组、不可交换。

#### 3.5.2 检验统计量

**主统计量：批次层面变化量均值差**（与 §2.2.1 的唯一主探索性统计量一致）

$$
T = \overline{\Delta}_{3} - \overline{\Delta}_{4},
\qquad
\Delta_b = \overline{Y_{T1}}_b - \overline{Y_{T0}}_b
$$

即 3 个 ClinPath 批次的平均批内变化，减去 4 个 CBL 批次的平均批内变化。
对 35 种分配逐一重算 $T$，得到精确零分布 $\{T^{(1)}, \dots, T^{(35)}\}$。

**双侧 P 值**：

$$
p = \frac{\#\{\,|T^{(k)}| \ge |T_{\text{obs}}|\,\}}{35}
$$

#### 3.5.3 P 值定义、分辨率与最小可及值（**必须写入预注册**）

**全项目只使用这一种双侧 P 值定义**（统计量、随机化机制与 P 值定义均在看到数据前固定）：

$$
p = \frac{\#\{\,k : |T^{(k)}| \ge |T_{\text{obs}}|\,\}}{35}
$$

| 项 | 值 |
| --- | --- |
| 合法分配数 | $\binom{7}{3} = 35$，每种概率 $1/35 \approx 0.0286$ |
| P 值取值 | $k/35$，$k \ge 1$（观察到的分配本身计入分子） |
| 最小可及 P | **取决于数据**：观察分配 $\vert T\vert$ 在 35 种中**唯一最大**时 $p = 1/35 \approx 0.029$；出现并列时 $p \ge 2/35 \approx 0.057$ |

- 两臂大小不等（3 vs 4），$T$ 的零分布一般**不对称**（互补分配的 $T$ 不是 $-T$），
  所以**不得无条件宣称最小双侧 P 为 2/35**。固定算例：批次层面变化 `[10, 9, 8, 0, 0, 0, 0]`、
  前三批为 ClinPath，独立穷举 35 种分配得 $p = 1/35$
  （`backend/tests/test_research_exact_permutation.py` 的独立穷举测试）；
- 因此 $p < 0.05$ **是可能的，但只在观察分配唯一最极端时出现**；这仍是 7 个群上的
  **探索性信号**，不构成确证性教学优效推断；不得用个体层面检验"凑"出一个显著结果；
- 若采用与上式不同的双侧 P 定义，必须在预注册中写明其定义与适用条件，**不得混用**；
- 计算实现：`backend/app/research/exact_permutation.py`（精确有理数运算，无近似）。

#### 3.5.4 报告要求

- 报告：**观测分配**、**$T_{\text{obs}}$**、**精确双侧 P**（分母 35）、
  以及 35 个 $T^{(k)}$ 的分布摘要（最小/最大/中位数）；
- 随机化脚本与种子一并归档，使 35 种枚举可完全复现；
- 与全部其他分析一样，在 7 个群规模下按**探索性**报告，**不据此写"显著优于"**；
- 若走**准实验路径**（`E5_01` §3.3），则**没有**随机化，**不报告**本检验。

### 3.6 研究定位：7 天窗口 + 49 人 → 探索性/可行性（**必须写入预注册与申报书**）

**结论：本研究的定位是探索性/可行性研究，不是确证性优效检验。**

两个各自独立、又叠加的限制：

| 限制 | 具体后果 |
| --- | --- |
| **样本量 49 人（3 批 vs 4 批 = 21 vs 28）** | 80% 功效最小可检出 d ≈ 0.87（未计设计效应）；对 d = 0.5 的名义功效仅约 0.34（§7.2） |
| **群数只有 7 个** | 精确随机化检验 P 值分辨率仅 1/35（p < 0.05 须观察分配 \|T\| 唯一最大）；wild bootstrap 下限 2/128 = 0.0156 |
| **7 天干预窗口** | 训练剂量上限约 3–4 例病例、15–20 步作答；真实效应可能低于可检出门槛（`E5_01` §5.4） |

**本研究能得出的**：可行性参数（招募率、保留率、评分者 ICC、批次 ICC、数据完整性）、
批次层面效应量的点估计与区间、训练轨迹与个性化执行度。
**本研究不能得出的**：对中等效应（d ≈ 0.5）的确证性结论；任何 α = 0.05 的"显著"宣称；
长期保持。

**要成为确证性研究，需要什么：**

| 条件 | 说明 |
| --- | --- |
| **更大的样本量** | 若目标为 80% 功效检出 d = 0.50，需 **64 人/组（合计 128 人）**，是 49 人的 2.6 倍 |
| **更长的干预窗口** | 需要足以产生可测量增益的暴露时间（须由预试验确定，7 天很可能不足） |
| **多中心或多届累积** | 单中心单届无法同时满足人数与群数要求；多届累积（每年 49 人，3–5 届）可接近确证性 |
| **先做预试验** | 估计前后测相关 ρ、提升量标准差、评分者 ICC 与批次 ICC，用于修订功效陈述 |
| **固定的评分者 ICC ≥ 0.75** | 否则主结局测量误差进一步侵蚀有效样本量（§7.5） |

## 4. 效应量与 95% 置信区间

| 结局 | 效应量 | 95% CI 来源 |
| --- | --- | --- |
| **主要结局（原始分，独立教师盲评）** | **批次层面变化量均值差 $T$**（§2.2.1）；辅助模型另报 $\beta_1$（§2.2.3） | 按群 bootstrap；**§3.5 精确随机化 P（分母 35）** |
| 主要结局（标准化） | 标准化 $T / SD_{\text{pooled}}$ | bootstrap 或解析近似 |
| 次要结局（六维度，同一份教师盲评） | 各维度批次层面 $T$（辅助模型另报 $\beta_1$） | 同主结局的方差方法 |
| **评分者一致性** | **ICC(2,1) 及 95% CI** | bootstrap |
| **批次 ICC** | **ICC 及 95% CI** | 混合模型方差成分；bootstrap |
| 二分类（完成率等） | 风险差 + RR | Wilson / bootstrap |
| **平台形成性评分** | 仅干预组内描述（均值、变化） | 不作组间推断 |

- **必须同时报告绝对效应（原始分）与相对效应（标准化）**，
  因为临床教师读原始分，方法学审稿人读标准化效应。
- 不报告"P < 0.05 即有效"的结论；CI 跨越 0 时表述为"未观察到可区分差异"。
- **本设计一律**：报告点估计与 bootstrap 区间，并明确写"探索性、不作确证性推断"（§3.2）；
  **同时写明精确随机化检验 P 值只有 k/35 的分辨率（p < 0.05 仅当观察分配 |T| 唯一最大）**（§3.5）。

## 5. 缺失数据

### 5.1 缺失类型与比例

| 缺失 | 典型原因 | 预计比例（`待确认`） |
| --- | --- | --- |
| D6 整例缺失 | 未参加考核、退出、轮转中断 | 10–20% |
| 单项维度缺失 | 评分表漏填 | < 5% |
| 平台过程数据缺失 | 技术故障、未提交 | 记录并报告 |
| 协变量缺失 | 基线（D1）分数缺失 | 极少；若发生，该例不进入 ITT |

### 5.2 主策略：多重插补（MI）

- **方法**：链式方程多重插补（MICE），**m = 20**；
- **插补模型**：`Y_T1 ~ Y_T0 + G + batch + 参与度 + 训练完成数`；
  不把 D6 之后的变量放入插补模型；
- **整群/批次结构**：插补模型必须含**批次**，并在**批次层面**处理缺失结构
  （同一批次的学生缺失往往相关）；
- **插补对象**：仅结局与协变量，不插补"是否参加"这一事实；
- **合并**：Rubin 规则；
- **诊断**：报告插补前后分布对比、FMI（缺失信息比例）。

### 5.3 敏感性：完整病例分析（CCA）

- 仅纳入同时有 D1 与 D6 者，重复主模型；
- 若 MI 与 CCA 结论不一致 → 报告两者，主要结论降级为"探索性"。

### 5.4 缺失比例阈值

- 主要结局缺失 ≤ 20%：按上述流程；
- 主要结局缺失 > 20%：主要结论降级，并在摘要中说明；
- 缺失 > 40%：不再做效果推断，只报告可行性。

> **49 人、7 批次规模下的提醒**：49 人的 20% 只有约 10 人。整群分配下
> ClinPath 臂只有 3 个批次（21 人）、CBL 臂 4 个批次（28 人），**每缺失 1 名学生**
> 都会改变其所在批次的均值（1/7）并改变该臂的批次均值（约 1/21 或 1/28）；
> 更重要的是，**缺失如果集中在某一个批次，会直接改变该批次的群均值**，
> 而群均值正是主要分析单位。对已经很低的可检出效应（d ≈ 0.87，未计设计效应）
> 影响不成比例。因此缺失必须**按批次、按人**报告，不能只报总百分比。

## 6. 多重比较

### 6.1 主要结局

**单一主要结局**（D6 独立教师盲评总分），**不做多重比较校正**。
名义 α = 0.05，但**精确 P 只有 k/35 的分辨率**：p < 0.05 仅当观察分配 |T| 唯一最大（p = 1/35），
否则 p ≥ 2/35 ≈ 0.057（§3.5）；即便 p = 1/35 也只是 7 个群上的探索性信号，报告时不得写"显著优于"。

### 6.2 次要结局（六维度）

六个维度构成一个"族"（family）。采用 **Benjamini–Hochberg（BH）**
控制错误发现率（FDR），q = 0.05。

- 报告**校正前**与**校正后**的 P 值，并标明哪一列用于推断；
- BH 只在六个维度**全部**可估计时执行；若某维度缺失过多，在 SAP 修订中说明；
- **本设计（每臂 3–4 个群）下，六维度一律只作描述性报告**（点估计 + bootstrap 区间），
  不报告 BH 校正后的 P 值——没有推断基础时，多重比较校正没有意义；
- 六维度即使报告，也必须同时写明"7 个群规模下为探索性、未校正的维度差异不作为结论"；
- **这是计划中的步骤，尚未执行**。任何"已校正"的表述都必须来自实际运行的分析脚本。

### 7.1 公式与逐步计算（真实运行输出）

两组等量、双侧 α、正态近似：

$$
n_{\text{每组}} = \frac{2\left(z_{1-\alpha/2} + z_{1-\beta}\right)^2}{d^2}
$$

代入 α = 0.05、power = 0.80：

```
z_(1-α/2) = 1.959964
z_(1-β)   = 0.841621
(z_(1-α/2)+z_(1-β))^2 = 7.848880
2*(...)^2 = 15.697759   → n/组 = 15.6978 / d^2
```

**t 分布修正**（小样本下更准确）：对每个 n 计算
$\text{power}(n) = \Phi\left(d\sqrt{n/2} - t_{1-\alpha/2,\,2n-2}\right)$，
向上搜索到 power ≥ 0.80。

### 7.5 主要结局的测量精度如何限制功效

样本量公式假设结局被**无误差地**测量。本研究的结局是教师盲评，必然有测量误差：

- 两位评分者的评分者一致性 **ICC(2,1)** 直接决定主结局的可靠性；
- 若 ICC = 0.90，测量误差较小；若 ICC = 0.60，主结局有相当大比例是噪声，
  **等效于损失大量有效样本**；
- 因此：**评分者一致性不是"附加结果"，而是样本量规划的一部分。**
  D1 之前的评分者校准必须报告校准 ICC，若校准 ICC < 0.75（`待确认`），
  必须先改进量表或培训，再启动研究。

> **本 SAP 不给 ICC 的数值假设**：没有真实评分数据，任何 ICC 数字都只能是
> 假设。校准阶段的实测值将用于修订功效陈述，并在预注册修订中记录。

## 9. 分析流程与可复现性

```
数据锁定（带时间戳的数据库备份 + 导出快照）
    ↓
数据字典校验（字段、取值范围、data_origin、population 只有一个取值）
    ↓
缺失模式描述（不查看组间比较）
    ↓
报告 ICC 与群数（这一步先于任何组间比较）
    ↓
主分析（批次层面分析 §2.2.1：每批次 Δ_b 与 T）
    ↓
精确随机化检验（§3.5，枚举全部 C(7,3)=35 种分配）
    ↓
辅助分析（§2.2.3 整群稳健/混合模型，明确标注高度不稳定）
    ↓
次要分析（六维度，只作描述性）
    ↓
敏感性分析 S1–S11
    ↓
双人复算（R 与 Python 各一遍，差异 > 0.01 分须查明）
    ↓
报告（含所有偏离、ICC、群数、定位声明、P 值定义与分辨率声明）
```

**版本控制要求**

- 分析脚本与分析数据集一并归档，附 SHA256；
- 平台版本 SHA 记录在研究日志中（因为 `learning_evidence_events` 的投影算法
  可能随版本变化）；
- 数据库迁移到 head 的记录随数据快照保存；
- 任何在数据锁定后修改的脚本，必须保留旧版本与修改理由。

- **批次 ICC 及 95% CI**；
- **评分者一致性 ICC(2,1) 及 95% CI**（主结局的测量精度）；
- 主要结局：批次层面 $T$、按群 bootstrap 区间、**精确随机化 P（分母 35）**；
- 辅助模型（§2.2.3）的 $\beta_1$ 与 CI，**明确标注高度不稳定**；
- 次要结局：六维度表（**仅描述性**）；
- **个性化执行度**：推荐病例数、推荐理由是否命中最弱维度、教师反馈次数（§7.2）；
- 敏感性分析汇总表（S1–S11）；
- 缺失数据表（**精确到人**，不只报百分比）；
- 平台运行事实：AI 调用次数、降级比例、故障次数（来自 `ai_invocations`）；

- 所有方案偏离；
- 明确声明：本研究**未**使用合成数据作为效果证据；
- 明确声明：研究定位（**探索性可行性**）、7 天窗口与 49 人规模、群数 7，
  以及**精确随机化检验 P 值只有 k/35 的分辨率（最小值取决于数据）**（§3.6、§3.5）。
