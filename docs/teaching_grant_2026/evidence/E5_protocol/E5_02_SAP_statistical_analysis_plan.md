## 2. 主要结局与主要分析

### 2.1 变量

```
Y   = T1 独立标准化病例总分（0–100，两位盲评教师）
X   = T0 独立标准化病例总分（0–100，同一量表）
G   = 组别（CBL = 0，ClinPath = 1）
B   = 轮转批次（分类）
```

### 2.2 主模型：基线校正的协方差分析（ANCOVA）

$$
Y_i = \beta_0 + \beta_1 G_i + \beta_2 X_i + \varepsilon_i
$$

- **效应量**：$\beta_1$，即"在基线相同的条件下，ClinPath 组相对 CBL 组的 T1 平均分差"，
  单位是**原始分（0–100）**，可直接向临床教师解释。
- **协变量**：基线 `X`（连续）。**批次 `B` 是否进入主模型，取决于最终确定的分配单位**
  （`E5_01` §4.3、本文件 §7.3），必须在预注册中二选一并写明：
  - **情形 1（批次嵌套组别）**：一个批次只有一种组别。此时批次与组别共线，
    **不能**同时放入主模型；主模型为 `Y ~ G + X`，批次只用于分层敏感性分析（S3）。
  - **情形 2（批次内小组分配）**：同一批次内同时存在两组。此时主模型为
    `Y ~ G + X + B`（批次固定效应），或使用混合模型 `Y ~ G + X + (1|B)`（S4）。
  → **本 SAP 的默认假设是情形 1**，与 `E5_01` §3.1 的整群分配一致。
  若教研室最终选择"班次内小组分配"（§7.3 的缓解路径 1），本节模型随之切换为情形 2，
  并须在预注册中明确记录这一选择及其理由。
- **稳健标准误**：使用 **HC3**（异方差稳健，leverage-corrected）。
  理由与实现细节见 §2.4。
- **假设检验**：双侧，α = 0.05。报告 $\beta_1$、95% CI、P 值。
- **不**对 P 值做"是否显著"的二元表述；同时报告效应量与 CI。

### 2.3 为什么用 ANCOVA 而不是"增益的 t 检验"

| 方法 | 估计量 | 说明 |
| --- | --- | --- |
| 增益 t 检验 | mean(T1−T0) 的组间差 | 简单，但忽略基线不平衡；基线差异会直接进入估计 |
| **ANCOVA（主分析）** | 基线校正后的组间差 | 基线不平衡时更有效；在前后测相关 ρ 较高时功效更高 |

在随机化缺失的设计里，ANCOVA 还有一个重要优点：它把"基线差异"显式地放进模型，
而不是让它混进组间差。代价是它假设**组内回归斜率相同**（见 §2.5）。

### 2.4 为什么用稳健标准误（HC3）

1. **异方差**：两组的基线分布与提升幅度可能不同，残差方差不齐；
   普通 OLS 标准误在此情形下会低估或高估不确定性。
2. **非正态残差**：0–100 量表有天花板/地板效应，残差可能偏斜；
   HC3 在小样本下比 HC0/HC1 表现更保守。
3. **实现方式**：
   - 平台侧已有一个**纯标准库**实现（`backend/app/services/demo_research.py`），
     供演示页使用；其 HC3 有两个容易写错的点，已在该文件注释中固定：
     杠杆校正作用在**白化残差**上，即 $(e_i/(1-h_i))^2$，而不是 $e_i^2/(1-h_i)^2$；
     参考分布用**正态**而非 t（与 statsmodels `cov_type="HC3"` 的默认一致）。
   - **正式分析**使用 R 的 `lmtest::coeftest(..., vcov = vcovHC(..., type = "HC3"))`
     或 Python `statsmodels` 的 `fit(cov_type="HC3")`，
     并由第二名分析人员用另一套代码复算 $\beta_1$ 与 CI（双人复核）。
   - 两条实现路径的差异若超过 0.01 分，必须查明原因后才报告。

> **注意**：HC3 的参考分布选择会改变 CI。据 `docs/ARCH.md` §18.3 记录的演示层实现说明：
> 用正态参考分布时 ANCOVA 95% CI 为 13.59–18.27；若误用 t 分布则为 13.54–18.32。
> （这两个数来自合成演示，只用于说明"参考分布会影响 CI"这一实现事实，
> 与本研究的效果无关。）正式分析必须在 SAP 中**预先声明**用哪一种，并全篇一致。

### 2.5 模型假设检查

| 假设 | 检查方式 | 违反时的处理 |
| --- | --- | --- |
| 线性（Y 与 X） | 残差 vs 拟合值图、局部加权平滑 | 加入 X 的样条项作为敏感性分析 |
| 组内斜率相同 | 加入 `G × X` 交互项检验 | 若交互显著，报告分层斜率并解释（不改变主要结论的表述方式） |
| 残差独立 | 按批次/班级检查 | 见 §3 的分层与混合模型 |
| 残差正态 | QQ 图（描述性，不作检验门槛） | 大样本下 OLS 推断稳健；同时报告 bootstrap CI |
| 影响点 | Cook's distance、杠杆值 | 报告剔除影响点后的敏感性结果，不擅自删除 |

## 3. 敏感性分析（全部预先声明）

| # | 分析 | 目的 | 实现 |
| --- | --- | --- | --- |
| S1 | **Welch t 检验**（对增益 T1−T0） | 不依赖 ANCOVA 的斜率同质假设 | 双侧，Welch–Satterthwaite 自由度 |
| S2 | **非参数替代**：Mann–Whitney U（对增益）+ Hodges–Lehmann 位移估计 | 抗偏态与离群值 | 报告位移估计与 95% CI |
| S3 | **按批次分层** | 排除批次混杂 | 每个批次内单独估计 $\beta_1$，报告森林图式汇总；批次内样本不足时只作描述 |
| S4 | **混合效应模型** | 处理整群相关 | `Y ~ G + X + (1 | 批次)`；报告 ICC |
| S5 | **完整病例分析** | 与多重插补比较 | 仅纳入有 T1 者 |
| S6 | **PP 分析** | 与 ITT 比较 | 按 §1 定义 |
| S7 | **bootstrap CI**（10000 次，分层重抽样） | 不依赖正态近似 | 报告百分位 CI |
| S8 | **剔除影响点** | 稳健性 | Cook's D > 4/n 者逐一剔除后重估 |
| S9 | **评分者分歧处理** | 测量稳健性 | 分别用 rater A、rater B、两人均分、裁决分重复主分析 |

> 敏感性分析**不用于挑选"更好看"的结果**。若 S1–S9 与主分析方向不一致，
> 在报告中并列呈现，并说明可能原因。

## 4. 效应量与 95% 置信区间

| 结局 | 效应量 | 95% CI 来源 |
| --- | --- | --- |
| 主要结局（原始分） | ANCOVA $\beta_1$ | HC3 稳健 CI |
| 主要结局（标准化） | 部分 $\eta^2$ 或标准化 $\beta_1 / SD_{\text{pooled}}$ | bootstrap 或解析近似 |
| 次要结局（六维度） | 各维度 ANCOVA $\beta_1$ | HC3 稳健 CI |
| 二分类（完成率等） | 风险差 + RR | Wilson / bootstrap |

- **必须同时报告绝对效应（原始分）与相对效应（标准化）**，
  因为临床教师读原始分，方法学审稿人读标准化效应。
- 不报告"P < 0.05 即有效"的结论；CI 跨越 0 时表述为"未观察到可区分差异"。

## 5. 缺失数据

### 5.1 缺失类型与比例

| 缺失 | 典型原因 | 预计比例（`待确认`） |
| --- | --- | --- |
| T1 整例缺失 | 未参加考核、退出、轮转中断 | 10–20% |
| 单项维度缺失 | 评分表漏填 | < 5% |
| 平台过程数据缺失 | 技术故障、未提交 | 记录并报告 |
| 协变量缺失 | 基线分数缺失 | 极少；若发生，该例不进入 ITT |

### 5.2 主策略：多重插补（MI）

- **方法**：链式方程多重插补（MICE），**m = 20**；
- **插补模型**：`T1 ~ T0 + G + 批次 + 参与度 + 训练完成数`；
  不把 T1 之后的变量放入插补模型；
- **插补对象**：仅结局与协变量，不插补"是否参加"这一事实；
- **合并**：Rubin 规则；
- **诊断**：报告插补前后分布对比、FMI（缺失信息比例）。

### 5.3 敏感性：完整病例分析（CCA）

- 仅纳入同时有 T0 与 T1 者，重复主模型；
- 若 MI 与 CCA 结论不一致 → 报告两者，主要结论降级为"探索性"。

### 5.4 缺失比例阈值

- 主要结局缺失 ≤ 20%：按上述流程；
- 主要结局缺失 > 20%：主要结论降级，并在摘要中说明；
- 缺失 > 40%：不再做效果推断，只报告可行性。

## 6. 多重比较

### 6.1 主要结局

**单一主要结局**（T1 总分），**不做多重比较校正**。α = 0.05。

### 6.2 次要结局（六维度）

六个维度构成一个"族"（family）。采用 **Benjamini–Hochberg（BH）**
控制错误发现率（FDR），q = 0.05。

- 报告**校正前**与**校正后**的 P 值，并标明哪一列用于推断；
- BH 只在六个维度**全部**可估计时执行；若某维度缺失过多，在 SAP 修订中说明；
- **这是计划中的步骤，尚未执行**。任何"已校正"的表述都必须来自实际运行的分析脚本。

### 6.3 过程指标与可行性指标

**不做**推断性检验，只作描述性报告（均值、比例、CI）。
理由：这些指标不是效果结局，检验它们会产生大量无意义的"显著"。

### 6.4 亚组

**不做**确证性亚组分析。若做探索性亚组（如按基线高低分层），
明确标注为"探索性、未校正、仅用于生成假设"。

## 7. 样本量可行性

### 7.1 公式与逐步计算（真实运行输出）

两组等量、双侧 α、正态近似：

$$
n_{\text{每组}} = \frac{2\left(z_{1-\alpha/2} + z_{1-\beta}\right)^2}{d^2}
$$

代入 α = 0.05、power = 0.80：

```
z_(1-α/2) = 1.959964
z_(1-β)   = 0.841621
(z_(1-α/2)+z_(1-β))^2 = 7.848880
2*(...)^2 = 15.697759   → n/组 = 15.6978 / d^2
```

**t 分布修正**（小样本下更准确）：对每个 n 计算
$\text{power}(n) = \Phi\left(d\sqrt{n/2} - t_{1-\alpha/2,\,2n-2}\right)$，
向上搜索到 power ≥ 0.80。

以下为 `python3.11 scripts/grant/sample_size.py` 的**实际输出**（2026-10-18 运行）：

```
--------------------------------------------------------------------------
[1] 正态近似 vs t 分布修正（d = 组间差值 / 变化量标准差）
--------------------------------------------------------------------------
    d      n/组(正态)     n/组(t修正)     +15%脱落      合计N
 0.40        98.11           99        117      234
 0.50        62.79           64         76      152
 0.60        43.60           45         53      106
 0.70        32.04           33         39       78
 0.80        24.53           26         31       62
 1.00        15.70           17         20       40
```

**读法**：若真实效应为 d = 0.50，需要 **64 人/组**；按 15% 脱落膨胀后
**76 人/组（合计 152 人）**。若效应为 d = 0.70，则 33 人/组、39 人/组（合计 78 人）。

### 7.3 整群分配的设计效应

若以轮转班次为分配单位（每群 m = 30 人），有效样本量需除以设计效应
$\text{DEFF} = 1 + (m-1)\rho$：

```
--------------------------------------------------------------------------
[3] 若按轮转班次整群分配（每群 m=30 人）
--------------------------------------------------------------------------
    d    rho       设计效应       群数/组       人数/组
 0.50   0.05       2.45          6        180
 0.50   0.10       3.90          9        270
 0.60   0.05       2.45          4        120
 0.60   0.10       3.90          6        180
 0.70   0.05       2.45          3         90
 0.70   0.10       3.90          5        150
```

**重要结论（必须在申报书中如实说明）**：
若每个班次 30 人、班次内 ICC = 0.05，要达到 d = 0.50 的 80% 功效，
需要**约 6 个班次/组（180 人/组）**。这在单中心一学年内通常不可行。

因此本研究采用**两条缓解路径**，并在预注册中固定：

1. **班次内小组分配**（若教学上可行）：同一班次内按学号随机分到两组，
   此时组别不嵌套于班次，设计效应接近 1，但必须评估**同班同伴外溢**
   （建议：两组在不同时间段使用平台，或约定不共享训练内容，并在局限中说明）；
2. **接受较低功效**：以方案 B（60/组）为主，明确声明本研究对 d < 0.5 的效应
   **功效不足**，结果按"探索性"解读。

> **`待院系与教研室确认`**：分配单位是"班次"还是"班次内小组"，
> 直接决定样本量能否达标。这是本方案最关键的可行性问题，必须在预注册前定下来。

### 7.4 ANCOVA 的效率

ANCOVA 相对"增益 t 检验"的方差比为 $(1+\rho)/2$（ρ = 前后测相关）：

```
--------------------------------------------------------------------------
[4] ANCOVA 相对变化量检验的效率比 sqrt((1+rho)/2)（rho = 前后测相关）
--------------------------------------------------------------------------
rho=0.30  方差比=0.650  n 可乘以 0.650  （例：t修正 64/组 → 42/组）
rho=0.50  方差比=0.750  n 可乘以 0.750  （例：t修正 64/组 → 48/组）
rho=0.70  方差比=0.850  n 可乘以 0.850  （例：t修正 64/组 → 55/组）
```

若效应以**原始分标准差**表达（更贴近临床教师的直觉），ANCOVA 规划用的
标准化效应为 $d_{\text{adj}} = d_{\text{raw}}/\sqrt{1-\rho^2}$：

```

--------------------------------------------------------------------------

  0.40  0.30   0.419           91        108
  0.40  0.50   0.462           75         89
  0.40  0.70   0.560           51         60
  0.50  0.30   0.524           59         70
  0.50  0.50   0.577           48         57
  0.50  0.70   0.700           33         39
  0.60  0.30   0.629           41         49
  0.60  0.50   0.693           34         40
  0.60  0.70   0.840           24         29
```

> **这些是示例计算。** d 的实际值未知，必须由**预试验或文献**估计。
> 上述数字只说明"不同假设下需要多少人"，不构成对本研究效应的预期。

### 7.5 效应量从哪来（诚实说明）

本 SAP **不提供**效应量估计，原因：

1. 没有真实前测数据；
2. 合成演示的效应是**输入参数**，不是观察结果（见 §8）；
3. 文献中的教育干预效应异质性大，直接套用不可靠。

**建议做法**：在正式研究前，用 1 个班次（约 30 人）做**单组预试验**，
估计前后测相关 ρ 与提升量的标准差，用于修订样本量；
预试验数据不进入主分析，并在预注册中说明。

Welch t / HC3-ANCOVA 的计算流程**可以跑通**，且页面、CSV 与离线工作簿同源可复现
（`backend/tests/test_demo_research.py` 逐项对齐，16 项通过）。

**它不能证明什么**：

- 不能证明 ClinPath 有效；
- 不能提供效应量或样本量依据；
- 不能作为"预试验结果"引用。

脚本 `scripts/grant/sample_size.py` §[5] 的实际输出也说明了这一点：

```
提升差 = 15.82   合并标准差 = 4.43   折算 d = 3.57
说明：该 d 是生成脚本**预先设定**的（nominal 6 vs 18），不是估计值，
      只能证明统计流程可跑通，不能用于样本量规划。
```

（d = 3.57 是一个**荒谬地大**的值，正好说明它是人为设定的，
而不是任何真实教学干预可能产生的效应。）

## 9. 分析流程与可复现性

```
数据锁定（带时间戳的数据库备份 + 导出快照）
    ↓
数据字典校验（字段、取值范围、data_origin）
    ↓
缺失模式描述（不查看组间比较）
    ↓
主要分析（ANCOVA + HC3）—— 先跑，不看其他
    ↓
次要分析（六维度 + BH）
    ↓
敏感性分析 S1–S9
    ↓
双人复算（R 与 Python 各一遍，差异 > 0.01 分须查明）
    ↓
报告（含所有偏离）
```

**版本控制要求**

- 分析脚本与分析数据集一并归档，附 SHA256；
- 平台版本 SHA 记录在研究日志中（因为 `learning_evidence_events` 的投影算法
  可能随版本变化）；
- 数据库迁移到 head 的记录随数据快照保存；
- 任何在数据锁定后修改的脚本，必须保留旧版本与修改理由。
