## 2. 主要结局与主要分析

### 2.1 变量与结局层级

```
Y   = T1 独立标准化病例总分（0–100，两位真实教师盲评）
X   = T0 独立标准化病例总分（0–100，同一量表、同一批评分教师）
G   = 组别（CBL = 0，ClinPath = 1）
B   = 轮转批次 / 班次（分类；整群设计下即为分组单位）
```

**结局层级（必须先读）**

| 来源 | 角色 | 进入主分析 |
| --- | --- | --- |
| **独立教师盲评（Y）** | **主要结局** | **是** |
| 平台形成性评分 `training_score_internal` | 过程指标 | **否** |
| AI 评分（如存在） | 过程指标，仅描述 | **否** |

- **平台形成性评分不是主要结局，也不是次要效果结局。** 它在对照组中不存在
  （对照组不开放训练模块），因此**无法做组间比较**；它只在干预组内描述训练轨迹。
- 任何把 `training_score_internal` 或 AI 评分当作"效果指标"的分析都不在本 SAP 内。
- 主要结局的测量误差由**评分者一致性（ICC）**决定，因此 ICC 是功效的约束条件（§7.6）。

### 2.2 主模型（**取决于分组单位，二选一，必须在预注册中写明**）

分组单位尚未确定（`E5_01` §3.1）。**下面两套模型互斥**，教研室选定设计后，
只有一套是主模型。**不得在看过结果之后切换。**

#### 2.2.1 设计 A（班次整群分配）：主模型 = 整群稳健 + 混合模型

一个班次只有一种组别，**组别与班次完全共线**，因此：

- **不能**把班次固定效应与组别同时放进模型（完全共线，不可识别）；
- **不能**用个体层面的 `Y ~ G + X` + HC3 作为主分析（忽略群内相关，见 §2.4）；
- **主分析**：

```
模型 A1（整群稳健方差）：
    Y ~ G + X                       # 固定效应部分
    vcov = cluster-robust at batch  # 方差部分

    R:      fit <- lm(Y ~ G + X, data = d)
            lmtest::coeftest(fit, vcov = sandwich::vcovCL(fit, cluster = ~ batch, type = "HC1"))
    Python: sm.OLS(y, X).fit(cov_type="cluster", cov_kwds={"groups": d["batch"]})

模型 A2（混合效应，并列主分析或首选敏感性分析）：
    Y ~ G + X + (1 | batch)
    R:      lme4::lmer(Y ~ G + X + (1 | batch), data = d)
    Python: statsmodels MixedLM.from_formula("Y ~ G + X", groups=d["batch"])
```

- **报告 ICC**（班次内相关系数）及其 95% CI。ICC 是本研究的重要产出：
  它告诉后续研究"按班次分配要付出多大代价"。
- **报告群数**（每臂班次数）与每群人数。这是判断推断可信度的前提，不是附录细节。
- 效应量：$\beta_1$（原始分，0–100 单位），附 95% CI。
- **群数少时的强制降级见 §3.2。**

#### 2.2.2 设计 B（班次内小组分配）：主模型 = 个体层面 + 班次效应

同一班次内同时存在两组，组别**不**嵌套于班次，个体层面模型是合法的：

```
模型 B1（固定效应，主分析）：
    Y ~ G + X + B          # B 为班次固定效应
    vcov = HC3（异方差稳健）

模型 B2（随机效应，敏感性分析）：
    Y ~ G + X + (1 | B)
```

- **仍需报告 ICC**：用来验证"设计效应接近 1"这一假设是否成立。
  若 ICC 明显大于 0（如 > 0.05），应改用整群稳健方差或模型 B2。
- **外溢敏感性分析**：按"对照组自报是否接触过平台训练内容"分层比较。
- **解释边界**：设计 B 估计的是**同一班次内**的组间差，不能外推为
  "整班采用新教学"的效果。申报书与论文中不得写成"整班改革有效"。

#### 2.2.3 两套模型的共同要求

- **假设检验**：双侧，α = 0.05。报告 $\beta_1$、95% CI、P 值。
- **不**对 P 值做"是否显著"的二元表述；同时报告效应量与 CI。
- **报告 ICC、群数、每群人数**——无论哪套模型，这三项都是必报项。
- 分析脚本必须在数据锁定前写好并版本化（§9）。

### 2.3 为什么用 ANCOVA 而不是"增益的 t 检验"

| 方法 | 估计量 | 说明 |
| --- | --- | --- |
| 增益 t 检验 | mean(T1−T0) 的组间差 | 简单，但忽略基线不平衡；基线差异会直接进入估计 |
| **ANCOVA（主分析）** | 基线校正后的组间差 | 基线不平衡时更有效；在前后测相关 ρ 较高时功效更高 |

在随机化缺失的设计里，ANCOVA 还有一个重要优点：它把"基线差异"显式地放进模型，
而不是让它混进组间差。代价是它假设**组内回归斜率相同**（见 §2.5）。

### 2.4 HC3 是什么、不是什么（**更正**）

#### 2.4.1 HC3 的定义与适用范围

HC3 是**异方差稳健**协方差估计量的一种，属于 HC0–HC3 家族：

$$
\widehat{\mathrm{Var}}_{\mathrm{HC3}}(\hat\beta)
= (X'X)^{-1}\left(\sum_i \frac{e_i^2}{(1-h_i)^2}x_i x_i'\right)(X'X)^{-1}
$$

其中 $e_i$ 是 OLS 残差，$h_i$ 是杠杆值。相对于 HC0，它把每个残差平方放大了
$1/(1-h_i)^2$ 倍（HC1 只放大 $n/(n-k)$），因此在**小样本、高杠杆点**存在时
比 HC0/HC1 更保守。

**HC3 的适用范围是：观测相互独立、但误差方差不恒定。**
它**不假设**同方差，但**确实假设**观测之间独立。

#### 2.4.2 HC3 **不能**处理群内相关（原文错误，已更正）

| 说法 | 是否正确 |
| --- | --- |
| HC3 处理异方差 | ✅ 正确 |
| HC3 处理小样本杠杆 | ✅ 部分正确（更保守，但不解决群数问题） |
| **HC3 处理群内相关 / 整群设计** | ❌ **错误** |
| **HC3 与 cluster-robust 可以互换** | ❌ **错误** |

**为什么不能互换**：HC3 的"肉"矩阵是 $\sum_i e_i^2/(1-h_i)^2 \, x_i x_i'$，
**逐个观测**求和。群内相关意味着同一班次内学生的残差同向，交叉项
$e_i e_j\ (i \ne j, \text{同群})$ 不为零。HC3 把它们全部当作零丢弃，
于是方差被**系统性低估**，CI 过窄，P 值过小。

**正确做法**：整群设计用 **cluster-robust 方差**（`vcovCL` / `cov_type="cluster"`，
按群求和并包含群内交叉项）或**混合效应模型**。二者都不是 HC3 的变体。

#### 2.4.3 参考分布与演示实现的说明

- **正式分析**用 R `lmtest::coeftest(..., vcov = vcovHC(..., type = "HC3"))`
  或 Python `statsmodels` 的 `fit(cov_type="HC3")`；整群分析用 `vcovCL`。
  由第二名分析人员用另一套代码复算 $\beta_1$ 与 CI（双人复核）。
  两条实现路径的差异若超过 0.01 分，必须查明原因后才报告。
- **平台演示层的纯标准库实现**（`backend/app/services/demo_research.py`）：
  - HC3 的杠杆校正作用在**白化残差**上，即 $(e_i/(1-h_i))^2$，而不是 $e_i^2/(1-h_i)^2$
    （已在 `docs/ARCH.md` §18.3 与代码注释中固定）；
  - **参考分布用正态**，对应 statsmodels `use_t=False`；
  - **这个实现只用于合成演示页**。它与真实分析无关——真实分析不会使用
    演示层的纯 Python 实现，也不会用演示数据。演示层的参考分布选择
    **不构成**对本 SAP 的任何约束。
- 正式分析的参考分布：**主分析用 t 分布**（自由度按模型与群数确定）；
  整群小样本情形见 §3.2 的 CR2 / Satterthwaite 说明。

### 2.5 模型假设检查

| 假设 | 检查方式 | 违反时的处理 |
| --- | --- | --- |
| 线性（Y 与 X） | 残差 vs 拟合值图、局部加权平滑 | 加入 X 的样条项作为敏感性分析 |
| 组内斜率相同 | 加入 `G × X` 交互项检验 | 若交互显著，报告分层斜率并解释（不改变主要结论的表述方式） |
| **残差独立（整群设计）** | **计算 ICC；检查群内残差相关** | **整群设计必须用 cluster-robust 或混合模型（§2.2.1）；不得只靠 HC3** |
| 残差正态 | QQ 图（描述性，不作检验门槛） | 大样本下 OLS 推断稳健；同时报告 bootstrap CI |
| 影响点 | Cook's distance、杠杆值 | 报告剔除影响点后的敏感性结果，不擅自删除 |

> **注意**：上表"残差独立"一行在整群设计中**几乎必然被违反**。
> 这不是一个可以"检查后再说"的假设，而是设计本身决定的结构性特征——
> 因此 §2.2.1 把整群稳健/混合模型定为**主分析**，而不是"违反时才用的补救"。

## 3. 整群设计下的推断与降级规则

### 3.1 群数决定推断能力（不是学生人数）

整群设计的推断精度由**群数**决定，而不是由学生总数决定。每臂 2–4 个班次时：

| 每臂群数 | 可用自由度（近似） | 能否做确证性组间检验 |
| --- | --- | --- |
| 1 | 0 | **否**（组别与群完全共线，效应不可估计） |
| 2–4 | 1–3 | **否**（cluster-robust SE 严重向下偏倚） |
| 5–9 | 4–8 | 仅在小样本校正下勉强可报告，须标注不确定性 |
| ≥ 10 | ≥ 9 | 可以，但仍须报告 ICC 与群数 |

`scripts/grant/sample_size.py` §[3b] 的实际计算（每群 25 人）：

| 群数/组 | ICC | 设计效应 | 有效 n/组 | 名义总人数/组 |
| --- | --- | --- | --- | --- |
| 2 | 0.05 | 2.20 | 22.7 | 50 |
| 2 | 0.20 | 5.80 | 8.6 | 50 |
| 3 | 0.20 | 5.80 | 12.9 | 75 |
| 4 | 0.20 | 5.80 | 17.2 | 100 |

> **2 个班次/组、每班 25 人、ICC = 0.20 时，每臂有效样本量只有约 9 人。**
> 这不是"功效略低"，而是**没有推断基础**。

### 3.2 群数很少时的强制规则（**必须写入预注册**）

> **每臂只有 2–4 个班次时，组间确证性检验不可信。**

具体地：

1. **常规 cluster-robust 标准误在群数少时向下偏倚**——CI 过窄、P 值过小，
   第一类错误率远高于名义 α。这是已知的有限样本性质，不是实现问题。
2. 可用的**小样本校正**：
   - **CR2** 校正（`clubSandwich` in R；`vcovCR` with `type="CR2"`）；
   - **Satterthwaite 自由度**（`lmerTest` / `clubSandwich` 的 `Satterthwaite`）；
   - **wild cluster bootstrap**（`fwildclusterboot` in R，`boottest`）。
3. 但**即使做了这些校正**，每臂 2–3 个群时仍不足以支撑一个可信的 P 值。
   校正能缓解偏倚，不能凭空创造信息。
4. 因此本 SAP 规定：

| 情形 | 报告方式 |
| --- | --- |
| 每臂 ≥ 5 个群 | 可报告主分析 P 值 + CI，并报告 ICC 与群数 |
| 每臂 2–4 个群 | **按探索性报告**：ICC、群数、描述性组间差、bootstrap 区间；**不报告确证性 P 值**，不写"显著优于" |
| 每臂 1 个群 | **组间效应不可估计**（见 §3.3）；只报告单组前后变化与可行性指标 |

### 3.3 单一组别批次内**不能**估计组间效应（**原文错误，已删除**）

原文的敏感性分析 S3 写"每个批次内单独估计 $\beta_1$，报告森林图式汇总"。
这在**设计 A（整群分配）下是错的**：

- 设计 A 中每个班次只含**一种**组别；
- 在一个只含一种组别的班次内，组别变量是常数，$\beta_1$ **不可识别**
  （设计矩阵中组别列与截距列完全共线）；
- 强行估计会得到无意义的系数（软件通常会丢弃该列或报奇异矩阵）。

**正确表述**：

| 情形 | 批次内分析是否可行 |
| --- | --- |
| 设计 A（整群）：一个批次只有一组 | **不可行**。批次内**不估计**组间效应；批次只用于描述与 ICC 估计 |
| 设计 B（班内小组）：一个批次含两组 | 可行，但每个批次内样本很小；只作描述性展示，不作推断 |

- 设计 A 下**不做**"森林图式批次内汇总"。可做的是：
  报告各批次的**组内前后变化**（单组前后差），以及批次间的**变化量异质性**描述。
- 设计 B 下可按批次展示组间差，但明确标注"描述性、样本量小、不作推断"。

### 3.4 敏感性分析（全部预先声明）

| # | 分析 | 目的 | 实现 | 适用设计 |
| --- | --- | --- | --- | --- |
| S1 | **Welch t 检验**（对增益 T1−T0） | 不依赖 ANCOVA 的斜率同质假设 | 双侧，Welch–Satterthwaite 自由度 | B；A 下仅描述性 |
| S2 | **非参数替代**：Mann–Whitney U（对增益）+ Hodges–Lehmann 位移估计 | 抗偏态与离群值 | 报告位移估计与 95% CI | B；A 下仅描述性 |
| S3 | **整群稳健方差**（`vcovCL`，按 batch） | **整群设计的主分析**（设计 A） | `lmtest::coeftest` + `sandwich::vcovCL`；或 statsmodels `cov_type="cluster"` | **A（主分析）** |
| S4 | **混合效应模型** `Y ~ G + X + (1|batch)` | 处理整群相关，估计 ICC | `lme4::lmer` / `MixedLM`；报告 ICC 与方差成分 | A（并列主分析）、B（敏感性） |
| S5 | **CR2 / Satterthwaite / wild cluster bootstrap** | 群数少时的小样本校正 | `clubSandwich::vcovCR(type="CR2")`；`fwildclusterboot::boottest` | A（群数 2–4 时**必做**，但结果仍按探索性报告） |
| S6 | **完整病例分析** | 与多重插补比较 | 仅纳入有 T1 者 | A、B |
| S7 | **PP 分析** | 与 ITT 比较 | 按 §1 定义 | A、B |
| S8 | **bootstrap CI**（10000 次，**按群**重抽样） | 不依赖正态近似 | 整群设计必须按群重抽样，不能按个体 | A、B |
| S9 | **剔除影响点** | 稳健性 | Cook's D > 4/n 者逐一剔除后重估 | A、B |
| S10 | **评分者分歧处理** | 测量稳健性 | 分别用 rater A、rater B、两人均分、裁决分重复主分析 | A、B |
| S11 | **外溢分层**（设计 B） | 估计污染程度 | 按对照组自报是否接触干预内容分层 | B |

> 敏感性分析**不用于挑选"更好看"的结果**。若 S1–S11 与主分析方向不一致，
> 在报告中并列呈现，并说明可能原因。
>
> **S3 与 S4 在设计 A 下是主分析，不是"敏感性分析"**——列入本表是为了完整性，
> 不代表它们可以被主分析忽略。设计 A 的"主分析"就是 S3 + S4，没有个体层面 HC3 的位置。

## 4. 效应量与 95% 置信区间

| 结局 | 效应量 | 95% CI 来源 |
| --- | --- | --- |
| **主要结局（原始分，独立教师盲评）** | ANCOVA $\beta_1$（整群稳健或混合模型，按 §2.2） | cluster-robust CI；群数少时 bootstrap（按群重抽样） |
| 主要结局（标准化） | 标准化 $\beta_1 / SD_{\text{pooled}}$ | bootstrap 或解析近似 |
| 次要结局（六维度，同一份教师盲评） | 各维度 ANCOVA $\beta_1$ | 同主结局的方差方法 |
| **评分者一致性** | **ICC(2,1) 及 95% CI** | bootstrap |
| **班次 ICC** | **ICC 及 95% CI** | 混合模型方差成分；bootstrap |
| 二分类（完成率等） | 风险差 + RR | Wilson / bootstrap |
| **平台形成性评分** | 仅干预组内描述（均值、变化） | 不作组间推断 |

- **必须同时报告绝对效应（原始分）与相对效应（标准化）**，
  因为临床教师读原始分，方法学审稿人读标准化效应。
- 不报告"P < 0.05 即有效"的结论；CI 跨越 0 时表述为"未观察到可区分差异"。
- **群数 ≤ 4/臂时**：报告点估计与 bootstrap 区间，并明确写"探索性、不作确证性推断"（§3.2）。

## 5. 缺失数据

### 5.1 缺失类型与比例

| 缺失 | 典型原因 | 预计比例（`待确认`） |
| --- | --- | --- |
| T1 整例缺失 | 未参加考核、退出、轮转中断 | 10–20% |
| 单项维度缺失 | 评分表漏填 | < 5% |
| 平台过程数据缺失 | 技术故障、未提交 | 记录并报告 |
| 协变量缺失 | 基线分数缺失 | 极少；若发生，该例不进入 ITT |

### 5.2 主策略：多重插补（MI）

- **方法**：链式方程多重插补（MICE），**m = 20**；
- **插补模型**：`T1 ~ T0 + G + 批次 + 参与度 + 训练完成数`；
  不把 T1 之后的变量放入插补模型；
- **整群设计**：插补模型必须含**班次**，并在**班次层面**处理缺失结构
  （同一班次的学生缺失往往相关）；
- **插补对象**：仅结局与协变量，不插补"是否参加"这一事实；
- **合并**：Rubin 规则；
- **诊断**：报告插补前后分布对比、FMI（缺失信息比例）。

### 5.3 敏感性：完整病例分析（CCA）

- 仅纳入同时有 T0 与 T1 者，重复主模型；
- 若 MI 与 CCA 结论不一致 → 报告两者，主要结论降级为"探索性"。

### 5.4 缺失比例阈值

- 主要结局缺失 ≤ 20%：按上述流程；
- 主要结局缺失 > 20%：主要结论降级，并在摘要中说明；
- 缺失 > 40%：不再做效果推断，只报告可行性。

## 6. 多重比较

### 6.1 主要结局

**单一主要结局**（T1 独立教师盲评总分），**不做多重比较校正**。α = 0.05。

### 6.2 次要结局（六维度）

六个维度构成一个"族"（family）。采用 **Benjamini–Hochberg（BH）**
控制错误发现率（FDR），q = 0.05。

- 报告**校正前**与**校正后**的 P 值，并标明哪一列用于推断；
- BH 只在六个维度**全部**可估计时执行；若某维度缺失过多，在 SAP 修订中说明；
- **群数 ≤ 4/臂时，六维度一律只作描述性报告**（点估计 + bootstrap 区间），
  不报告 BH 校正后的 P 值——没有推断基础时，多重比较校正没有意义；
- **这是计划中的步骤，尚未执行**。任何"已校正"的表述都必须来自实际运行的分析脚本。

### 6.3 过程指标与可行性指标

**不做**推断性检验，只作描述性报告（均值、比例、CI）。
理由：这些指标不是效果结局，检验它们会产生大量无意义的"显著"。

**平台形成性评分属于本类**：只在干预组内描述，不做组间比较（§2.1）。

### 6.4 亚组

**不做**确证性亚组分析。若做探索性亚组（如按基线高低分层），
明确标注为"探索性、未校正、仅用于生成假设"。

## 7. 样本量可行性

> **本节所有 d 都是示例假设。** 本 SAP **不提供**本研究的效应量估计
> （理由见 §7.6）。下表的含义是"**如果**真实效应是 d，需要多少人"，
> 不是"我们预计效应是 d"。任何把下表数字写成"预期效果"的做法都是对文件的误用。
>
> **特别地：合成演示数据折算出的 d = 3.57 是生成器参数，禁止使用**（§8）。

### 7.1 公式与逐步计算（真实运行输出）

两组等量、双侧 α、正态近似：

$$
n_{\text{每组}} = \frac{2\left(z_{1-\alpha/2} + z_{1-\beta}\right)^2}{d^2}
$$

代入 α = 0.05、power = 0.80：

```
z_(1-α/2) = 1.959964
z_(1-β)   = 0.841621
(z_(1-α/2)+z_(1-β))^2 = 7.848880
2*(...)^2 = 15.697759   → n/组 = 15.6978 / d^2
```

**t 分布修正**（小样本下更准确）：对每个 n 计算
$\text{power}(n) = \Phi\left(d\sqrt{n/2} - t_{1-\alpha/2,\,2n-2}\right)$，
向上搜索到 power ≥ 0.80。

以下为 `python3.11 -I scripts/grant/sample_size.py` 的**实际输出**（2026-10-18 修订后重跑）：

```
--------------------------------------------------------------------------
[1] 正态近似 vs t 分布修正（d = 组间差值 / 变化量标准差；d 为示例假设）
--------------------------------------------------------------------------
    d      n/组(正态)     n/组(t修正)     +15%脱落      合计N
 0.40        98.11           99        117      234
 0.50        62.79           64         76      152
 0.60        43.60           45         53      106
 0.70        32.04           33         39       78
 0.80        24.53           26         31       62
 1.00        15.70           17         20       40
```

**读法**：**如果**真实效应为 d = 0.50，需要 **64 人/组**；按 15% 脱落膨胀后
**76 人/组（合计 152 人）**。**如果**效应为 d = 0.70，则 33 人/组、39 人/组（合计 78 人）。
这两个"如果"都不是预测——真实效应未知（§7.6）。

### 7.2 若可招募人数固定，能检出多大效应（可行性反推）

```

--------------------------------------------------------------------------

    60          0.511        0.776        0.904        0.968

读法：每年 20–50 名学生、两组等分即 10–25 人/组，对应最小可检出 d ≈ 1.25–0.79。
      25 人/组只能稳定检出 d≈0.80 的大效应（这正是 2 臂 RCT 在本规模下的上限）；
      想检出 d=0.50 需要 64 人/组，是当前规模的 2.5 倍以上。

```

**与 `E5_01` §4.3.2 的方案对应**：

| 方案 | 结构 | 每组 n | 80% 功效最小可检出 d | 若真实 d = 0.5 的功效 | 能否确证 |
| --- | --- | --- | --- | --- | --- |
| E1 | 单组前后测 + 历史/同期对照 | 20–50（单组） | 不适用（无同期对照） | 不适用 | 否 |

| E3 | 阶梯楔形，4–6 轮转 | 10–25/轮转 | 0.79–1.25 | 0.40–0.16 | 否（轮转数少） |
| E4 | 多年累积（3–5 年） | 累积 45–90+ | 0.59–0.42 | 0.65–0.92 | **可能**，取决于最终群数 |

> **25 人/组的 80% 功效最小可检出 d = 0.792；15 人/组为 1.023；10 人/组为 1.253。**
> 也就是说，在本项目最乐观的单年规模（每年 50 人、两组各 25 人）下，
> 两臂设计**只能稳定检出 d ≈ 0.8 的大效应**，对 d = 0.5 的中等效应功效只有 0.40；
> 若每年只有 20–30 人（每组 10–15 人），连 d = 1.0 的效应都难以稳定检出。
> 这是本 SAP 反复强调"定位为可行性 + 信号生成"的算术依据。

### 7.4 ANCOVA 的效率

ANCOVA 相对"增益 t 检验"的方差比为 $(1+\rho)/2$（ρ = 前后测相关）：

```

--------------------------------------------------------------------------

rho=0.50  方差比=0.750  n 可乘以 0.750  （例：t修正 64/组 → 48/组）
rho=0.70  方差比=0.850  n 可乘以 0.850  （例：t修正 64/组 → 55/组）
```

标准化效应为 $d_{\text{adj}} = d_{\text{raw}}/\sqrt{1-\rho^2}$：

### 7.5 主要结局的测量精度如何限制功效

样本量公式假设结局被**无误差地**测量。本研究的结局是教师盲评，必然有测量误差：

- 两位评分者的评分者一致性 **ICC(2,1)** 直接决定主结局的可靠性；
- 若 ICC = 0.90，测量误差较小；若 ICC = 0.60，主结局有相当大比例是噪声，
  **等效于损失大量有效样本**；
- 因此：**评分者一致性不是"附加结果"，而是样本量规划的一部分。**
  T0 之前的评分者校准必须报告校准 ICC，若校准 ICC < 0.75（`待确认`），
  必须先改进量表或培训，再启动研究。

> **本 SAP 不给 ICC 的数值假设**：没有真实评分数据，任何 ICC 数字都只能是
> 假设。校准阶段的实测值将用于修订功效陈述，并在预注册修订中记录。

### 7.6 效应量从哪来（诚实说明）

本 SAP **不提供**效应量估计，原因：

1. 没有真实前测数据；
2. 合成演示的效应是**输入参数**，不是观察结果（见 §8）；
3. 文献中的教育干预效应异质性大，直接套用不可靠。

**允许的效应量来源（按优先级）**：

1. **本单位的预试验**（1 个班次，单组前后测）：估计前后测相关 ρ、
   提升量标准差、评分者 ICC。这是最可信的来源。
2. **同类教学干预的已发表文献**：只作为**区间假设**使用，并明确标注
   "假设、待本地预试验确认"；不得把文献的单一数字当作本研究的预期效应。
3. **临床/教学判断的合理范围**：由教研室给出"最小有教学意义的差值"（MCID），
   这比"预期效应"更适合指导本研究——它决定的是"值得检出多大的差"。

**禁止的来源**：合成演示数据（§8）。

预试验数据不进入主分析，并在预注册中说明。

