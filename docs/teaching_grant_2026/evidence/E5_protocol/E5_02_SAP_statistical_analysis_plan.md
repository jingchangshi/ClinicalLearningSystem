## 2. 主要结局与主要分析

### 2.1 变量与结局层级

```
Y    = D6 独立标准化病例总分（0–100，两位真实教师盲评）
X    = D1 独立标准化病例总分（0–100，同一量表、同一批评分教师）
G    = 组别（CBL = 0，ClinPath = 1）
B    = 批次（分类；7 个批次）
N    = 49（主研究总体 = 7 批 × 7 人）
```

**结局层级（必须先读）**

| 来源 | 角色 | 进入主分析 |
| --- | --- | --- |
| **独立教师盲评（Y）** | **主要结局** | **是** |
| 平台形成性评分 `training_score_internal` | 过程指标 | **否** |
| AI 评分（如存在） | 过程指标，仅描述 | **否** |

- **平台形成性评分不是主要结局，也不是次要效果结局。** 它在对照组中不存在
  （对照组不开放训练模块），因此**无法做组间比较**；它只在干预组内描述训练轨迹。
- 任何把 `training_score_internal` 或 AI 评分当作"效果指标"的分析都不在本 SAP 内。
- 主要结局的测量误差由**评分者一致性（ICC）**决定，因此 ICC 是功效的约束条件（§7.6）。

### 2.2 主模型（**取决于分组方案，二选一，必须在预注册中写明**）

分组方案由教研室在 D1 前书面确定（`E5_01` §3）。**下面两套模型互斥**，
教研室选定方案后，只有一套是主模型。**不得在看过结果之后切换。**

#### 2.2.1 方案 A（7 批次整群分配）：主模型 = 整群稳健 + 混合模型

一个批次只有一种组别，**组别与批次完全共线**，因此：

- **不能**把批次固定效应与组别同时放进模型（完全共线，不可识别）；
- **不能**用个体层面的 `Y ~ G + X` + HC3 作为主分析（忽略群内相关，见 §2.4）；
- **主分析**：

```
模型 A1（整群稳健方差）：
    Y ~ G + X                       # 固定效应部分
    vcov = cluster-robust at batch  # 方差部分

    R:      fit <- lm(Y ~ G + X, data = d)
            lmtest::coeftest(fit, vcov = sandwich::vcovCL(fit, cluster = ~ batch, type = "HC1"))
    Python: sm.OLS(y, X).fit(cov_type="cluster", cov_kwds={"groups": d["batch"]})

模型 A2（混合效应，并列主分析或首选敏感性分析）：
    Y ~ G + X + (1 | batch)
    R:      lme4::lmer(Y ~ G + X + (1 | batch), data = d)
    Python: statsmodels MixedLM.from_formula("Y ~ G + X", groups=d["batch"])
```

- **报告 ICC**（批次内相关系数）及其 95% CI。
- **报告群数**（7 个批次；每臂 3–4 个）与每群人数（7 人）。这是判断推断可信度的前提。
- 效应量：$\beta_1$（原始分，0–100 单位），附 95% CI。
- **只有 7 个群时的强制降级见 §3.2。**

#### 2.2.2 方案 B（每批 7 人内部 3+4 随机）：**推荐**主模型 = 个体层面 + 批次固定效应

同一批次内同时存在两组，组别**不**嵌套于批次，个体层面模型是合法的：

```
模型 B1（批次固定效应，主分析）：
    Y_T1 ~ G + Y_T0 + batch + form_T1      # batch = 7 个批次 → 6 个哑变量
    vcov = HC3（异方差稳健）

模型 B2（随机效应，敏感性分析）：
    Y_T1 ~ G + Y_T0 + (1 | B)
```

> **`form_T1`（T1 所用考核病例）为什么必须进模型**：两份独立考核病例
> CASE-A01（未分化多关节炎）与 CASE-A02（成人 Still 病伴 MAS 风险）**难度不可比**
> （证据见 `workpackages/A_cases/A04_assessment_quality_control.md` §1）。
> 若所有学生 T0 固定用 A01、T1 固定用 A02，"T1 − T0"会同时包含**学习增益**与
> **病例难度差**，且该难度差与时间点完全共线、无法从数据中分离。
>
> 处置（`A04` §2 的交叉反平衡设计）：每名学生在 T0 与 T1 各做**不同**的一例，
> 顺序 X（T0=A01, T1=A02）与顺序 Y（T0=A02, T1=A01）在**每组、每批次内**尽量均分，
> 使难度差在组间抵消；同时在主模型中加入 `form_T1`（T1 所用病例，二分类）吸收残余差异。
>
> - `form_T1` 使参数个数由 9 增至 **10**，残差自由度由 40 降至 **39**。
> - 若教研室最终**不采用**反平衡（例如固定题本顺序），则 `form_T1` 与 `G` 的
>   可分离性取决于是否与组别共线；此时该设计**不可用**，必须在预注册中说明并
>   把"病例难度差"列为无法排除的混杂。
> - 是否采用反平衡须在 T0 前确定，并写入预注册；**不得在看过结果后更改**。

**样本量与自由度（实测，`sample_size.py` §[6]）**

| 项目 | 值 |
| --- | --- |
| 总人数 | 49（7 批 × 7 人） |
| 两组人数 | ClinPath **24** / CBL **25**（4 批各 3 人 + 3 批各 4 人入干预） |
| 主模型参数个数 | 1（截距）+ 1（G）+ 1（Y_T0）+ 6（批次哑变量）+ 1（`form_T1`）= **10** |
| 残差自由度 | 49 − 10 = **39**（不含 `form_T1` 时为 40，见 §2.2.2 说明） |
| 组别效应的检验自由度 | 40（HC3 下）；CR2/Satterthwaite 下受群数限制，见 §3.2 |

**为什么批次固定效应在方案 B 可估、在方案 A 不可估：**

| | 方案 A | 方案 B |
| --- | --- | --- |
| 批次内是否存在组别变异 | **否**（整批同组） | **是**（每批 3+4） |
| `G` 与批次哑变量 | **完全共线**，设计矩阵 rank 不足 | 批次内两组并存 → **非共线，可估** |
| 能分离的量 | 只有 `G`（批次信息只能进随机效应或稳健方差） | `G` **与** 批次效应**同时**可估 |

- 代数上：方案 A 中"批次 1–3 全为对照、批次 4–7 全为干预"时，
  `G = 1` 与"批次 ∈ {4,…,7}"完全等价，故 `G` 与批次哑变量线性相关，系数不可识别。
  方案 B 中每个批次内部既有 `G=0` 又有 `G=1`，批次哑变量只吸收**批次的水平差**，
  不吸收 `G` 的批内变异，因此两者可同时估计。
- **仍需报告 ICC**：用来验证"设计效应接近 1"这一假设是否成立。
  若 ICC 明显大于 0（如 > 0.05），应改用整群稳健方差或模型 B2。
- **外溢敏感性分析**：按"对照组自报是否接触过平台训练内容"分层比较（S11）。
- **解释边界**：方案 B 估计的是**同一批次内**的组间差，不能外推为
  "整批采用新教学"的效果。申报书与论文中不得写成"整批改革有效"。

#### 2.2.3 两套模型的共同要求

- **假设检验**：双侧，α = 0.05。报告 $\beta_1$、95% CI、P 值。
- **不**对 P 值做"是否显著"的二元表述；同时报告效应量与 CI。
- **报告 ICC、群数、每群人数**——无论哪套模型，这三项都是必报项。
- 分析脚本必须在数据锁定前写好并版本化（§9）。

### 2.3 为什么用 ANCOVA 而不是"增益的 t 检验"

| 方法 | 估计量 | 说明 |
| --- | --- | --- |
| 增益 t 检验 | mean(D6−D1) 的组间差 | 简单，但忽略基线不平衡；基线差异会直接进入估计 |
| **ANCOVA（主分析）** | 基线校正后的组间差 | 基线不平衡时更有效；在前后测相关 ρ 较高时功效更高 |

在随机化缺失的设计里，ANCOVA 还有一个重要优点：它把"基线差异"显式地放进模型，
而不是让它混进组间差。代价是它假设**组内回归斜率相同**（见 §2.5）。

### 2.4 HC3 是什么、不是什么（**更正**）

#### 2.4.1 HC3 的定义与适用范围

HC3 是**异方差稳健**协方差估计量的一种，属于 HC0–HC3 家族：

$$
\widehat{\mathrm{Var}}_{\mathrm{HC3}}(\hat\beta)
= (X'X)^{-1}\left(\sum_i \frac{e_i^2}{(1-h_i)^2}x_i x_i'\right)(X'X)^{-1}
$$

其中 $e_i$ 是 OLS 残差，$h_i$ 是杠杆值。相对于 HC0，它把每个残差平方放大了
$1/(1-h_i)^2$ 倍（HC1 只放大 $n/(n-k)$），因此在**小样本、高杠杆点**存在时
比 HC0/HC1 更保守。

**HC3 的适用范围是：观测相互独立、但误差方差不恒定。**
它**不假设**同方差，但**确实假设**观测之间独立。

#### 2.4.2 HC3 **不能**处理群内相关（原文错误，已更正）

| 说法 | 是否正确 |
| --- | --- |
| HC3 处理异方差 | ✅ 正确 |
| HC3 处理小样本杠杆 | ✅ 部分正确（更保守，但不解决群数问题） |
| **HC3 处理群内相关 / 整群设计** | ❌ **错误** |
| **HC3 与 cluster-robust 可以互换** | ❌ **错误** |

**为什么不能互换**：HC3 的"肉"矩阵是 $\sum_i e_i^2/(1-h_i)^2 \, x_i x_i'$，
**逐个观测**求和。群内相关意味着同一批次内学生的残差同向，交叉项
$e_i e_j\ (i \ne j, \text{同群})$ 不为零。HC3 把它们全部当作零丢弃，
于是方差被**系统性低估**，CI 过窄，P 值过小。

**正确做法**：整群设计用 **cluster-robust 方差**（`vcovCL` / `cov_type="cluster"`，
按群求和并包含群内交叉项）或**混合效应模型**。二者都不是 HC3 的变体。

#### 2.4.3 参考分布与演示实现的说明

- **正式分析**用 R `lmtest::coeftest(..., vcov = vcovHC(..., type = "HC3"))`
  或 Python `statsmodels` 的 `fit(cov_type="HC3")`；整群分析用 `vcovCL`。
  由第二名分析人员用另一套代码复算 $\beta_1$ 与 CI（双人复核）。
  两条实现路径的差异若超过 0.01 分，必须查明原因后才报告。
- **平台演示层的纯标准库实现**（`backend/app/services/demo_research.py`）：
  - HC3 的杠杆校正作用在**白化残差**上，即 $(e_i/(1-h_i))^2$，而不是 $e_i^2/(1-h_i)^2$
    （已在 `docs/ARCH.md` §18.3 与代码注释中固定）；
  - **参考分布用正态**，对应 statsmodels `use_t=False`；
  - **这个实现只用于合成演示页**。它与真实分析无关——真实分析不会使用
    演示层的纯 Python 实现，也不会用演示数据。演示层的参考分布选择
    **不构成**对本 SAP 的任何约束。
- 正式分析的参考分布：**主分析用 t 分布**（自由度按模型与群数确定）；
  整群小样本情形见 §3.2 的 CR2 / Satterthwaite 说明。

### 2.5 模型假设检查

| 假设 | 检查方式 | 违反时的处理 |
| --- | --- | --- |
| 线性（Y 与 X） | 残差 vs 拟合值图、局部加权平滑 | 加入 X 的样条项作为敏感性分析 |
| 组内斜率相同 | 加入 `G × X` 交互项检验 | 若交互显著，报告分层斜率并解释（不改变主要结论的表述方式） |
| **残差独立（整群设计）** | **计算 ICC；检查群内残差相关** | **整群设计必须用 cluster-robust 或混合模型（§2.2.1）；不得只靠 HC3** |
| 残差正态 | QQ 图（描述性，不作检验门槛） | 大样本下 OLS 推断稳健；同时报告 bootstrap CI |
| 影响点 | Cook's distance、杠杆值 | 报告剔除影响点后的敏感性结果，不擅自删除 |

> **注意**：上表"残差独立"一行在整群设计中**几乎必然被违反**。
> 这不是一个可以"检查后再说"的假设，而是设计本身决定的结构性特征——
> 因此 §2.2.1 把整群稳健/混合模型定为**主分析**，而不是"违反时才用的补救"。

## 3. 整群设计下的推断与降级规则

### 3.1 群数决定推断能力（不是学生人数）

整群设计的推断精度由**群数**决定，而不是由学生总数决定。本项目只有 **7 个批次**
（方案 A 每臂 3–4 个）：

| 每臂群数 | 可用自由度（近似） | 能否做确证性组间检验 |
| --- | --- | --- |
| 1 | 0 | **否**（组别与群完全共线，效应不可估计） |
| 2–4 | 1–3 | **否**（cluster-robust SE 严重向下偏倚） |
| 5–9 | 4–8 | 仅在小样本校正下勉强可报告，须标注不确定性 |
| ≥ 10 | ≥ 9 | 可以，但仍须报告 ICC 与群数 |

**本项目：方案 A 每臂只有 3–4 个批次**，落在"否"的区间。

`scripts/grant/sample_size.py` §[3b]、§[6] 的实际计算（每批 7 人）：

| 群数/组 | ICC | 设计效应 | 有效 n/组 | 名义人数/组 |
| --- | --- | --- | --- | --- |
| 3 | 0.05 | 1.30 | 16.2 | 21 |
| 3 | 0.20 | 2.20 | 9.5 | 21 |
| 4 | 0.05 | 1.30 | 21.5 | 28 |
| 4 | 0.20 | 2.20 | 12.7 | 28 |
| 7（全部） | 0.20 | 2.20 | 22.3 | 49 |

> **7 个批次全部用上、ICC = 0.20 时，全部 49 人的有效样本量只有约 22 人。**
> 这不是"功效略低"，而是**没有推断基础**。

### 3.2 群数很少时的强制规则（**必须写入预注册**）

> **每臂只有 3–4 个批次（总共只有 7 个批次）时，组间确证性检验不可信。**

具体地：

1. **常规 cluster-robust 标准误在群数少时向下偏倚**——CI 过窄、P 值过小，
   第一类错误率远高于名义 α。这是已知的有限样本性质，不是实现问题。
2. **自由度由群数决定**：方案 A 中组别效应的可用自由度约 G − 2 = **5**；
   t₀.₉₇₅(df=5) = **2.571**，是正态 1.960 的 **1.31 倍**，区间本就宽得多。
3. 可用的**小样本校正**：
   - **CR2** 校正（`clubSandwich` in R；`vcovCR` with `type="CR2"`）；
   - **Satterthwaite 自由度**（`lmerTest` / `clubSandwich` 的 `Satterthwaite`）；
   - **wild cluster bootstrap**（`fwildclusterboot` in R，`boottest`）。
4. **但即使做了这些校正**，7 个群仍不足以支撑一个可信的 P 值：
   - wild cluster bootstrap 在 **G = 7、Rademacher 权重**下只有 **2⁷ = 128 种符号组合**，
     双侧 P 值**不可能小于 2/128 = 0.0156**（`sample_size.py` §[6] 实测）。
     这不是实现问题，而是**信息量的上限**；
   - 校正能缓解偏倚，不能凭空创造信息。
5. 因此本 SAP 规定：

| 情形 | 报告方式 |
| --- | --- |
| 每臂 ≥ 10 个群 | 可报告主分析 P 值 + CI，并报告 ICC 与群数 |
| 每臂 5–9 个群 | 可用小样本校正后报告，但必须标注不确定性 |
| **每臂 2–4 个群（本项目方案 A）** | **按探索性报告**：ICC、群数、描述性组间差、bootstrap 区间；**不报告确证性 P 值**，不写"显著优于" |
| 每臂 1 个群 | **组间效应不可估计**；只报告单组前后变化与可行性指标 |

> **方案 B 的补充说明**：方案 B 的主分析用**批次固定效应 + HC3**，其残差自由度 = 40
> （不是由群数决定），因为批次效应被显式建模为固定效应而非依赖群层面的方差估计。
> 但**若另行报告批次层面的 cluster-robust 推断**，其自由度仍受群数限制（约 5），
> 因此 CR2/Satterthwaite 结果只作为**敏感性分析**报告，不据此做确证性宣称。

### 3.3 单一组别批次内**不能**估计组间效应

原文（v1）的敏感性分析 S3 写"每个批次内单独估计 $\beta_1$，报告森林图式汇总"。
这在**方案 A（整群分配）下是错的**：

- 方案 A 中每个批次只含**一种**组别；
- 在一个只含一种组别的批次内，组别变量是常数，$\beta_1$ **不可识别**
  （设计矩阵中组别列与截距列完全共线）；
- 强行估计会得到无意义的系数（软件通常会丢弃该列或报奇异矩阵）。

**正确表述**：

| 情形 | 批次内分析是否可行 |
| --- | --- |
| 方案 A（整群）：一个批次只有一组 | **不可行**。批次内**不估计**组间效应；批次只用于描述与 ICC 估计 |
| 方案 B（批内 3+4）：一个批次含两组 | 可行，但每个批次内只有 7 人（3+4）；只作描述性展示，不作推断 |

- 方案 A 下**不做**"森林图式批次内汇总"。可做的是：
  报告各批次的**组内前后变化**（单组前后差），以及批次间的**变化量异质性**描述。
- 方案 B 下可按批次展示组间差，但明确标注"描述性、样本量小、不作推断"。
  这是方案 B 相对于方案 A 的一个实质优势：**每批都提供一份批内对照**。

### 3.5 分层置换检验（**方案 B 的随机化推断，必须预先声明**）

方案 B 的随机化机制是**批次内 3+4 分配**，这使**分层置换检验**成为主分析
（批次固定效应模型）之外最自然的随机化推断方法：它不依赖正态近似、
不依赖大样本、也不需要正确的标准误公式，因此在 49 人规模下尤其有价值。

#### 3.5.1 随机化方案（置换的"零假设世界"如何生成）

- 每个批次 **b**（b = 1,…,7）内有 7 名学生；
- 预先规定该批次分入 ClinPath 的人数 $k_b \in \{3, 4\}$（4 个批次 $k_b = 3$、
  3 个批次 $k_b = 4$，使总体为 24 vs 25）；
- 在该批次内**等概率**从 7 人中选出 $k_b$ 人入 ClinPath：$\binom{7}{3} = \binom{7}{4} = 35$ 种可能；
- 各批次**独立**置换 → 全部可能分配数 = $35^7 = 64{,}339{,}296{,}875 \approx 6.43\times10^{10}$。

> **置换必须"限定在批次内"**：即每次置换只在同一批次内重新分配标签，
> 批次成员固定不变。**不得**跨批次打乱（那对应的是"整群随机"的零假设，
> 是方案 A 的问题，不是方案 B 的问题）。

#### 3.5.2 检验统计量

**主统计量：批次调整后的组间均值差（batch-adjusted mean difference）**

$$
T = \frac{1}{7}\sum_{b=1}^{7} \left( \bar{Y}^{(1)}_b - \bar{Y}^{(0)}_b \right)_{\text{调整 } Y_{T0}}
$$

即以**批次为分层**、对基线 $Y_{T0}$ 做调整后的组间差异。
它与 §2.2.2 主模型中 $G$ 的系数 $\beta_1$ **同号同量级**，但在置换下无需模型假设。
实际实现中可直接取"在批内对 $Y_{T1}$ 关于 $Y_{T0}$ 做中心化后的组间均值差"，
或等价地取主模型 $\hat\beta_1$ 作为统计量（两种写法在无交互项时一致）。

**双侧 P 值**：$p = \frac{1 + \#\{|T^{*}_b| \ge |T_{\text{obs}}|\}}{B + 1}$。

#### 3.5.3 枚举可行性（**为什么用 Monte Carlo**）

| 方案 | 组合数 | 是否可行 |
| --- | --- | --- |
| 精确枚举全部置换 | $35^7 = 6.43\times10^{10}$ | **不可行**（即使每秒 $10^6$ 次也要约 18 小时，且需存储全部统计量） |
| 单批次内枚举 | $\binom{7}{3} = 35$ | 可行，但只给出单批次检验 |
| **Monte Carlo 置换** | **B = 20,000 次** | **采用**。最小可及双侧 P = 1/(B+1) ≈ **5.0×10⁻⁵** |

- **随机种子必须在预注册中固定**（建议 `20270101`，与合成演示种子 20261018 区分），
  并记录在分析脚本中，使置换结果可完全复现；
- 置换次数 **B = 20,000**：在 α = 0.05 下，Monte Carlo 标准误约为
  $\sqrt{p(1-p)/B} \approx 0.0015$，足以支持探索性推断；
- 报告时同时给出**置换 P 值**与**主模型 $\beta_1$ 的 95% CI**，两者并列。
- **附加可选的精确检验**：若采用"批次内秩和"等取离散值的统计量，
  其**精确零分布可由 7 个批次各自 35 个可能值的卷积直接算出**（无需枚举 $35^7$），
  可作为置换检验的精确性核对。这一路径由统计顾问在实现阶段确认。

#### 3.5.4 置换检验的定位（不要过度解读）

- 置换检验**只对随机化本身有效**，它不解决**同批外溢**（外溢使置换的"可交换性"
  在小范围内被破坏）、也不解决**评分者测量误差**；
- 因此它是主分析的**支持性证据**，不是"更严格的显著性检验"；
- 与全部其他分析一样，在 49 人规模下按**探索性**报告，**不据此写"显著优于"**。

### 3.6 研究定位：7 天窗口 + 49 人 → 探索性/可行性（**必须写入预注册与申报书**）

**结论：本研究的定位是探索性/可行性研究，不是确证性优效检验。**

两个各自独立、又叠加的限制：

| 限制 | 具体后果 |
| --- | --- |
| **样本量 49 人（每臂 24–25）** | 80% 功效最小可检出 d ≈ 0.81；对 d = 0.5 的功效仅 0.39–0.40（§7.2） |
| **7 天干预窗口** | 训练剂量上限约 3–4 例病例、15–20 步作答；真实效应可能低于可检出门槛（`E5_01` §5.4） |
| **批次固定效应消耗 6 个自由度** | 残差自由度 40；批次间变异被吸收（这是优点），但 df 从 47 降到 40 |

**本研究能得出的**：可行性参数（招募率、保留率、评分者 ICC、批次 ICC、数据完整性）、
效应量的点估计与区间、训练轨迹与个性化执行度。
**本研究不能得出的**：对中等效应（d ≈ 0.5）的确证性结论；长期保持；
"整批采用新教学"的因果效应（那是方案 A 的量）。

**要成为确证性研究，需要什么：**

| 条件 | 说明 |
| --- | --- |
| **更大的样本量** | 若目标为 80% 功效检出 d = 0.50，需 **64 人/组（合计 128 人）**，是 49 人的 2.6 倍 |
| **更长的干预窗口** | 需要足以产生可测量增益的暴露时间（须由预试验确定，7 天很可能不足） |
| **多中心或多届累积** | 单中心单届无法同时满足人数与群数要求；多届累积（每年 49 人，3–5 届）可接近确证性 |
| **先做预试验** | 估计前后测相关 ρ、提升量标准差、评分者 ICC 与批次 ICC，用于修订功效陈述 |
| **固定的评分者 ICC ≥ 0.75** | 否则主结局测量误差进一步侵蚀有效样本量（§7.5） |

## 4. 效应量与 95% 置信区间

| 结局 | 效应量 | 95% CI 来源 |
| --- | --- | --- |
| **主要结局（原始分，独立教师盲评）** | ANCOVA $\beta_1$（方案 B：批次固定效应 + HC3；方案 A：整群稳健或混合模型） | cluster-robust CI；群数少时 bootstrap（按群重抽样）；**方案 B 并列报告 §3.5 置换 P 值** |
| 主要结局（标准化） | 标准化 $\beta_1 / SD_{\text{pooled}}$ | bootstrap 或解析近似 |
| 次要结局（六维度，同一份教师盲评） | 各维度 ANCOVA $\beta_1$ | 同主结局的方差方法 |
| **评分者一致性** | **ICC(2,1) 及 95% CI** | bootstrap |
| **批次 ICC** | **ICC 及 95% CI** | 混合模型方差成分；bootstrap |
| 二分类（完成率等） | 风险差 + RR | Wilson / bootstrap |
| **平台形成性评分** | 仅干预组内描述（均值、变化） | 不作组间推断 |

- **必须同时报告绝对效应（原始分）与相对效应（标准化）**，
  因为临床教师读原始分，方法学审稿人读标准化效应。
- 不报告"P < 0.05 即有效"的结论；CI 跨越 0 时表述为"未观察到可区分差异"。
- **方案 A 一律**：报告点估计与 bootstrap 区间，并明确写"探索性、不作确证性推断"（§3.2）。
- **方案 B**：主模型 $\beta_1$ 的 95% CI 与 §3.5 置换 P 值并列报告，
  并明确写"探索性、49 人规模不足以支持确证性结论"（§3.6）。

## 5. 缺失数据

### 5.1 缺失类型与比例

| 缺失 | 典型原因 | 预计比例（`待确认`） |
| --- | --- | --- |
| D6 整例缺失 | 未参加考核、退出、轮转中断 | 10–20% |
| 单项维度缺失 | 评分表漏填 | < 5% |
| 平台过程数据缺失 | 技术故障、未提交 | 记录并报告 |
| 协变量缺失 | 基线（D1）分数缺失 | 极少；若发生，该例不进入 ITT |

### 5.2 主策略：多重插补（MI）

- **方法**：链式方程多重插补（MICE），**m = 20**；
- **插补模型**：`Y_T1 ~ Y_T0 + G + batch + 参与度 + 训练完成数`；
  不把 D6 之后的变量放入插补模型；
- **整群/批次结构**：插补模型必须含**批次**，并在**批次层面**处理缺失结构
  （同一批次的学生缺失往往相关）；
- **插补对象**：仅结局与协变量，不插补"是否参加"这一事实；
- **合并**：Rubin 规则；
- **诊断**：报告插补前后分布对比、FMI（缺失信息比例）。

### 5.3 敏感性：完整病例分析（CCA）

- 仅纳入同时有 D1 与 D6 者，重复主模型；
- 若 MI 与 CCA 结论不一致 → 报告两者，主要结论降级为"探索性"。

### 5.4 缺失比例阈值

- 主要结局缺失 ≤ 20%：按上述流程；
- 主要结局缺失 > 20%：主要结论降级，并在摘要中说明；
- 缺失 > 40%：不再做效果推断，只报告可行性。

> **49 人规模下的提醒**：49 人的 20% 只有约 10 人。**每缺失 1 名学生，
> 每臂就少约 0.5 人**，对已经很低的可检出效应（d ≈ 0.81）影响不成比例。
> 因此缺失比例必须精确报告到人，不能只报百分比。

## 6. 多重比较

### 6.1 主要结局

**单一主要结局**（D6 独立教师盲评总分），**不做多重比较校正**。α = 0.05。

### 6.2 次要结局（六维度）

六个维度构成一个"族"（family）。采用 **Benjamini–Hochberg（BH）**
控制错误发现率（FDR），q = 0.05。

- 报告**校正前**与**校正后**的 P 值，并标明哪一列用于推断；
- BH 只在六个维度**全部**可估计时执行；若某维度缺失过多，在 SAP 修订中说明；
- **方案 A（每臂 3–4 个群）下，六维度一律只作描述性报告**（点估计 + bootstrap 区间），
  不报告 BH 校正后的 P 值——没有推断基础时，多重比较校正没有意义；
- **方案 B 下**，六维度的 BH 校正 P 值可与主分析一起报告，但必须同时写明
  "49 人规模下为探索性、未校正的维度差异不作为结论"；
- **这是计划中的步骤，尚未执行**。任何"已校正"的表述都必须来自实际运行的分析脚本。

### 6.3 过程指标与可行性指标

**不做**推断性检验，只作描述性报告（均值、比例、CI）。
理由：这些指标不是效果结局，检验它们会产生大量无意义的"显著"。

**平台形成性评分属于本类**：只在干预组内描述，不做组间比较（§2.1）。

### 6.4 亚组

**不做**确证性亚组分析。若做探索性亚组（如按基线高低分层），
明确标注为"探索性、未校正、仅用于生成假设"。

## 7. 样本量可行性

> **本节所有 d 都是示例假设。** 本 SAP **不提供**本研究的效应量估计
> （理由见 §7.6）。下表的含义是"**如果**真实效应是 d，需要多少人"，
> 不是"我们预计效应是 d"。任何把下表数字写成"预期效果"的做法都是对文件的误用。
>
> **特别地：合成演示数据折算出的 d = 3.57 是生成器参数，禁止使用**（§8）。

### 7.1 公式与逐步计算（真实运行输出）

两组等量、双侧 α、正态近似：

$$
n_{\text{每组}} = \frac{2\left(z_{1-\alpha/2} + z_{1-\beta}\right)^2}{d^2}
$$

代入 α = 0.05、power = 0.80：

```
z_(1-α/2) = 1.959964
z_(1-β)   = 0.841621
(z_(1-α/2)+z_(1-β))^2 = 7.848880
2*(...)^2 = 15.697759   → n/组 = 15.6978 / d^2
```

**t 分布修正**（小样本下更准确）：对每个 n 计算
$\text{power}(n) = \Phi\left(d\sqrt{n/2} - t_{1-\alpha/2,\,2n-2}\right)$，
向上搜索到 power ≥ 0.80。

### 7.4 ANCOVA 的效率

ANCOVA 相对"增益 t 检验"的方差比为 $(1+\rho)/2$（ρ = 前后测相关）：

```
--------------------------------------------------------------------------
[4] ANCOVA 相对变化量检验的效率比 sqrt((1+rho)/2)（rho = 前后测相关）
--------------------------------------------------------------------------
rho=0.30  方差比=0.650  n 可乘以 0.650  （例：t修正 64/组 → 42/组）
rho=0.50  方差比=0.750  n 可乘以 0.750  （例：t修正 64/组 → 48/组）
rho=0.70  方差比=0.850  n 可乘以 0.850  （例：t修正 64/组 → 55/组）
```

若效应以**原始分标准差**表达（更贴近临床教师的直觉），ANCOVA 规划用的
标准化效应为 $d_{\text{adj}} = d_{\text{raw}}/\sqrt{1-\rho^2}$：

```
--------------------------------------------------------------------------

  0.40  0.50   0.462           75         89
  0.40  0.70   0.560           51         60
  0.50  0.30   0.524           59         70
  0.50  0.50   0.577           48         57
  0.50  0.70   0.700           33         39
  0.60  0.30   0.629           41         49
  0.60  0.50   0.693           34         40
  0.60  0.70   0.840           24         29
```

> **这些是示例计算。** d 的实际值未知，必须由**预试验或文献**估计。
> 上述数字只说明"不同假设下需要多少人"，不构成对本研究效应的预期。

### 7.5 主要结局的测量精度如何限制功效

样本量公式假设结局被**无误差地**测量。本研究的结局是教师盲评，必然有测量误差：

- 两位评分者的评分者一致性 **ICC(2,1)** 直接决定主结局的可靠性；
- 若 ICC = 0.90，测量误差较小；若 ICC = 0.60，主结局有相当大比例是噪声，
  **等效于损失大量有效样本**；
- 因此：**评分者一致性不是"附加结果"，而是样本量规划的一部分。**
  D1 之前的评分者校准必须报告校准 ICC，若校准 ICC < 0.75（`待确认`），
  必须先改进量表或培训，再启动研究。

> **本 SAP 不给 ICC 的数值假设**：没有真实评分数据，任何 ICC 数字都只能是
> 假设。校准阶段的实测值将用于修订功效陈述，并在预注册修订中记录。

### 7.6 效应量从哪来（诚实说明）

本 SAP **不提供**效应量估计，原因：

1. 没有真实前测数据；
2. 合成演示的效应是**输入参数**，不是观察结果（见 §8）；
3. 文献中的教育干预效应异质性大，直接套用不可靠。

**允许的效应量来源（按优先级）**：

1. **本单位的预试验**（1 个批次，单组前后测）：估计前后测相关 ρ、
   提升量标准差、评分者 ICC。这是最可信的来源。
2. **同类教学干预的已发表文献**：只作为**区间假设**使用，并明确标注
   "假设、待本地预试验确认"；不得把文献的单一数字当作本研究的预期效应。
3. **临床/教学判断的合理范围**：由教研室给出"最小有教学意义的差值"（MCID），
   这比"预期效应"更适合指导本研究——它决定的是"值得检出多大的差"。

**禁止的来源**：合成演示数据（§8）。

预试验数据不进入主分析，并在预注册中说明。

- 所有方案偏离；
- 明确声明：本研究**未**使用合成数据作为效果证据；
- 明确声明：研究定位（**探索性可行性**）、7 天窗口与 49 人规模的限制（§3.6）。
