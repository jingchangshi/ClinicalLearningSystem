## 3. 关键设计决定（供评审复核）

> **2026-10-18 v1.1 修订**：原第 1、2 行把"整群分配"与"ANCOVA + HC3"写成已定方案，
> 这是错误的——分组单位未定，且整群设计必须按整群分析。下表为修订后版本。
> 修订清单见 `PROTOCOL_REVISION_NOTES_v1.md`。

| 决定 | 理由 | 文件位置 |
| --- | --- | --- |
| 两组前后测；**分组单位并列两种方案，不预设** | 班次整群无外溢但群数不足；班内小组样本量可行但有外溢 | E5-01 §3.1–3.3 |
| 整群设计**按整群分析**：cluster-robust / 混合模型，报告 ICC 与群数 | HC3 只处理异方差，**不处理群内相关**；群数 ≤4/臂时确证性检验不可信 | E5-02 §2.2.1、§2.4、§3.1–3.2 |
| 删除"单组别批次内估计组间效应" | 一个批次只有一组时，组别是常数，效应**不可识别** | E5-02 §3.3 |
| **主要结局 = 独立教师盲评**；平台形成性评分仅过程指标 | 平台评分与训练同源、对照组不存在，无法做组间比较 | E5-01 §7.0；E5-02 §2.1 |
| 每年 20–50 人规模定位为**可行性 + 信号生成** | 25 人/组的 80% 功效最小可检出 d = 0.792；d=0.5 时功效仅 0.40 | E5-01 §3.4、§4.3；E5-02 §7.2 |
| 六维度用 BH，主要结局不校正；群数不足时只作描述 | 单一主要结局；六维为一个族 | E5-02 §6 |
| 样本量用 t 修正而非只看正态近似 | 小样本下正态近似低估 n（64 vs 62.79） | E5-02 §7.1 |
| 明确写出整群设计效应可能使研究不可行 | 30 人/班 × ICC 0.05 需约 180/组；2 班/组 × ICC 0.20 有效 n 仅约 9 | E5-02 §7.3 |
| 不提供效应量估计；所有 d 标注为示例假设 | 无真实前测；合成 d=3.57 是生成器参数 | E5-02 §7、§8 |
| 真实数据字段与合成字段**列名不同** | 误合并会在列名层面暴露 | 数据字典 §5 |
| 同意建为事件表而非状态字段 | 撤回与版本变更可审计 | 数据字典 §3 |
