> **状态：待教研室确认。** 方案 B 为推荐方案，但**只有教研室书面允许班内分组后才能定稿**。
> 本研究尚未开展，本表不包含任何结果。

## 1. 现实约束（已确认）

| 项目 | 数值 |
| --- | --- |
| 每批见习生 | 7 人 |
| 每批持续时间 | 7 天 |
| 批次数 | 7 |
| 主要研究对象 | **49 名本科见习生** |
| 拓展人群 | 其余 21 名（见习 + 实习合计 70），**不并入主要结局分析**；其学段归属与是否与 49 人完全重叠**待确认** |

## 2. 方案 A 与方案 B 对照

| 维度 | **方案 A：7 批次整群分配** | **方案 B：每批 7 人内部随机 3+4**（推荐） |
| --- | --- | --- |
| 分配单位 | 整个批次（7 人） | 批次内的学生 |
| 群数 | **7 个**（每臂 3–4 个） | 7 个批次，但每批同时含两组 |
| 每臂人数 | 约 21–28（3 或 4 批 × 7） | **24 vs 25**（见 §5 的 3/4 交替分配） |
| 有效样本量 | 受设计效应压缩；ICC=0.05 时约 30–40% | 接近名义人数（批次固定效应吸收批次差异） |
| 主要分析 | 整群稳健 / 混合模型 `Y ~ G + X + (1\|batch)`，报 ICC 与群数 | **`Y_T1 ~ group + Y_T0 + batch`**（批次固定效应） |
| 能否估计批次效应 | **不能**：批次与组别共线 | **能**：每批同时含两组 |
| 能否做确证性检验 | **不能**。每臂 3–4 个群，cluster-robust SE 向下偏倚 | 仍属小样本，但可做**批次内限制置换检验** |
| 定位 | **探索性**，不承诺显著性 | **探索性/可行性**，提供效应信号与 95%CI |
| 混杂风险 | 批次 = 季节 = 教师 = 组别，全部混在一起 | 批次差异被固定效应吸收；教师效应需靠同一教师带两组控制 |
| 教学污染风险 | 低（整批同组） | **较高**：同批学生互相交流；需明确规则 |
| 伦理与公平 | 整批同组，学生无选择 | 同批内随机，需说明"对照组延迟获得平台权限" |
| 教研室需要批准什么 | 允许整批分组（通常较易） | **允许班内随机分组 + 同批两组同时教学**（通常较难） |
| 随机化记录 | 批次分配记录 | **每批 3/4 分配的随机化记录**（种子、时间、执行人） |

## 3. 为什么推荐方案 B

1. **批次效应可被吸收**：方案 A 中"第 3 批比第 1 批分数高"无法区分是干预还是季节/教师/病例难度；
   方案 B 中每批同时含两组，批次固定效应可以估计并扣除。
2. **样本量不被群内相关吃掉**：49 人分成 7 个群，若 ICC=0.05，方案 A 的有效样本量约
   14–20 人/臂；方案 B 接近 24/25。
3. **可以做受限置换检验**：在"每批 3 人干预、4 人对照"的约束下，可枚举或蒙特卡洛生成
   所有合法的组别分配，得到不依赖大样本近似的 p 值——这在 n=49 时比 t 检验更可信。
4. **教师效应可控**：同一教师同时带两组的病例讨论，可减少"教师水平"与组别的混淆。

## 4. 方案 B 必须控制的三件事

| 风险 | 具体表现 | 控制措施 |
| --- | --- | --- |
| **教学污染** | 同批干预组学生把平台内容/追问讲给对照组 | 明确告知不得共享账号与训练内容；问卷中自报交叉接触；敏感性分析剔除自报污染者 |
| **教师效应** | 教师对某一组投入更多 | 同一教师带两组、等课时；教师不知 T0/T1 分配（盲评由另两位教师完成） |
| **人员流失** | 7 天内因病/请假缺席 | 记录每次出勤；ITT 为主分析；缺失按 SAP 处理，不剔除 |

## 5. 方案 B 的随机化与置换检验（技术要点）

- 每批 7 人：随机选 3 人入 ClinPath 组、其余 4 人入对照。
- 为平衡总人数，**批次间交替 3/4 与 4/3**：4 个批次按 3+4，3 个批次按 4+3，
  得到 ClinPath **4×3 + 3×4 = 24** 人、对照 **4×4 + 3×3 = 25** 人，合计 49。
  （若 7 批全部 3+4，则为 21 vs 28，两组人数差异过大。）
- 每批内部的 3/4 分配独立随机，随机化工具与种子须记录，且在 T0 **之前**完成。
- **受限置换检验**：每批的合法分配数为 `C(7,3)=35`（或 `C(7,4)=35`，同一组数）。
  7 批共有 `35^7 ≈ 6.44×10^10` 种，无法穷举 → 使用**蒙特卡洛置换**（如 10,000 次，
  固定种子），每次在各批内部按该批的 3/4 或 4/3 约束独立置换组别标签，
  重算批次调整后的组间差异。
- 检验统计量：批次固定效应模型中的组别系数（或各批组间差的加权平均）。
- 报告：观测统计量、置换分布、双侧 p 值、以及置换次数与种子。

## 6. 方案 A 的分析降级规则（若教研室只批准整群）

- 主分析：`Y ~ G + X + (1|batch)` 混合模型，报告 ICC 与每臂群数。
- **不报告确证性 p 值**；改为报告效应量、95%CI 与"本设计无法排除批次混杂"的说明。
- 敏感性：wild cluster bootstrap（若群数 ≥ 6）或直接按探索性描述。
