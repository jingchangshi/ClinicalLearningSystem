## 2. 唯一设计：7 批次整群分配

| 维度 | 内容 |
| --- | --- |
| 分配单位 | **整个批次（7 人）** |
| 组别结构 | **预先固定 3 批进入 ClinPath 组、4 批进入常规 CBL 组** |
| 随机化 | 在 **C(7,3) = 35** 种合法批次分配中随机产生实际分配 |
| 每臂人数 | ClinPath **21** 人（3 批 × 7）／CBL **28** 人（4 批 × 7） |
| 分配时点 | **D1 之前**完成并封存 |
| 随机化留痕 | 随机种子、批次日期、分配执行人、分配结果（见数据字典 `randomisation_record`） |
| 定位 | **探索性整群研究**，不承诺确证性统计显著性 |

**为什么不能做得更"高效"**：把每批 7 人拆成两组能提高有效样本量，但**申请人的教学组织条件不允许**
（同一批学生必须在同一教学组内完成 7 天见习）。这是本研究最大的方法学限制，
必须如实写入申报书与研究方案，而不是用统计技巧掩盖。

### 2.1 若无法随机分配

若实际排课使随机分配不可行，则本研究**如实改为整群准实验研究**，
并**放弃随机化推断**（不做 §3 的精确枚举检验），只报告描述性与整群调整后的探索性结果。

## 3. 随机化推断：精确枚举 C(7,3) = 35

整群随机化只有 35 种合法分配，**可以完全枚举**，因此不需要任何近似：

- **检验统计量**（预先规定，不得在看到结果后更换）：两组**批次均值之差**
  （即 ClinPath 组 3 个批次的 D6 均值 − CBL 组 4 个批次的 D6 均值），
  以批次为观测单位；敏感性分析再报告基线校正版本（以批次 D1 均值为协变量）。
- **双侧 p 值**：`p = #{|T*| ≥ |T_obs|} / 35`，遍历全部 35 种分配。
- **P 值取值**：`k/35`（k ≥ 1，观察到的分配计入分子）。**不得无条件宣称最小双侧 p 为 2/35**：
  `p = 1/35` 当且仅当观察到的分配在 35 种分配中 |T| 严格最大（固定算例 `[10,9,8,0,0,0,0]` 穷举得 1/35）；
  出现 |T| 并列时 p ≥ 2/35。全项目仅使用这一种双侧 p 定义。

> **必须写明的限制**：35 种分配的分辨率极粗，p < 0.05 只在观察分配是唯一最极端分配时才出现，
> 且结论高度依赖数据。因此本研究**不承诺统计显著性**，
> 只报告效应量、全部 35 种分配的分布、以及"结果在多大比例的合法分配中可被复制"。
> 这是 7 个群的硬约束，不是分析选择。

## 4. 辅助分析：小样本整群调整模型

精确枚举是主推断；下列模型仅作**辅助**，且必须同时报告其不稳定性：

| 模型 | 用途 | 必须同时说明 |
| --- | --- | --- |
| `Y ~ G + X + (1\|batch)` 混合模型 | 估计组别效应并报告 ICC | **只有 7 个群**，方差成分估计高度不稳定 |
| 整群稳健标准误（按批次聚类） | 敏感性分析 | 组别效应可用自由度约 **G − 2 = 5**；`t(0.975, 5) = 2.571`，是正态 1.960 的 1.31 倍 |
| wild cluster bootstrap | 小样本稳健推断 | G = 7 时 Rademacher 权重只有 `2⁷ = 128` 种符号组合，**双侧 p 不可能低于 2/128 ≈ 0.0156** |

**不得**用个体层面 HC3 代替整群相关处理：HC3 只校正异方差，不处理群内相关
（说明见 `E5_02` §2.4）。

## 5. 主要威胁与缓解

| 威胁 | 具体表现 | 缓解 | 残留风险 |
| --- | --- | --- | --- |
| **批次与组别共线** | 一个批次只有一种组别，批次效应与组别效应无法分离 | 无法消除；报告批次层面的描述性数据 | 季节、教师、病例难度差异全部混入组别效应 |
| **群数极少（7 个）** | 区间推断不稳定，P 值分辨率仅 1/35 | 用精确枚举替代近似检验；如实报告 35 种分配 | 结论只能是探索性的 |
| **基线不平衡** | 整群分配下某批整体基础更好 | 报告两组基线标准化差异；基线差异大时进一步降级为描述性 | 无法通过随机化保证平衡 |
| **教学污染** | 同批学生互相交流（批内同组，风险较低） | 批内同组，天然隔离 | 跨批交流仍可能发生 |
| **人员流失** | 7 天内因病/请假缺席 | 记录出勤；ITT 为主分析 | 每缺失 1 人在 49 人规模下影响不成比例 |
| **7 天窗口过短** | 练习效应与真实增益混淆，无法测保持 | 明确声明；阴性结果必须并列陈述"窗口/剂量不足"与"干预无效" | 无法排除 |
