## 1. 研究题目

**所属项目（正式申报名称）**：基于人工智能辅助临床推理训练的医学生个性化学习与形成性评价教学改革研究

> 本文件是该项目下的**子研究方案**。项目整体以临床见习教学模式改革及效果验证为核心，
> **不是**重新开发医学教学系统；子研究聚焦风湿免疫科本科见习的临床推理形成性训练。

**子研究题目（内部研究方案名称）**：基于 ClinPath 平台的本科风湿免疫见习临床推理形成性训练效果研究——一项拟开展的 7 天两组前后测探索性研究

**英文（供伦理申请与预注册使用）**：
Formative clinical-reasoning training in a seven-day undergraduate rheumatology
clerkship: a planned two-group pretest–posttest exploratory study of a
platform-supported condition versus conventional case-based learning.

**研究类型**：教育干预研究（educational intervention study），**两组前后测**设计。
**分组单位并列两种方案**（§3），**推荐方案 B（每批 7 人内部随机 3+4）**，
但**必须由教研室在 D1 之前书面确认**后才能定稿与预注册。
本研究不以患者为研究对象，不涉及患者个体数据。

**研究定位（重要）**：在 **49 名见习学生、每臂 24–25 人**的规模下，两组设计的
**主要目的不是确证性优效检验**，而是**可行性验证与效应信号生成**（见 §3.4、§4.4）。
主要结局仍是独立教师盲评（§7.1）。在 49 人规模下 80% 功效只能检出 d ≈ 0.79–0.81
的大效应（`scripts/grant/sample_size.py` §[6] 实测），对中等效应（d ≈ 0.5）
功效仅约 0.39–0.40，因此本研究会**如实报告为探索性结果**，不做确证性优效宣称。

## 2. 背景与问题

### 2.1 教学问题

风湿免疫病在本科见习中占比小、病例分散、起病表现重叠，学生常见困难是：
能背出疾病名称，但难以完成"提取关键信息 → 形成问题表征 → 列出鉴别并给出反证 →
选择检查 → 作出处置决策"这一完整推理链。常规病例讨论（CBL）受课时与病例数量限制，
一名学生在一个 7 天见习期内往往只在少数病例上获得**一次**完整推理的机会，
且反馈多为终结性的（讨论结束时的教师总结），缺少**过程性、可追踪**的形成性反馈。

### 2.2 可研究的问题

在**7 天的本科风湿免疫见习**中，**以平台承载的、按推理步骤拆分的形成性训练**，
相对于**常规 CBL**，是否能在**独立标准化病例**上产生可测量的学习增益？
增益是否体现在临床推理的六个可分解维度上？学生的训练轨迹与参与度如何？

> 本研究的因变量是**学生在标准化病例上的表现**，不是患者的临床结局，
> 也不是平台使用量。研究不评价任何真实患者的诊疗决策。

### 2.3 研究假设（方向性，待检验）

- **H1（主要）**：在控制基线后，ClinPath 辅助组的**独立标准化病例后测总分**高于常规 CBL 组。
  在 49 人规模下，H1 按**探索性**目标处理（§3.4、§4.4）。
- **H2（次要）**：上述差异在六个评分维度上方向一致，其中"鉴别诊断与论证"
  与"检查与临床决策"两个维度的组间差异可能相对更大（探索性预期，不作确证性检验）。
- **H3（次要）**：两组的训练完成率与导师追问轮次存在差异，且参与度与后测表现相关。
- **H4（可行性，主要目标之一）**：在真实的 7 天见习排课下，本研究的招募率、保留率、
  评分者一致性（ICC）、数据完整性与平台可用性达到可接受水平，从而为后续
  多中心研究提供参数。

H2 的方向来自平台设计的教学重点，**不是**来自任何已有数据；合成演示数据中
`scenario_assumptions` 的 6 分 / 18 分是生成脚本的**输入参数**，不是效应量估计。

## 3. 研究设计（分组单位：方案 A / 方案 B，推荐方案 B）

### 3.1 设计类型与两种分组方案

**设计类型**：两组（常规 CBL 对照 vs ClinPath 辅助）前后测设计（pretest–posttest, two-group）。

```
          D1 独立标准化病例         D2–D5 训练期（7 天循环内）        D6 独立标准化病例
常规 CBL 组 ────►  常规 CBL 病例讨论 + 平台外常规学习        ────►
ClinPath 组 ────►  ClinPath 分步形成性训练 + 教师针对性反馈   ────►
          （同一套评分量表、两位盲评教师、与训练库不重复的病例）
```

**已确认的真实教学条件**（替代 v1.1 的全部旧假设）：

| 条件 | 值 | 含义 |
| --- | --- | --- |
| 见习周期 | **7 天/批** | 整个干预与前后测必须在 7 天内完成 |
| 每批人数 | **7 人/批** | 单个分配单元的规模很小 |
| 批次数 | **7 批** | 主研究总体 = 7 × 7 = **49 名见习学生** |
| 见习 + 实习合计 | 70 人 | 其余 **21 人为实习阶段学生，属独立扩展人群**（§4.3） |
| 可参与教师 | ≥ 2 名（第 3 名可裁决） | 用于病例/量表审核与盲评 |

**分组单位（unit of allocation）由教研室在 D1 前书面确定**，两种方案并列如下：

| | **方案 A：7 批次整群分配** | **方案 B：每批 7 人内部 3+4 随机** |
| --- | --- | --- |
| 分配单位 | 整个批次（7 人） | 批次内的学生（每人独立） |
| 同批是否同时有两组 | 否（一个批次只有一种组别） | 是（每批 3 人 + 4 人） |
| 组别是否嵌套于批次 | **是** | 否 |
| 干预/对照人数 | 21 vs 28（3 批 vs 4 批） | **24 vs 25**（每批 3+4，跨批互补） |
| 统计模型 | 整群稳健 / 混合模型；**批次固定效应不可估**（§3.2.5） | `Y_T1 ~ G + Y_T0 + batch`，**批次固定效应可估**（§3.3.5） |
| 主要威胁 | **只有 7 个群**，无法支持确证性检验 | **同批同伴外溢**，稀释组间差异 |
| 定位 | **仅探索性**，不报告确证性 P 值 | **推荐**：仍是探索性，但可估批内效应并控制批次混杂 |

> **本文件推荐方案 B，但选择权在教研室。** 推荐理由见 §3.3.6：方案 B 使**每个批次
> 内部都同时存在两组**，因此批次固定效应**可以估计**（批次内部有组别变异），
> 批次间的季节/教师/病例差异被吸收；而方案 A 中组别与批次**完全共线**，
> 批次固定效应**不可识别**（§3.2.5）。
> **方案 B 必须在 D1 之前经教研室书面确认**（涉及教务与病房排班），
> 并在预注册中写明（见 §13 第 1 项）。

### 3.2 方案 A：7 批次整群分配

#### 3.2.1 做法

一个批次（7 人）整体进入某一组：该批次所有学生接受 ClinPath 训练，或全部接受常规 CBL。
分配在 D1 之前按批次编号交替或抽签确定，**不根据学生基线或教师偏好调整**。
7 个批次按 3 : 4 分到两组（21 人 vs 28 人）。

#### 3.2.2 可行性

**优点**

- 行政阻力最小：不改变行政班级、不拆分讨论组、不影响排课；
- **无同批同伴外溢**：同批学生接受同一种教学；
- 教师层面干净：一名带教教师只负责一种教学方式；
- 伦理上更容易解释："你们这批采用这种方式"。

**代价（在本项目规模下是决定性的）**

- **群数只有 7 个**。两组设计下每臂只有 **3–4 个批次**。这是本设计的致命约束（§3.2.5）。
- **有效样本量缩水**：每批 7 人、批次内 ICC = 0.20 时，设计效应 = 1 + 6×0.20 = 2.20；
  全部 49 人的有效样本量只有约 22 人（`scripts/grant/sample_size.py` §[3b]、§[6]）。
- **组别与批次完全共线**：无法把"批次效应"与"组别效应"分开（§3.2.5）。

#### 3.2.3 需要教研室提供什么

| 需要 | 为什么 |
| --- | --- |
| 7 个批次的**时间顺序**（学期/月份） | 判断季节与课程进度是否与组别混杂 |
| 每个批次的**带教教师名单** | 判断教师效应能否与组别分离；同一教师是否跨组 |
| 是否允许**同一教师跨组带教** | 若不允许，教师与组别完全混淆 |
| 分配方式（交替 / 抽签）与执行人 | 决定能否声称"分配隐藏" |
| 能否接受"某一整批学生只用一种教学" | 整群分配的直接后果 |

#### 3.2.4 混杂风险

| 混杂源 | 机制 | 处理 |
| --- | --- | --- |
| **批次/季节效应** | 不同批次的学生基础、课程进度、考试压力不同 | 批次作为随机效应；报告批次间异质性；避免"一部分批次干预、另一部分对照"的单向安排 |
| **教师效应** | 某位教师恰好带干预批，其教学水平被误读为干预效果 | 尽量让每位教师**两组都带**；做不到时如实写明教师与组别完全混淆，结论降级 |
| **学生基线差异** | 非随机分配，某批整体基础更好 | D1 基线校正；报告两组基线标准化差异；基线差异大时降级为探索性 |
| **群数太少** | 每臂 3–4 个批次，任何"组间差异"都可能只是这几批的差异 | **见下方硬约束** |
| **霍桑/期望效应** | 整批知道自己是"新方法组" | 对照组同样获得账号与教师关注；局限中说明无法排除 |

#### 3.2.5 统计模型（整群设计必须按整群分析）

**核心原则：HC3 不能替代整群分析。** HC3 只处理**异方差**，对**群内相关**完全无效。
把批次嵌套在组别里的数据当作个体独立观测来跑 `Y ~ G + X` + HC3，
会**系统性低估标准误、高估显著性**。正确的做法是：

**（1）整群稳健方差（首选，主分析）**

```
R:  lm(Y ~ G + X, data = d)
    lmtest::coeftest(fit, vcov = sandwich::vcovCL(fit, cluster = ~ batch, type = "HC1"))
Python: statsmodels OLS(...).fit(cov_type="cluster", cov_kwds={"groups": d["batch"]})
```

**（2）混合效应模型（并列主分析或敏感性分析）**

```
Y ~ G + X + (1 | batch)
```

报告 **ICC**（批次内相关系数）与批次随机效应的方差成分。

**（3）批次固定效应在本方案中**不可估**（关键事实）**

在方案 A 中，一个批次只含一种组别，**组别列与批次哑变量列完全共线**：

```
若批次 1、2、3 全为对照组，批次 4、5、6、7 全为干预组：
    batch_1 = 1 ⟺ G = 0
    batch_4 = 1 ⟺ G = 1
   → 设计矩阵中 G 与 (batch 哑变量) 线性相关，rank 不足，系数不可识别。
```

因此 **方案 A 的模型里不能同时放入 `batch` 固定效应与 `G`**；
能估的只有 `G`（+ 基线 `X`），批次信息只能通过**随机效应**或**整群稳健方差**进入。
这正是"方案 A 无法分离批次效应与组别效应"的代数表达。

**（4）群数只有 7 时的硬约束（必须写入预注册）**

> **只有 7 个批次、每臂 3–4 个批次时，组间确证性检验不可信。**
>
> - 常规 cluster-robust 标准误在群数少时**向下偏倚**（CI 过窄、P 值过小）；
> - 可用自由度由群数决定（G − 2 = **5**），不是由 49 名学生决定；
>   t₀.₉₇₅(df=5) = 2.571，是正态 1.960 的 **1.31 倍**，区间本就宽得多；
> - **wild cluster bootstrap 在 G = 7、Rademacher 权重下只有 2⁷ = 128 种符号组合，
>   双侧 P 值不可能小于 2/128 = 0.0156**——这不是实现问题，是信息量的上限；
> - 因此：**方案 A 一律按探索性研究报告**——报告 ICC、群数、描述性组间差与
>   bootstrap 区间，**不报告确证性 P 值**，也不写"显著优于"。

#### 3.2.6 方案 A 在本项目规模下的结论

**7 个批次、每臂 3–4 个批次时，方案 A 无法作为确证性研究。**
它可作为**可行性研究 + 信号生成**（§3.4），或作为多届累积设计的一部分。
是否接受这一现实，由教研室决定。

### 3.3 方案 B：每批 7 人内部 3+4 随机（**推荐**）

#### 3.3.1 做法

同一批次内的 7 名学生按**随机数**分到两组（每批 3 人 + 4 人，哪一组得 3 人按批次
预定的交替规则确定，使总体接近平衡）。两组在同一批次、同一病房、同一时间段内并行，
教学方式不同。**分配序列与执行人记录留档**（`randomisation_record`，见数据字典 §12）。

> **人数：24 vs 25。** 7 个批次中，4 批各分 3 人入 ClinPath、3 批各分 4 人入 ClinPath：
> ClinPath = 4×3 + 3×4 = 24 人，CBL = 4×4 + 3×3 = 25 人（`sample_size.py` §[6]）。

#### 3.3.2 可行性

**优点**

- **样本量按个体计算**：批次固定效应吸收批次差异，设计效应接近 1，49 人就是 49 个观测单位；
- **批次效应被两组共同吸收**：同一批次的两组共享季节、课程进度、病房环境，
  批次混杂大幅减小，且**批次固定效应可估**（§3.3.5）；
- 每个批次都能产生两组数据，不必跨批等待。

**代价**

- **同批同伴外溢（contamination）**：这是本设计最大的威胁。同批同学会讨论病例、
  互相看屏幕、共享训练内容；对照组可能间接获得干预内容，使组间差异**被稀释**。
  稀释方向是保守的（低估效果），但它使"阴性结果"无法区分"无效"与"污染"。
- **教师角色冲突**：同一教师同时带两组，可能不自觉地区别对待。
- **伦理上更敏感**：同批同学被分到不同待遇，容易产生"不公平"感受，
  必须在知情同意与解释中处理（见 `E5_03` §2.3）。
- **实施复杂度高**：需要在同一批次内安排两种并行的教学流程（7 天内，7 人）。

#### 3.3.3 需要教研室提供什么

| 需要 | 为什么 |
| --- | --- |
| 是否允许**同一批次内拆分**两组 | 这是方案 B 的前提，涉及教务与病房排班 |
| 两组能否安排**不同时间段**使用平台 | 减少外溢（建议错开，并约定不共享训练内容） |
| 同一教师能否同时带两组 | 决定教师效应是否与组别混淆 |
| 随机化执行人与随机化时点 | 决定能否声称"分配隐藏" |
| 是否接受"同批不同待遇"的伦理与舆情风险 | 伦理审查与知情同意的前提 |

#### 3.3.4 混杂风险

| 混杂源 | 机制 | 处理 |
| --- | --- | --- |
| **同批同伴外溢** | 对照组间接接触干预内容 | 错开使用时间；约定不共享；局限中说明；把"外溢程度"作为可行性指标记录（对照组自报是否看过平台训练内容） |
| **教师区别对待** | 同一教师知道谁在干预组 | 教师不参与结局评分；结局双盲；记录教师接触两组的时长是否可比 |
| **随机化执行偏差** | 分配序列被提前知晓 | 用随机数生成器分配；记录分配序列与执行人；分配隐藏到 D1 前 |
| **批内两组基线不平衡** | 每批只有 7 人，随机化易失衡 | 基线校正；报告标准化差异；必要时**按基线分层随机**（在每批内按 D1 高低各随机一半） |
| **霍桑效应** | 两组都知道自己在被研究 | 两组同等对待；局限中说明 |

#### 3.3.5 统计模型（**推荐主模型**）

同一批次内同时存在两组，组别**不**嵌套于批次，批次固定效应**可估**：

```
主分析（方案 B 主模型）：
    Y_T1 ~ G + Y_T0 + batch          # batch 为固定效应（7 批 → 6 个哑变量）
    vcov = HC3（异方差稳健）；同时报告 CR2 小样本校正作为敏感性

随机效应版本（敏感性分析）：
    Y_T1 ~ G + Y_T0 + (1 | batch)
```

**为什么批次固定效应在方案 B 中可估、在方案 A 中不可估：**

| | 方案 A | 方案 B |
| --- | --- | --- |
| 批次内是否存在组别变异 | **否**（整批同组） | **是**（每批 3+4） |
| `G` 与批次哑变量的相关性 | **完全共线**，rank 不足 | 批次内两组并存 → 非共线，**可估** |
| 可分离的量 | 只有 `G`（批次信息只进随机效应/稳健方差） | `G` **与** 批次效应同时可估 |
| 参数个数（n = 49） | 1 + 1 + 1 = 3 | 1 + 1 + 1 + (7−1) = **9** |
| 残差自由度 | 49 − 3 = 46（但组别自由度受 G 限制，见 §3.2.5） | **49 − 9 = 40** |

- **自由度现实**：方案 B 主模型残差自由度 = 40（`sample_size.py` §[6] 实测）。
  若另加批次层面的 cluster-robust 推断，自由度仍受**群数**限制（G − 2 = 5），
  因此主分析用批次固定效应 + HC3，**另报告 CR2/Satterthwaite 作为敏感性**并如实说明
  其自由度只有约 5，不据此做确证性宣称。
- **报告 ICC**：即使方案 B，也应报告批次内相关，以验证"设计效应接近 1"的假设；
  若 ICC 明显大于 0（如 > 0.05），应改用整群稳健方差或随机效应模型。
- **外溢敏感性分析**：按"对照组自报是否接触干预内容"分层比较。

> **重要**：方案 B 的"组别效应"估计的是**同一批次内、同一教师下**的差异。
> 它不能直接外推到"整批采用新教学"的情景（那正是方案 A 估计的量）。
> 两种设计估计的是**不同的因果量**，不能互相替代，也不能把方案 B 的结果
> 写成"整批改革有效"。

#### 3.3.6 为什么推荐方案 B

1. **批次固定效应可估**：每批内部两组并存，批次间的季节/教师/病例差异可被吸收，
   而方案 A 中组别与批次完全共线（§3.2.5）。
2. **人数更平衡**：24 vs 25（方案 A 为 21 vs 28），以较小臂规划时最小可检出 d
   从 0.865 降到 0.809（`sample_size.py` §[6]）。
3. **每批都产生两组数据**，7 天/批的短周期下不必跨批等待。
4. **随机化支持置换检验**：批内 3+4 分配使**分层置换检验**（`E5_02` §3.5）
   在原理上成立，而整群分配下没有可置换的批内变异。

**代价**是**同批外溢**——本方案把"群数不足"换成了"外溢稀释"，前者使研究无法推断，
后者使效应被低估但方向保守。**这个取舍必须在 D1 前由教研室书面确认。**

### 3.4 49 人规模下的定位：探索性 + 可行性

**现实约束**：49 名见习学生，方案 B 两组等分即 **24 vs 25 人/组**。
`scripts/grant/sample_size.py` §[2]、§[6] 的实际计算：

| n/组 | 80% 功效最小可检出 d | 若真实 d=0.50 的功效 | 若真实 d=0.60 的功效 |
| --- | --- | --- | --- |
| 21 | 0.865 | 0.344 | 0.469 |
| 24 | 0.809 | 0.389 | 0.526 |
| 25 | 0.792 | 0.404 | 0.544 |

> **诚实的结论：在 49 人（每臂 24–25 人）的规模下，两组设计只能检出 d ≈ 0.8 以上的大效应；
> 对中等效应（d ≈ 0.5）功效只有 0.39–0.40。**
> 因此本研究的主要目的是**可行性与信号生成**，不是确证性优效检验。
> 任何把 d = 0.5 写成"本研究预期效应"的表述都是不诚实的。

**本研究能得出什么、不能得出什么：**

| 能得出 | 不能得出 |
| --- | --- |
| 招募率、保留率、评分者 ICC、数据完整性、平台可用性等可行性参数 | 确证性的"ClinPath 优于 CBL"结论 |
| 效应量的**点估计与区间**（原始分 + 标准化） | 对 d ≈ 0.5 的中等效应作出有把握的检验 |
| 批次内相关（ICC）的估计，为后续研究提供参数 | 整批改革（方案 A 的因果量）的外推结论 |
| 训练轨迹、参与度与平台运行事实（AI 降级比例等） | 长期保持（7 天窗口内无法测保持） |

> **共同要求**：
> 1. 明确写出"本研究为**探索性/可行性研究**，不以确证性优效检验为目的"；
> 2. 主要报告**可行性指标**与**效应量的点估计及区间**，而不是"是否显著"；
> 3. 不因结果不利而改换主要结局或分析模型（§12.2）。

> **若希望最终达到可推断的规模**，唯一路径是**多中心或多届累积**
> （每年 49 人，累积 3–5 届），见 §4.4.2。该路径的代价是研究周期，
> 是否接受由教研室与科研管理部门决定。

### 3.5 两种设计的已知局限（必须在申报书与论文中如实写明）

| 局限 | 后果 | 本方案的应对 |
| --- | --- | --- |
| 非随机分配（方案 A） | 批次、带教教师、轮转季节与组别混杂 | 批次作为随机效应；报告 ICC 与群数；群数少时降级为探索性 |
| 整群设计且群数少（方案 A） | **无法支持确证性组间检验** | §3.2.5 硬约束；报告 ICC 与描述性结果 |
| 同批同伴外溢（方案 B） | 组间差异被稀释；阴性结果无法区分"无效"与"污染" | 错开时间；记录外溢程度；敏感性分析 |
| 前后测的练习效应 | D6 可能因熟悉题型而偏高 | D1/D6 使用不同病例；评分者不知时间点；敏感性分析比较两组增益 |
| **7 天窗口过短** | 学习增益可能很小，无法检出；无法测保持 | **§5.4 如实写明**；定位为可行性 + 信号生成 |
| 霍桑效应 | 干预组因"被关注"而表现更好 | 对照组同样接受等量教师关注与平台账号（§5.5）；局限中说明无法完全排除 |
| 单中心 | 外推性受限 | 明确写为单中心研究；不做跨院校推广结论 |
| 评分者主观性 | 主结局测量误差 | 两位教师独立盲评 + 一致性报告 + 分歧裁决规则（见 §6） |
| 无法盲学生与教师 | 期望偏倚 | 仅结局评分者盲法；在局限中说明 |
| 规模不足 | 只能检出大效应 | 明确定位为可行性 + 信号生成（§3.4） |

### 4.1 纳入标准

### 4.3 研究人群（**两个人群，不得合并**）

| 人群 | 规模 | 来源 | 在主结局分析中的地位 |
| --- | --- | --- | --- |
| **主研究总体** | **49 人** | 风湿免疫本科见习 7 天/批 × 7 人/批 × 7 批 | **主结局分析的对象** |
| **扩展人群** | **21 人** | 见习 + 实习合计 70 人中，除 49 名见习学生外的实习阶段学生 | **独立分析或仅描述，绝不并入主结局** |

**关于扩展人群的诚实说明（`待院系与教研室确认`）：**

- 这 21 名学生的**确切学段**（实习年级/阶段）与**是否与 49 名见习学生完全重叠**
  **尚未确认**。本文件不假设二者互斥，也不假设二者可比。

  研究样本量是 **49 人**。

### 4.4 样本量与分组方案（**全部为 `待院系与教研室确认`**）

本文件采用教研室已确认的真实条件：**7 天/批、7 人/批、7 批 = 49 名见习学生**。

**关键前提：主要结局是独立教师盲评（§7.1），不是平台形成性评分。**
样本量由**盲评的测量精度**约束：评分者一致性（ICC）越低，同样的学生人数提供的
有效信息越少。若两位评分教师的 ICC 只有 0.6，主结局的测量误差会显著侵蚀功效；
这也是必须在 D1 之前做评分者校准的原因（§6.2 第 6 条）。

#### 4.4.1 49 人规模下的功效上限（实测）

`scripts/grant/sample_size.py` §[6] 的实际输出（方案 B，24 vs 25 人/组，双侧 α=0.05）：

| 项目 | 值 |
| --- | --- |
| 主研究总体 | 7 批 × 7 人 = **49 人** |
| 方案 B 两组人数 | ClinPath **24** / CBL **25** |
| 以较小臂 n=24 规划：80% 功效最小可检出 d | **0.809** |
| 若真实 d=0.50 的功效 | **0.389** |
| 若真实 d=0.60 的功效 | **0.526** |
| 若真实 d=0.70 的功效 | **0.660** |
| 方案 B 主模型参数个数 / 残差自由度 | 9 / **40** |

方案 A（3 批 vs 4 批 = 21 vs 28 人）：

| 项目 | 值 |
| --- | --- |
| 以较小臂 n=21 规划：80% 功效最小可检出 d | 0.865（未计设计效应） |
| 设计效应（每批 7 人，ICC=0.05 / 0.10 / 0.20） | 1.30 / 1.60 / 2.20 |
| 全部 49 人的有效样本量（ICC=0.20） | 约 22.3 人 |
| 组别效应的可用自由度（G−2） | **5**（t₀.₉₇₅ = 2.571，是正态的 1.31 倍） |
| wild cluster bootstrap 双侧 P 下限（G=7） | 2/128 = **0.0156** |

> **诚实结论：在 49 人、每臂 24–25 人的规模下，两组设计只能检出 d ≈ 0.8 以上的大效应。
> 检出 d = 0.5 需要 64 人/组（`sample_size.py` §[1]，t 修正），是当前规模的 2.6 倍。**
> 因此本研究的定位是**可行性 + 信号生成**（§3.4），不是确证性优效检验。

#### 4.4.2 可选路径（教研室按排课现实选择）

| 路径 | 结构 | 人数 | 能否做确证性检验 | 需要的条件 |
| --- | --- | --- | --- | --- |
| **单届（方案 A）** | 7 批次整群，3 批 vs 4 批 | 21 vs 28 | 否（群数 = 7，每臂 3–4） | 无（最省事，但推断能力最弱） |
| **单届（方案 B，推荐）** | 每批 7 人内 3+4 随机 | 24 vs 25 | 否（探索性，但可估批次固定效应） | 教研室同意批内拆分与并行教学 |
| **多届累积（方案 B）** | 每年 49 人，累积 3–5 届 | 累积 147–245 | **可能**，取决于最终人数与 ICC | 跨年度持续排课与稳定团队 |
| **单组前后测（备选）** | 全部 49 人只接受干预，无同期对照 | 49 | 否 | 无对照，只能描述前后变化 |

- **单届方案 A / 方案 B 都在本项目规模下实际可交付**，但都只能得出可行性参数与效应信号，
  不能得出确证性组间结论。选择它们时，申报书必须如实写明"探索性"。
- **多届累积**是唯一可能达到确证性的路径，代价是研究周期拉长到 3–5 年，
  且需要每年稳定排课、稳定团队、稳定平台版本。**是否接受这一周期由教研室与
  科研管理部门决定**，本文件不预设。

> **必须由教研室决定的问题是"分组单位"**（方案 A 还是方案 B）：
> - **方案 A（整批）**：行政最省事，但群数只有 7，无法分离批次与组别效应；
> - **方案 B（批内 3+4，推荐）**：可估批次固定效应、人数更平衡，但有同批外溢。
>
> 该项**必须在预注册前定下来**，且必须与 `E5_02` SAP 的主模型一致。

## 5. 干预与对照（7 天循环）

### 5.0 7 天循环总览（**待教研室确认的建议流程，不是已执行的排课**）

> 下表是**建议流程**，用于说明"在 7 天内可以做哪些教学动作"。
> 它**不是**已确定或已执行的课表；实际排课、课时与病例数由教研室确认。

| 日 | 学生做什么 | 教师做什么 | ClinPath 功能 | 教师接触时间 |
| --- | --- | --- | --- | --- |
| **D1** | **T0 独立标准化病例考核**（60 min，闭卷） | 监考、收卷；**不参与评分** | 无（或仅提交入口） | 10 min（监考） |
| **D2** | 基础病例推理训练：训练病例 1（如 SLE），**5 步全做** | 集体讲解训练规则；不介入作答 | 五步推理、导师追问、形成性反馈 | 15 min（规则讲解） |
| **D3** | 基础病例推理训练：训练病例 2（如 RA），5 步全做 + 至少 1 步修订 | 集体反馈（共性错误） | 同上 + 学习证据记录 | 15 min（集体反馈） |
| **D4** | **个性化强化**：完成平台按短板推荐的训练病例 3（5 步） | **逐个学生针对性反馈**（≥5 min/生） | **能力画像 → 推荐服务 → 学习证据 → 教师干预**（§5.3） | ≥35 min（7 生 × 5 min） |
| **D5** | **个性化强化**：完成推荐的训练病例 4（5 步）或对薄弱步骤再训练 | 逐个学生针对性反馈（≥5 min/生）；确认薄弱维度 | 同上 + 教师确认评分 | ≥35 min |
| **D6** | **T1 独立标准化病例考核**（60 min，闭卷） | 监考、收卷；不参与评分 | 无 | 10 min（监考） |
| **D7** | 填问卷、教学反馈、学习小结 | 组织问卷、收尾 | 问卷 | 20 min |

**对照组（常规 CBL）在同一 7 天内接受等量课时与等量教师关注**（§5.5）：
D2–D5 由同一教师主持常规病例讨论，病例主题范围与干预组一致，
但**不使用**平台的分步训练与导师追问。

**评分时点说明**：D6 考核结束后，两位盲评教师**统一**对 D1 与 D6 的全部作答评分，
评分材料中**不标注时间点**（§6.2）。因此评分可在 D7 之后进行，不影响 7 天教学循环。

### 5.1 干预组：ClinPath 分步形成性训练

学生在平台内完成风湿免疫病例训练，每次训练固定包含**五个推理步骤**
（平台唯一事实源 `backend/app/core/reasoning_steps.py`，`REQUIRED_REASONING_STEPS`）：

| 步骤 | 平台 canonical 标题 | key |
| --- | --- | --- |
| 1 | 关键信息提取 | `key_information` |
| 2 | 初步诊断及依据 | `initial_diagnosis` |
| 3 | 鉴别诊断 | `differential_diagnosis` |
| 4 | 进一步检查 | `examination` |
| 5 | 治疗方案 | `treatment` |

每一步：

- 学生提交自己的作答（`student_answers`，`(session_id, step)` 唯一，`docs/ARCH.md` §6）；
- 平台按步骤状态给出**形成性追问**（AI 导师或规则追问），每次只问一个问题，
  不透露标准诊断、标准治疗或评分量表；命中泄漏防护时自动改用规则问题并记录
  （`backend/app/services/tutor_service.py`：`next_tutor_question`、`leaks_hidden_answer`、
  `_rule_question`；每步追问轮次上限 `MAX_TUTOR_TURNS_PER_STEP = 6`）；
- 学生可修订作答，修订与初次作答都被保留（形成学习轨迹，`reasoning_steps` 表）；
- 训练结束后由平台给出**形成性**反馈（`backend/app/services/scoring_llm.py`），
  教师可复核与确认（`POST /api/teacher/reviews`，`teacher_score_reviews` 表）。

**AI 的边界（写入方案与伦理申请）**：

- AI 反馈是**形成性**的，不是成绩；最终评价由教师确认；
- 模型不可用时平台自动降级为规则反馈，并显式标记 `rule_fallback`，
  **绝不把规则输出呈现为 AI 输出**（`evaluation_mode` 枚举，见数据字典 §5）；
- 每一次 AI 调用都留下 `ai_invocations` 审计事件（只含元数据与证据引用，
  不含 prompt / response 正文，`backend/app/models.py` `AIInvocation`）；
- **AI 评分不作为本研究的主要结局**（见 §7.1）。

### 5.2 最低有效训练剂量（**教学可行性下限，非循证有效剂量**）

> **诚实前提**：教育干预没有公认的"最低有效剂量"。下表给出的是
> **在 7 天内教学上可交付、且能让平台形成性循环真正运行起来的下限**，
> 不是"已经证明有效"的剂量。真实有效剂量未知，须由预试验估计。

| 剂量要素 | 最低要求 | 建议目标 | 依据 |
| --- | --- | --- | --- |
| 完成的训练病例数 | **≥ 3 例** | 4 例 | 平台现有 4 个训练病例（`workpackages/A_cases/A01_case_index.md`：CASE-T01～T04） |
| 每例完成的推理步骤 | **5 步全做** | 5 步全做 | `reasoning_steps.py` 要求提交前五步齐备 |
| 步骤作答提交总数 | **≥ 15 次**（3 例 × 5 步） | 20 次 | 每步 1 次提交 |
| 导师追问轮次 | **≥ 1 轮/步，共 ≥ 15 轮** | ≥ 20 轮 | 每步至少触发 1 次追问 |
| 作答修订次数 | **≥ 3 次**（每例 ≥ 1 步修订） | ≥ 4 次 | 体现"追问→修订"闭环 |
| **个性化推荐驱动**的病例 | **≥ 1 例**由推荐服务产生 | ≥ 2 例 | §5.3 第 2 步 |
| 教师针对性反馈 | **≥ 1 次/生，≥ 5 min** | 2 次/生 | §5.3 第 4 步 |

**对照组等量安排**：对照组在同样的 D2–D5 内完成等量课时的常规病例讨论
（同样覆盖 ≥3 个风湿免疫常见病例主题），并接受等量教师接触时间，但不使用平台分步训练。

### 5.3 必须真正运行的"个性化循环"（**不是统一刷题**）

> **要求**：干预组的训练**不得**退化为"给所有学生推同一批病例、做完就算"。
> 必须能证明下列四步**真的运行过**，且每一步都留有可核查的记录。
> 这四步对应平台中**已实现**的功能（下方逐条给出代码位置）。

| # | 环节 | 学生/系统做什么 | 平台已实现的功能（代码位置） | 留下的记录 |
| --- | --- | --- | --- | --- |
| 1 | **基线能力识别** | 学生完成 D1/D2 的病例后，平台按六维能力更新其能力画像 | 能力画像 `CompetencyProfile`（`backend/app/models.py`）；按学习证据更新 `update_competency_from_case()`（`backend/app/services/competency_update_service.py`），投影权重 `UPDATE_WEIGHT = 0.3`（`backend/app/services/competency_projector.py`）；读取入口 `GET /api/students/{id}/dashboard`（`backend/app/routes/students.py`） | `competency_profiles` 六维分数 + `learning_evidence_events` |

> 该学生的"个性化"要素视为**未执行**，须在报告中如实标注。

### 5.4 7 天是否足够？——诚实评估（**必须写入申报书与论文局限**）

**结论：7 天很可能只能产生小幅增益，这从根本上限制了本研究能得出的结论。**

理由：

1. **时间窗口短**。7 天内训练剂量上限约 3–4 例病例、15–20 步作答。
   教育干预的常见效应（d ≈ 0.2–0.5）在如此短的暴露下可能进一步缩小；
2. **可检出的效应门槛高**。49 人、每臂 24–25 人时，80% 功效最小可检出 d ≈ 0.81
   （§4.4.1）。若 7 天内的真实效应小于此，研究**大概率得到阴性结果**，
   而阴性结果**不能**被解释为"ClinPath 无效"——它更可能反映**窗口太短、剂量不足**；
3. **练习/成熟效应与真实增益混淆**。D1 → D6 相隔 5 天，学生在此期间还会参加
   其他见习活动，D6 的提升可能部分来自练习效应与常规教学，而非平台干预；
4. **无法测保持**。7 天结束即轮转结束，本研究**不能**回答"增益能否保持"。

**因此本研究对自身的定位是：**

- 这是**可行性研究**：回答"在 7 天真实排课下，这套训练与评价流程能否跑通、
  评分是否可靠、数据是否完整"，而不是"ClinPath 是否显著有效"；
- 主要报告**可行性指标 + 效应量点估计与区间**，不做确证性优效宣称；
- 若结果为阴性，必须**并列陈述"窗口过短/剂量不足"与"干预无效"两种解释**，
  不得只写后者。

### 5.5 对照组：常规 CBL

对照组接受**与干预组等量课时、等量教师关注**的常规病例讨论：

- 同样的病例主题范围（风湿免疫常见病），同样覆盖 ≥3 个病例；
- 同样的 7 天周期与讨论次数；
- 同样的 D1/D6 独立病例考核；
- **不**使用平台的分步训练与导师追问。

为减少"仅因多接触教师"造成的差异，对照组**同样获得平台账号**，
可访问非本研究的常规学习材料（知识单元、指南摘要），但**不开放**
分步病例训练与导师追问模块。是否允许对照组在见习结束后补做训练，
由教研室决定（建议允许，并在方案中写明"延迟开放"）。

> 对照组是否应接受"主动对照"（如另一种结构化反馈）是设计上的取舍。
> 本研究选择"常规 CBL"作为对照，因为它代表**当前教学的真实替代方案**；
> 代价是组间差异无法区分"平台"与"结构化分步反馈"各自的贡献。此局限必须写明。

### 5.6 两组共同事项

- 同一套评分量表、同一批评分教师、同一批 D1/D6 病例；
- 同一份知情同意与退出机制；
- 同一套数据采集字段（见 `E5_protocol_data_dictionary.md`）。

### 6.1 谁被盲

| 角色 | 是否盲 | 说明 |
| --- | --- | --- |
| 学生 | 否 | 无法对干预内容设盲；在局限中说明 |
| 带教教师 | 否 | 知道自己所带学生的分配；不参与结局评分 |
| **结局评分教师** | **是（双盲）** | 独立病例由**两位真实教师**独立评分，**不知学生组别、不知 D1/D6** |
| 统计分析人员 | 部分 | 分析脚本在数据锁定前写好并版本化；组别变量在分析时以 A/B 编码，出结果后揭盲 |

### 6.2 评分流程

1. D1/D6 的作答以**匿名研究编号**提交，评分材料中**不出现**姓名、学号、班级、组别、
   时间点；
2. 两位评分教师**各自独立**按六维量表评分，互不商议；
3. 记录 `rater_A_total`、`rater_B_total`、`independent_total`（两人均分或裁决后分数，
   规则须在 D1 之前固定）；
4. 计算评分者一致性（ICC(2,1) 或加权 kappa，按量表性质），**在方案中预先声明**；
5. 分歧超过预设阈值（建议 ≥ 10 分，待确认）时由第三位教师裁决，裁决记录留痕；
6. 评分者培训：D1 之前用**合成作答样例**做一次校准评分，
   记录校准结果（这只证明评分流程可用，不构成真实学生数据）。

## 7. 结局指标

### 7.0 结局层级（**先读这一节**）

本研究区分**三个来源**的分数，它们的地位完全不同，不得混用：

| 来源 | 产生方式 | 在本文中的地位 | 是否进入主分析 |
| --- | --- | --- | --- |
| **独立教师盲评** | 两位不知组别、不知时间点的真实教师，按六维量表对 D1/D6 独立病例作答评分 | **主要结局** | **是** |
| 平台形成性评分（`training_score_internal`） | 平台按六维权重对训练作答自动打分 | **过程/次要指标** | **否** |
| AI 评分（如存在） | 模型对作答的评分 | **过程指标，仅描述** | **否** |

> **主要结局是独立教师盲评，不是平台形成性评分。**
> 平台形成性评分是**过程指标**：它衡量"学生在平台上的训练表现"，
> 而主要结局衡量"学生在独立病例上的推理能力"。两者不能互相替代，
> 也不能把平台分数的变化写成教学效果。原因有三：
> 1. 平台评分与训练内容同源（"教什么考什么"），存在构念污染；
> 2. 平台评分由规则或模型产生，其可靠性未经独立验证；
> 3. 平台评分在对照组中**不存在**（对照组不使用训练模块），无法做组间比较。
>
> 因此平台评分只在干预组内描述训练轨迹，**不参与任何组间效应估计**。

### 7.1 主要结局

**D6 独立标准化病例总分（0–100），由两位真实教师独立盲评。**

- 测量时点：D6（训练期结束后）；
- 基线协变量：D1 同一量表、同一批评分教师的盲评总分；
- 病例与训练库**不重复**，评分者不知组别与时间点；
- **不使用平台内部形成性评分**（`training_score_internal`）作为主要结局；
- **不使用 AI 评分**作为主要结局。若平台同时产生 AI 评分，只作为过程指标报告，
  并标注其 `evaluation_mode`。

**测量精度是功效的约束条件**：主要结局的可靠性由评分者一致性决定。
若两位评分教师的 ICC 只有 0.6，则主结局的有效信噪比显著下降，
相当于损失可观的有效样本量。因此：

- 评分者校准必须在 D1 之前完成，并报告校准 ICC；
- 主分析必须报告评分者一致性 ICC 及其 95% CI；
- 若 ICC 低于预设阈值（建议 0.75，`待确认`），主要结论降级为探索性。

### 7.2 次要结局

| 类别 | 指标 | 来源 | 说明 |
| --- | --- | --- | --- |
| 六维度 | 医学知识运用、关键信息提取、鉴别诊断与论证、临床证据整合、检查与临床决策、循证依据与安全意识（各 0–100） | **同一份 D6 教师盲评** | 与平台 `CORE_ABILITIES` 对应；**权重必须在 D1 前固定**（见 §13 注） |
| 学习轨迹 | 每步骤作答次数与修订次数、导师追问轮次、完成状态 | 平台 `student_answers` / `tutor_turns` / `reasoning_steps` | 只描述过程，不用于主要推断 |
| **平台形成性评分** | `training_score_internal`、AI 评分（如存在） | 平台评分记录 | **过程指标**：只在干预组内描述训练表现，**不做组间比较** |
| 能力投影 | 平台加权能力投影（`new = old×0.7 + module×0.3`） | `learning_evidence_events` 重放 | 这是**可审计的投影**，不是"数字孪生"，不得包装为全局胜任力 |
| **个性化执行度** | 推荐病例数、推荐理由是否命中最弱维度、教师反馈次数与时长 | `learning_recommendations` / `teaching_interventions` | 用于核查 §5.3 的四步是否真的运行 |
| 参与度 | 完成的训练次数、每次用时、是否完成全部步骤 | 平台会话记录 | 需在方案中预先定义"完成" |
| 可行性 | 招募率、脱落率、平台故障次数、AI 降级比例、**评分者 ICC**、**批次 ICC** | 研究日志 + `ai_invocations` | 为后续研究提供依据 |

### 7.3 不设为结局的内容

- 患者临床结局（本研究不涉及患者）；
- 平台页面访问量、点击量（可作描述性使用，不作效果指标）；
- **平台形成性评分作为组间效果指标**（对照组无训练模块，无法比较）；
- 任何合成演示数据中的数值（见 §12.3）。

## 8. 时间线与流程（7 天循环）

```
（时间点均为相对描述；绝对学期 `待院系与教研室确认`）

伦理审批 ──► 预注册 ──► 评分者校准 ──► 分组方案书面确定（方案 A 或 B）
                                              │
                                              ▼
        D1  T0 独立病例考核（基线，闭卷）
        D2  训练病例 1（基础）
        D3  训练病例 2（基础）+ 共性反馈
        D4  个性化强化病例 3 + 教师针对性反馈
        D5  个性化强化病例 4 + 教师针对性反馈
        D6  T1 独立病例考核（同一批评分者，盲法）
        D7  问卷、教学反馈、学习小结
                                              │
                    D1/D6 作答统一盲评（评分者不知时间点）
                                              │
        数据锁定 ──► 统计分析（按预注册 SAP）──► 报告
```

**关键控制点**

1. **D1 必须在训练开始前**完成，不得在训练中途补测；
2. **D1 与 D6 使用不同病例**，且两例难度在评分者校准阶段确认可比；
3. **D1/D6 的作答统一在 D6 之后一起盲评**，评分者不知道哪份是 D1、哪份是 D6；
4. 数据锁定前不得查看组间比较结果（可查看数据完整性与缺失模式）；
5. 任何方案偏离在发生时记录，不做事后修改（见 §12）。

### 8.1 考核题本顺序：交叉反平衡（**必须在 D1 前完成分配**）

两份独立考核病例 **CASE-A01（未分化多关节炎）** 与 **CASE-A02（成人 Still 病伴 MAS 风险）**
经逐维比较后判定**难度不可比**：A02 在推理步数、危险信号数量与性质、检查深度、
治疗与安全决策复杂度上均高于 A01（完整证据见
`workpackages/A_cases/A04_assessment_quality_control.md` §1）。

若所有学生"T0 固定用 A01、T1 固定用 A02"，则 T1 − T0 会同时包含**学习增益**与
**病例难度差**，而难度差与时间点**完全共线**，无法从数据中分离。

**处置**：采用**交叉反平衡**——每名学生在两个时点各做不同的一例：

| 顺序 | D1（T0） | D6（T1） |
| --- | --- | --- |
| **顺序 X** | CASE-A01 | CASE-A02 |
| **顺序 Y** | CASE-A02 | CASE-A01 |

- 顺序 X 与顺序 Y 在**每个组内、每个批次内**尽量均分（精确分配表见 `A04` §2.3）；
- 顺序分配与组别分配**相互独立**，均在 D1 前完成并写入分配记录；
- 主模型加入 `form_T1`（T1 所用病例）吸收残余难度差异（`E5_02` §2.2.2）；
- **代价**：每名学生在两个时点做不同病例，`T1 − T0` 同时含增益与难度差；
  反平衡在**组间**抵消难度差，但不减小方差；若要检验"顺序 × 组别"交互，
  每格人数不足（49 人 ÷ 7 批 ÷ 2 组 ÷ 2 顺序 ≈ 每格 1.75 人），只能描述、不作推断。
- 若教研室最终不采用反平衡，必须在预注册中写明，并把"病例难度差"列为
  无法排除的混杂（`A04` §1.3 选项 1/2 提供了修改病例的两条替代路径）。

| --- | --- |
| 选择偏倚（方案 A 非随机） | 分配在 D1 前书面确定；比较两组基线特征并报告标准化差异 |
| **批次/季节混杂** | 方案 B：批次作为**固定效应**直接吸收；方案 A：批次作为随机效应，报告 ICC 与群数 |
| **教师效应** | 尽量让每位教师两组都带；做不到时如实写明教师与组别混淆 |
| **同批外溢**（方案 B） | 两组错开使用平台；约定不共享训练内容；记录并报告外溢程度 |
| 实施偏差 | 统一病例范围、统一训练剂量（§5.2）、统一平台版本；记录平台版本与 SHA |
| 测量偏差 | 双人盲评、评分者校准、一致性报告、分歧裁决 |
| **主要结局测量误差** | 报告评分者 ICC；ICC 低于阈值时主结论降级为探索性 |
| 退出偏倚 | 记录退出原因与时间；ITT 为主分析，PP 为敏感性分析 |
| 期望偏倚 | 无法消除；在局限中说明，并报告学生与教师对分配的知晓情况 |
| 分析偏倚 | SAP 预注册；分析脚本版本化；主要分析先于次要分析执行 |
| **把过程指标当效果指标** | 平台形成性评分只在干预组内描述，不做组间比较（§7.0） |
| 平台不可用 | 记录每次故障与 AI 降级；若故障率过高，报告为可行性结果而非效果结论 |
| **7 天窗口过短** | §5.4 如实写明；阴性结果不得单独解释为"无效" |

## 10. 缺失数据处理原则

1. **主分析采用意向性分析（ITT）**：只要学生完成了 D1 且有分配，即纳入；
2. **缺失机制**：记录缺失原因（未参加 D6、作答不完整、评分缺失、技术故障），
   区分"完全随机缺失"与"与结果相关缺失"；
3. **多重插补**为主（链式方程，m = 20，插补模型含基线分数、批次、组别、
   参与度；具体见 E5-02 §5）；
4. **完整病例分析**作为敏感性分析，两者结论不一致时如实报告；
5. **不填补主要结局的整例缺失**（未参加 D6 的学生不伪造后测），
   而是通过多重插补在模型层面处理，并报告缺失比例；
6. 缺失比例 > 20% 时，主要结论降级为"探索性"。

## 11. 数据管理

### 11.1 匿名研究编号

- 每名参与者分配 **`study_id`**（如 `R-2027-001`），**不使用姓名、学号、身份证号**；
- 唯一连接表（`study_id ↔ 学号`）**单独存放**，与研究生数据集物理分离，
  仅研究负责人可访问，权限最小化；
- 分析数据集**不含**连接表字段。

### 11.2 存储位置与访问控制

| 数据 | 存放位置 | 访问者 |
| --- | --- | --- |
| 研究主数据集（去标识） | 依托单位指定的加密存储（`待院系与教研室确认`具体位置） | 研究负责人、统计人员 |
| 连接表 | 独立加密文件，与主数据集不同目录/不同账号 | 仅研究负责人 |
| 平台运行数据 | ClinPath 生产库（`students` / `case_sessions` / `learning_evidence_events` 等） | 平台管理员、教师（按角色） |
| 原始评分表（含签名） | 纸质/扫描件，锁存 | 研究负责人 |

- 生产库**不写入**研究专用字段（如 `data_origin`、`consent_status`）；
  研究字段在导出后的研究数据集中生成（见数据字典 §5）；
- 导出必须走**已实现的匿名导出路径** `/api/teacher/export/research-data.csv`，
  该路径只输出 `S<student_id:04d>` 与班级，**不输出姓名**；
- 任何研究用导出都要在文件名与首列标注数据来源。

### 11.3 保存年限

研究数据保存 **`待依托单位科研管理部门确认`**（建议不少于论文发表后 5 年，
或按单位规定）；到期后销毁并记录销毁方式与日期。

### 11.4 撤回同意

学生可在任何时间撤回，且**不影响其课程成绩**。撤回后：
- 不再采集新数据；
- 已采集的去标识数据是否删除，按伦理批件与知情同意书写明的规则执行
  （建议：可识别信息删除；已进入汇总分析的匿名数据保留，但需在同意书中事先说明）；
- 撤回记录本身（日期、范围）保留，用于报告脱落。

## 12. 预注册与偏离报告

### 12.1 预注册

在**第一名学生完成 D1 之前**完成预注册，建议平台为中国临床试验注册中心（ChiCTR）
或 OSF Registries（`待确认`）。预注册至少包含：

- 研究题目、设计、纳入/排除标准；
- **分组方案（方案 A 批次整群 / 方案 B 批内 3+4）与选择理由**；
- **研究定位**（探索性可行性研究）；
- **7 天循环的每日安排与最低训练剂量**（§5.0、§5.2）；
- **批次固定效应是否可估**（方案 B 可估，方案 A 不可估，§3.3.5）；
- 主要与次要结局的**精确定义**（明确主要结局为独立教师盲评）；
- 样本量方案（49 人，24 vs 25 或 21 vs 28）与依据；
- 主要分析模型（`Y_T1 ~ G + Y_T0 + batch`）与置换检验方案（`E5_02` §3.5）；
- 多重比较策略；
- 缺失数据处理；
- 分配规则、随机化种子与分配隐藏方式。

### 12.2 偏离报告

- 任何与预注册不一致的改动，在**发生时**记入偏离日志
  （日期、内容、原因、是否影响主要结局、谁批准）；
- 论文与结题报告必须列出全部偏离；
- **禁止**在看到结果后更换主要结局、更换主要分析模型、或删除预先声明的协变量；
- **禁止**在样本量不足、结果不显著时把研究"改称"确证性研究；
  探索性定位必须在预注册时就写明。

### 12.3 与合成演示的关系（重要）

`demo_research/synthetic_v1/` 中的统计结果**不是**预注册依据，也**不是**效应量来源：

- 演示数据由 `generate_demo.py` 以种子 20261018 生成，
  组间差异是脚本的**输入参数**（`nominal_CBL_gain = 6`、`nominal_CLINPATH_gain = 18`）；
- 演示中的 P 值（Welch P ≈ 8.59×10⁻²⁰、ANCOVA HC3 P ≈ 1.41×10⁻⁴⁰）
  只证明**统计流程可以跑通**，其大小完全由预设参数决定；
- **演示数据折算出的 d = 3.57 是生成器参数**，不是效应估计。
  它在任何真实教学干预中都不可能出现，**禁止**用于样本量规划、功效陈述
  或"预期效果"表述；
- 样本量规划的效应量必须来自**预试验或文献**，不得引用演示数据（见 `E5_02` §7.6）。
