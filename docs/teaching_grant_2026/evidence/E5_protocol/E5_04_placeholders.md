## 2. 本轮（第四轮）相对第三版的变化

**占位符集合不变（仍为 12 项 P01–P12），正文各占位符原文逐字未改。** 第四轮的变化集中在研究设计的表述，不改变需要院系 / 教研室 / 伦理提供的信息：

| 变化 | 说明 |
| --- | --- |
| 研究设计固定 | 正文研究设计固定为 **7 批次整群分配**（预先固定 3 批 ClinPath / 4 批常规 CBL，从 C(7,3)=35 种合法分配中随机产生）；删除第三版"分组可在批次间整群或在批次内随机，方案由教研室书面选定"的开放表述 |
| 举措六改写 | 删除方案 B 及班内分组相关表述；补入"精确随机化检验 P 取 k/35、最小值取决于数据（不再宣称恒为 2/35）、仅探索性"的诚实限制 |
| 术语统一 | 基线 / 终末独立考核统一记作 **D1 / D6**（原 T0 / T1） |
| 前期准备改写 | §五"确定分组方案与批次安排"改为"完成 7 批次整群分配并封存分配记录" |
| §六教学组织支持 | "分组方案"改为"整批分配方案" |
