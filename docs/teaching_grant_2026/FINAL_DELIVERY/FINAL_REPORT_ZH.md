## 6.2 最终架构

三个逻辑域并列，只在用户身份层相见（权威描述见 `docs/ARCH.md` §19—§20）：

```
Training（形成性训练）        Assessment（独立在线考核）      Research（教学研究管理）
Case/CaseSession/Score       AssessmentForm(+Review)        StudyCohort/StudyAllocation
CompetencyProfile            AssessmentSitting/Answer      整批随机化(35 种)·题本顺序 X/Y
LearningRecommendation       AssessmentReview(双教师盲评)    精确随机化检验·ICC·冻结
教师反馈与干预               Adjudication/DatasetLock        受控导出（研究编码）
        └──── 共享：用户身份与基础信息 ────┴── 只读/受控关联 ──┘
```

隔离不是靠约定，而是**结构 + 测试**双重固定：

1. `app/assessment/` 的 import 面只有 `get_current_user`、`User`/`Student`、`get_db` 与纯函数 `app.research`；
   **不 import** `Score`、`CompetencyProfile`、`LearningRecommendation`、`CaseSession`、`ai_policy` 或任何模型客户端。
2. `test_assessment_isolation.py` 在 `python -I` 隔离子进程中导入考核模块，断言训练/AI 模块**从未被加载**。
3. 考核路径**没有任何 AI 调用**——因此不存在「AI 不可用需降级」的分支，也不产生 `ai_invocations`。

详见 `ARCHITECTURE.md`。
