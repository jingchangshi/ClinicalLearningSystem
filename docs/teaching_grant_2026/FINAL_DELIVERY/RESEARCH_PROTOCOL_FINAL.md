# 研究方案终稿指引（RESEARCH_PROTOCOL_FINAL）

> 本文件**不复制**方案正文，避免出现相互矛盾的两个版本。研究方案的唯一正文是
> `../evidence/E5_protocol/E5_01_research_protocol.md`（v3.1，终稿轮）；统计分析见 `STATISTICAL_ANALYSIS_PLAN.md`；
> 伦理与隐私见 `../evidence/E5_protocol/E5_03_ethics_privacy.md`；7 天教学计划见 `../evidence/E5_protocol/T2_7day_teaching_plan.md`。
> 项目名称：《基于人工智能辅助临床推理训练的医学生个性化学习与形成性评价教学改革研究》

## 固定的设计要点（一页）

| 项 | 固定内容 | 出处 |
| --- | --- | --- |
| 人群 | 主要研究人群 49 名本科见习生（7 批 × 7 人）；见习+实习合计 70 人，其余 21 人**是否与 49 人重叠由申请人确认（未确认）** | E5-01 §4.3 |
| 教学单元 | 每批 7 名学生是完整教学单元，不得拆分 | E5-01 §3.1 |
| 分配 | 预先固定 3 批 ClinPath、4 批常规 CBL，从 C(7,3)=35 种整批分配中等概率随机抽取；记录算法、种子、执行人、时间、方案版本，封存后不得重抽 | E5-01 §3.1.1、§3.1.2 |
| 备选 | 教研室不允许随机时改为整群准实验（`quasi_experimental`），不再生成随机化检验结论 | E5-01 §3.3 |
| 题本顺序 | X：T0=A01, T1=A02；Y 反之；每批内约 4/3；**先冻结题本顺序，再抽教学组**；两个随机化过程不同 | E5-01 §8.1 |
| 流程 | D1 T0 独立在线考核 → D2—D3 训练建画像 → D4—D5 依据 D2/D3 证据的个性化与教师干预 → D6 T1 → D7 总结问卷 | E5-01 §5、T2 |
| 考核 | ClinPath 独立在线考核模块；不走训练路由，不调用 AI，不更新画像、不生成推荐；两位教师匿名独立盲评，分歧超阈值裁决 | E5-01 §6.3 |
| 分析 | 以批次为分析单位的探索性分析；精确随机化检验；单一双侧 P 定义（见 SAP §3.5）；不作确证性推断 | SAP |
| 数据 | 研究编码；身份映射另行限制访问；冻结数据集可复现；合成数据不混入 | E5-01 §11 |
| 伦理 | **尚无批件、尚未提交**；真实学生数据收集前须取得伦理意见或书面豁免 | E5-03 |

## 状态

- 方案为**拟开展**；真实学生研究未启动，没有任何真实教学效果数据。
- 量表权重、分歧阈值、题本可比性均**待两位真实教师确认**。
- 批次日期、每日课时、教师排班**待教研室确认**。
