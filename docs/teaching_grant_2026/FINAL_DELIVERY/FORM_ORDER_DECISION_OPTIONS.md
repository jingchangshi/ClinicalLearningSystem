## 2. 两个选项（分析对象，不含建议）

### 选项 A——保留 X/Y 交叉，强化统一监考、保密管理、题本校准与泄漏事件登记

题本安排**完全不变**（D1 一例、D6 另一例，批内约 4/3 交叉）。新增的控制全部是**管理措施**：

| 控制 | 具体做法（需教研室与申请人确认可实施性） |
| --- | --- |
| A1 统一同时开考 | 同批 7 人在**同一时段、同一场所**同时开始 D1；D6 同样。迟到/请假者不得补测后再计入本批同一时点 |
| A2 监考 | 每次考核有监考人在场；不得携带手机等设备（防拍照，不能防口头转述） |
| A3 保密声明 | 全部 49 名学生签署题本保密声明（D1 与 D6 各一次）；声明文本纳入伦理材料 |
| A4 题本校准 | 两位真实教师对 A01'、A02'（新保密版）做难度与锚点校准，**在冻结顺序之前**完成 |
| A5 泄漏事件登记 | 建立登记表（时间、批次、学生、题本、性质、知情人、处理）；**预先规定**登记事件对分析集的处理（主分析不剔除，另做"剔除已登记事件"的敏感性分析） |
| A6 敏感性分析 | 把 SAP S12 提升为**必报**项；按批次序号、按批内/往届知情者数报告变化量 |

残余风险（**不因 A1—A6 消失**）：F2 的批内暴露 100% 存在；F3 的往届暴露存在；口头转述无法观测；A5 只能记录"被发现的"事件。

### 选项 B——采用经过独立校准的其他平行题本，调整 T0/T1 题本安排

在**不改变**整批随机分配、不改变 7 天流程、不改变主分析单位的前提下，把题本家族拆开：

```
D1（T0）：A 家族（A01' / A02'），批内约 4/3 交叉   ← 新保密版，F5 已要求
D6（T1）：B 家族（B01' / B02'），批内约 4/3 交叉   ← 新增两份平行题本，需独立校准
每名学生：D1 与 D6 仍做不同病例，且**两个时点都不重复**；B 家族在本批 D6 之前从未被本批任何人作答
```

仍然需要的管理措施：A2、A3、A5（题本仍可被拍照或转述）。**A1 仍然需要**（同一批内同时开考可减少跨时点交流），
但 A4 的校准工作量与 B 家族一起翻倍，并**新增**：

| 控制 | 具体做法 |
| --- | --- |
| B1 四份题本 | A01'、A02'、B01'、B02' 各自两位真实教师独立审核（共 8 份独立审核表） |
| B2 家族间校准 | 除 A01'↔A02'、B01'↔B02' 各自可比外，还需就"家族间难度差"给出教师判断，用于解释 T1−T0 的绝对水平 |
| B3 试答校准 | 用住院医/非研究学生做小规模非研究试答，估计作答时间与评分者一致性；试答数据不并入研究数据 |
| B4 家族字段 | 数据字典新增题本家族与版本字段（命名由研究/统计域决定），每名学生的每时点题本编码入库 |

残余风险：F3（往届传播）**不减小**（往届同学在各自 D6 已做过 B 家族）；新增"家族间难度差"这一系统性水平差异（§4.3 论证其在组间差中精确抵消，但使单名学生的 T1−T0 **不能**解读为学习增益）。

> **不推荐、也不在本轮提出的变体**：每批使用不同题本对（题本对与批次完全混杂，7 个群下更难分析）；
> 批内同序（X/Y 与批次/教学组混杂，且与"批内约 4/3"冲突）。理由见泄漏审计 §3 的 P1/P3 行。

## 4. 为什么两选项对"35 种分配"的影响相同，以及对批次层面的影响不同

### 4.1 与随机化推断无关

35 种合法分配是**整批教学组分配**的参考空间（SAP §3.5.1）。题本顺序是**批内**的、在抽签之前就已冻结的第二个过程（E5-01 §8.1）。
无论选 A 还是 B，抽签规则、零分布枚举与 P 值定义（k/35）都**不发生变化**。这一点必须在预注册中写清楚，
以免被误读为"题本方案改动会改变随机化检验"。

### 4.2 选项 A 的污染是"随批次变化的、单方向的"

批内知情者 3—4 人（每批相同），但**往届**知情者 7(b−1) 人随批次增长（F3）。日历顺序与教学组臂是**两次独立过程**，
但 3 对 4 的整批抽签只有 35 种可能，臂与日历顺序的偶然相关无法排除。因此该污染会以**不同幅度**进入不同批次的 Δ_b，
而 Δ_b 就是主统计量 T 的输入（SAP §2.2.1）：它是**偏倚**，不是随机噪声，S12 只能描述其大小，无法校正。

### 4.3 选项 B 的家族难度差精确抵消，但要放弃"变化量＝学习增益"

在 B 下每名学生：T1−T0 ＝（学习增益）＋（B 家族相对 A 家族的难度差 δ）＋（个体机构内变化）。
δ 对所有学生**相同**（同一对家族），因此批次层面变化量 Δ_b 全体平移 δ：
组间差 T 中 δ 精确抵消（**前提**：家族分配与教学组分配相互独立——两者都在 D1 之前冻结）。
这意味着：

- 组间比较（本研究的探索性主要结局）**不受家族难度差影响**；
- 但**单名学生或单个批次的变化量绝对值不再是学习增益**，不得据此写"教学效果"；
- 若教研室希望报告"绝对增益"，需要另行设计（本轮不提出），且需要教师给出 δ 的量级判断（B2）。
