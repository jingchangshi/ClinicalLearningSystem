## 仍然可选：申请人自己的那份 ZIP

若贵校教务处要求的是**另一版本**（栏目名、字数上限或附加页不同），把申请人手上的
`ClinPath_2026_Official_Source_Templates.zip` **原样**放到本目录即可，文件名保持该名称
（或用 `--zip` 指定绝对路径）。填写脚本会自行识别并**只解压**其中的申报书与汇总表到仓库外的临时目录。
本目录已在 `.gitignore` 中排除，**放入的任何原件都不会被提交**。

也接受：`~/.config/clinpath/official/`。

## 为什么放在这里

- Agent 无法访问 ChatGPT 文件沙盒；放到本机可读路径后即可开始 §7.6 的字段级转录与版式核验。
- 也接受：`~/.config/clinpath/official/`，或申请人自选路径（把绝对路径告知 Agent 即可）。

## 提交规则

- 本目录下**除本 README 外的所有文件均被 `.gitignore` 排除**，不会提交到公开仓库。
- 官方原件、原件中的个人信息、签章页**一律不得**进入公开仓库（任务书 §7.1、§11）。
- 转录结果写入私有输出目录，见 `../项目申报前最终核对清单.md`。
