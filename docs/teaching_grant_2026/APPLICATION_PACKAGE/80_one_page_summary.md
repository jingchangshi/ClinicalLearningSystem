# 一页项目摘要（草稿）

**项目名称**：基于人工智能辅助临床推理训练的医学生个性化学习与形成性评价教学改革研究

**场景**：风湿免疫科本科临床见习——每批 7 名学生、7 天、7 个批次，主要研究人群为 49 名本科见习生。

**要解决的问题**：7 天见习内学生完整推理机会少；反馈偏终结性、难追溯；个性化与教师干预缺依据；
缺少独立于训练的评价。

**做什么（教学改革）**：以教师为主导、AI 为辅助，把五阶段推理训练、六维形成性评价、
能力画像、个性化任务和教师干预嵌入 7 天见习：D1 独立在线考核 T0 → D2—D3 分步训练建立能力画像 →
D4—D5 依据 D2/D3 证据个性化强化与教师反馈 → D6 独立在线考核 T1 → D7 总结与问卷。
D1/D6 考核与训练分域：不调用 AI、不更新画像，由两位教师盲评。

**怎么验证（探索性）**：7 个批次整批分配，预先固定 3 批 ClinPath、4 批常规 CBL，从 35 种合法分配中随机抽取
（教研室不允许随机则改为整群准实验）；以批次为分析单位，只作可行性与效应信号探索。

**现状（严格区分）**

| 状态 | 内容 |
| --- | --- |
| 已实现 | ClinPath 训练平台：五阶段作答、追问、六维形成性评价、教师复核与干预、能力画像、任务推荐 |
| 已通过技术测试 | 训练闭环的自动化测试与运行记录（版本与 SHA 见证据包 E2） |
| 待真实教师审核 | 六例病例、六维量表（含权重与锚点）、A01/A02 难度可比性 |
| 计划开展 | 独立在线考核的正式应用、7 批次研究、伦理审查、预注册 |

**预期成果**：经审核的病例与量表；7 天最小训练方案与教师手册；独立考核与盲评流程；探索性研究报告。

**边界声明**：真实学生研究未启动，无任何真实教学效果数据；伦理意见尚未取得；
合成演示（SYNTHETIC / SIMULATED_NOT_HUMAN）仅用于技术可行性。
