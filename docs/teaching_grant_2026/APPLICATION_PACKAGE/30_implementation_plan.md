## 三、风险与对策

| 风险 | 对策 |
| --- | --- |
| 教研室不允许整批随机 | 明确改为整群准实验，不做随机化检验结论 |
| 评分教师同时带教 | 记录盲法风险；由研究负责人安排独立人员 |
| 7 天窗口内增益小 | 定位为探索性；不承诺显著性 |
| 模型不可用 | 规则降级并显式标记；独立考核本身不依赖 AI |
| 学生答案中写入身份信息 | 作答说明禁止；评分前人工去标识检查 |
| 病例/量表审核延误 | 审核未完成则不得用于正式考核 |
