# 供专家与教学管理部门审阅的简明技术演示说明

> 目的：让评审者在 5 分钟内理解**教学流程**与**平台如何支撑它**，以及哪些已实现、哪些尚未发生。
> 演示使用测试/合成账号与数据，**不是真实学生，也不是真实教师**。

## 1. 一句话

教师主导的 7 天见习流程，用 ClinPath 记录推理过程、给出六维形成性反馈、按 D2/D3 证据推荐个性化任务，
并用与训练分开的独立在线考核（D1/D6）做前后测，由两位教师盲评。

## 2. 看什么

| 环节 | 演示内容 | 状态 |
| --- | --- | --- |
| 学生 T0 | 登录 → 我的独立考核 → 分阶段作答 → 提交；看不到答案与评分 | 开发分支，技术验收进行中 |
| 训练 | 五阶段作答、AI 追问（AI 不可用时规则降级并标记） | 已实现 |
| 能力画像与推荐 | 六维画像；推荐任务附理由 | 已实现 |
| 教师干预 | 教师看板、追加任务、复核形成性评分 | 已实现 |
| 学生 T1 | 同 T0，题本不同 | 开发分支，技术验收进行中 |
| 盲评 | 匿名编码队列、互不可见的双评、分歧裁决 | 开发分支，技术验收进行中 |
| 研究导出 | 受控导出研究编码数据 | 开发分支，技术验收进行中 |
| 合成研究演示页 | 60 名虚拟学生，横幅 `SYNTHETIC / SIMULATED_NOT_HUMAN` | 已实现；不是效果证据 |

可复现步骤：`../evidence/E4_validation/README.md`；测试与版本记录：`../FINAL_DELIVERY/TEST_REPORT.md`。

## 3. 请评审者注意

1. 病例与量表是草案，**待真实教师审核**；审核前不会用于正式考核。
2. 平台功能「已实现」不等于教学改革「有效」；真实学生研究尚未开始。
3. 49 人、7 个批次的设计只能探索，不作确证性结论。
4. 独立考核不使用 AI；训练阶段 AI 只改写说明、不决定推荐。
5. 若教研室不允许整批随机，将改为整群准实验，并不再给出随机化检验结论。
